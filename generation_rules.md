# Правила одной генерации тренировки

Документ читается моделью как часть system-prompt вместе с `tutor_prompt.md`
и `VOCAB_TRAINER_SPEC.md`. Определяет формат выхода, состав тренировки и
обязательные инварианты.

## 1. Базовое правило

- Одна тренировка — на **сегодняшнюю дату** в часовом поясе ученика (MSK,
  UTC+3). Файл всегда называется `trainings/training_${TODAY}.html`.
- Проверку «файл за сегодня уже существует» делает код (`generate.py`).
  Модель об этом думать не должна — её всегда зовут только когда файла нет.

## 2. Контракт вывода

Ответ модели **строго** в таком виде, без вступительного текста:

```
<manifest>
{
  "lesson_number": <int>,
  "lesson_title": "<строка>",
  "session_number": <int>,
  "is_new_lesson": <true|false>,
  "new_words": [
    {"tr": "...", "ru": "..."},
    ... ровно 8 элементов
  ]
}
</manifest>

<html lang="ru">
... полный самодостаточный HTML-файл тренировки ...
</html>
```

После `</html>` не должно быть ничего. JSON в `<manifest>` обязан быть
валидным.

## 3. Сколько новых слов

С 2026-05-25: **ровно 8 новых слов в день**. Раньше было 5 (с 2026-04-30,
когда срезали с 10 — слова не закреплялись). Сейчас ученик сам обозначил
лексику как слабое место и попросил усилить именно её. Параметр в коде:
`NEW_WORDS_PER_DAY = 8`.

**Состав 8 новых слов:** минимум 4 из них — **глаголы из приоритетного
пула** (передаётся в `user_message`, парсится из
`lesson_materials/verbs_master_list.md`, ТОП-200 курса). Остальные 4 —
существительные / прилагательные / наречия, тоже частотная разговорная
лексика. Перевод на русский — на модели.

## 4. Девять блоков тренировки

HTML обязан содержать все 9 блоков в этом порядке:

1. 📚 **Словарная разминка** — кликабельные карточки со словами **из
   предыдущей тренировки** (`vocabulary_bank.active`, ещё не
   перенесённые в `long_term`). Лёгкий warm-up.
2. 🧠 **Словарный тренажёр** — 5 типов упражнений по спецификации из
   `VOCAB_TRAINER_SPEC.md`. **Минимум 4 слова из `weak_words` обязаны
   быть задействованы** (часть «вставь пропущенное слово» — лучший
   слот). Этого требует параметр `WEAK_WORDS_MIN_USAGE = 4` в коде.
3. ⚡ **Recall** — 2–3 быстрые проверки на грамматику предыдущего урока.
4. 🎯 **Глагол дня** *(новый блок с 2026-05-25)* — глубокий разбор
   **одного** ключевого глагола из новой лексики:
   - Инфинитив + перевод + управление (-i / -e / -den / -le).
   - Спряжение в 3 основных временах (`-yor`, `-DI`, `-(y)EcEK`) для
     `ben/sen/o/biz/siz/onlar` — таблица.
   - 5–7 живых примеров (предложений) с переводом и разбором.
   - Гармония гласных в этом глаголе, нерегулярности (если есть).
   - Связь с однокоренными словами / синонимами.
5. 📖 **Новая грамматика** — теория сегодняшней темы: формула, таблица
   гармонии гласных, 4–6 примеров с декомпозицией, `dikkat`-блоки.
6. ✍️ **Упражнения по грамматике** — 8–10 интерактивных заданий.
7. 🎨 **Свободная продукция** — творческое задание с шаблоном-подсказкой.
   Опорная лексика — обязательно из 8 новых слов + 2–3 weak_words.
8. 🆕 **8 новых слов** — карточки с новой лексикой. Турецкое слово,
   перевод, пример в контексте. 4+ глагола.
9. 🧭 **Мини-ревью урока** — 3–5 ключевых тезисов, главная формула,
   типичная ошибка.

## 5. Темп прохождения тем

**Максимум 2 сессии на одну грамматическую тему.** После
`session_number=2` следующая тренировка **обязана** быть по новой теме
(`is_new_lesson: true`, `lesson_number+1`). Лимит зашит в код
(`MAX_SESSIONS_PER_LESSON = 2`) и проверяется валидатором — попытка
держаться за старую тему 3+ дня будет отклонена.

При выборе следующей темы: ориентир — учебный план из `tutor_prompt.md`,
но если ученик уже прошёл тот же материал в другой формулировке (см.
`completed_lessons`) — пропускаем и берём следующую неосвоенную.

## 6. Режим работы

В `lesson_progress.json` поле `mode` определяет режим:

- **`mode: "curriculum"`** (по умолчанию) — идём по учебному плану из
  `tutor_prompt.md`, тема выбирается через `current_lesson` + 1.
- **`mode: "expansion"`** — авто-выставляется кодом после
  `lesson_number > LAST_CURRICULUM_LESSON` (=32, последний урок
  Cowork-курса). В этом режиме:
  - Новые темы — выбор модели по уровню ученика: каузатив `-DIR/-T`,
    пассив `-IL/-IN`, плюсквамперфект `-mIşTI`, косвенная речь через
    `-DIK/-EcEK`, идиомы, частотные сложные конструкции.
  - Активное повторение тем из `completed_lessons` через расширенный
    recall (2–4 упражнения вместо 2–3).
  - Удвоенный объём словарной практики: каждое из 8 новых слов
    отрабатывается в нескольких упражнениях.

## 7. Технические требования к HTML

- Один файл, валидный HTML5, инлайн-стили и инлайн-JS.
- Открывается в браузере без внешних запросов.
- Все интерактивные элементы (карточки, чек-ответы, тренажёр) — работают
  без сети.
- Кодировка UTF-8, язык интерфейса — русский.

## 8. Чего НЕ делать

- Не повторять подряд один и тот же тип упражнения.
- Не выдавать больше или меньше 8 новых слов.
- Не использовать в `new_words` слова, которые уже в `active`,
  `long_term` или `weak_words` (это уже знакомая лексика).
- Не задерживаться на одной грамматической теме больше 2 сессий.
- Не трогать `lesson_progress.json` сама — это сделает код после
  валидации ответа.
- Не вставлять текст вне блоков `<manifest>` и `<html>`.
