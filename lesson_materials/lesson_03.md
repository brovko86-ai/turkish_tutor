# Lesson 03 — FıSTıKÇı ŞaHaP — Hard consonants, -d→-t mutation

There are some hard consonants in Turkish. And they are the letters "FSTKÇŞHP". In some cases, these letters make pronunciation difficult in Turkish. For this reason, we make pronunciation easier by replacing these letters with a soft consonant. We can say that there are two main rules in total.


1. FıSTıKÇı ŞaHaP ENDING
If there is a word that ends with one of the letters "FSTKÇŞHP", and if 
the same word gets a suffix starting with "-d", the letter "-d" is converted to "-t". 


NOTE: And there are no exceptions to this rule. 
The meanings of the suffixes we will add to the nouns:


“-de, -da” : “in, on, at”
“-den, -dan” : “from” 
“-ler, -lar” : “plural suffix”
“-dır, -dir, -dur, -dür” : “certainly”
“-ım, -im, -um, -üm” : “my”

As we can see from the examples of "simit, kalem, sabah ve iman”, if both conditions are not met, the FSTKÇŞHP rule is not applied and "d" is not converted to "t".


2. “KeTÇaP”
If there is a word that ends with the letter "k", and the same word has any suffixes that begin with a vowel, the "-k" becomes "-ğ". So with the same logic: 


“k” becomes “ğ”          “t” becomes “d” 
“ç” becomes “c”           “p” becomes ”b”


NOT: We do not follow this rule in some single syllable words. We will discuss this in the following pages. (yumuşak ge:soft g)
