# Lesson 16 — ÖNCE-SONRA — Before/after with nouns & verbs

There is a rule that never changes when we use "önce-before" and "sonra-after" with nouns or verbs in Turkish.


ÖNCE-BEFORE


When we use it with nouns the rule is:
(noun) + (-den, -dan) + (önce) 


(kahve:coffee)(su:water)(içmek:to drink)
Kahveden önce su içiyorum. 


(uyku:sleep)
Uykudan önce kitap okuyorum. 


(ders:lesson)(yemek yemek:to eat -food/meal-)
Dersten önce yemek yiyorum. 


When we use it with verbs the rule is:
(verb root) + (-meden, -madan) + (önce) 


Kahve içmeden önce su içiyorum. 
Uyumadan önce kitap okuyorum. 
Ders çalışmadan önce yemek yiyorum. 


SONRA-AFTER


When we use it with nouns the rule is:
(noun) + (-den, -dan) + (sonra) 


Kahveden sonra su içiyorum. 
Uykudan sonra kitap okuyorum. 
Dersten sonra yemek yiyorum. 


When we use it with verbs the rule is:
(verb root) + (-dıktan, -dikten -duktan, -dükten) + (sonra) 


Kahve içtikten sonra su içiyorum. 
Uyuduktan sonra kitap okuyorum. 
Ders çalıştıktan sonra yemek yiyorum.
