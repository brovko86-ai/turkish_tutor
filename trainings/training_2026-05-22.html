📖 Новая грамматика — суффикс -CE / -CA

Суффикс -ce / -ca / -çe / -ça — один из самых продуктивных в турецком. Он превращает существительные и прилагательные в наречия, образует названия языков и выражает мнение / точку зрения.

Основа + -ce / -ca (гласная гармония)

Если последняя гласная: e / i → -ce
Если последняя гласная: a / ı → -ca
Если последняя гласная: o / u → -ca
Если последняя гласная: ö / ü → -ce

⚠️ FıSTıKÇı ŞaHaP: если слово заканчивается на ç, f, h, k, p, s, ş, t → c становится ç → суффикс -çe / -ça

1️⃣ Наречия из прилагательных и существительных

Добавляя -ce/-ca к прилагательному, мы получаем наречие — «каким образом?». Многие из них ты уже знаешь!

yavaş → yavaşça
yavaş (медленный) + -ça [посл. гл. «а»→-ca, посл. согл. «ş» — FıSTıKÇı, c→ç]
медленно / тихонько
sessiz → sessizce
sessiz (тихий) + -ce [посл. гл. «i»→-ce, посл. согл. «z» — не жёсткий, c остаётся]
тихо / беззвучно
açık → açıkça
açık (открытый) + -ça [посл. гл. «ı»→-ca, посл. согл. «k» — FıSTıKÇı, c→ç]
открыто / откровенно → açıkça
dost → dostça
dost (друг) + -ça [посл. гл. «o»→-ca, посл. согл. «t» — FıSTıKÇı, c→ç]
по-дружески → dostça
çocuk → çocukça
çocuk (ребёнок) + -ça [посл. гл. «u»→-ca, посл. согл. «k» — FıSTıKÇı, c→ç]
по-детски → çocukça
⚠️ DİKKAT ET! Правило мягкого/жёсткого согласного работает с суффиксом -CE так же, как и с -DE/-DA!
Жёсткие (FıSTıKÇı ŞaHaP): F S T K Ç Ş H P → суффикс начинается на ç, а не c.

2️⃣ Названия языков

Языки в турецком образуются по той же формуле: название народа/страны + -ce/-ca. Это и есть «по-турецки», «по-русски» и т.д.

3️⃣ Выражение мнения / точки зрения

К личным местоимениям (в форме дательного падежа) можно добавить -ce/-ca — получаем «по-моему», «по-твоему» и т.д. Но чаще всего суффикс присоединяется к притяжательной форме местоимения.

ben (я) → ben + -ce = bence (по-моему)
sen (ты) → sen + -ce = sence (по-твоему)
o (он/она) → o + -nca = onca (по его/её мнению)
biz (мы) → biz + -ce = bizce (по-нашему)
siz (вы) → siz + -ce = sizce (по-вашему)
Bence bu film çok güzel.
bence = по-моему
По-моему, этот фильм очень красивый.
Sence bu doğru mu?
sence = по-твоему
По-твоему, это правильно?
Türkçe öğrenmek zor, ama mümkün!
Türkçe = язык + naречие
Учить турецкий сложно, но возможно!
