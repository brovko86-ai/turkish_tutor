⚡ Recall — Проверка прошлых тем

Быстрые задачи по ранее изученным темам (включая слабые места из диагностики).

Тема: -arak/-erek · Выбери правильную форму: «Она пришла, напевая» (напевать = şarkı söylemek)
Корень «söyle-» оканчивается на гласную → отбрось «-mek», добавь «-yerek» (передняя гласная «e»).
Тема: future -EcEK · Переведи: «Завтра я куплю новую книгу» (satın almak — покупать, kitap — книга, yarın — завтра)
Будущее время: корень «satın al-» + -(y)acak + личное окончание «-ım» для «ben»; гласная «a» → «-acak».
Тема: -EN/-AN relative · Выбери правильный перевод «человек, говорящий по-турецки»
Причастие настоящего времени «-en/-an» образуется от корня глагола; «konuş-» + «-an» (задняя гласная «u»).
Тема: çünkü / -diği için · Соедини причину: «Я остался дома, потому что шёл дождь» (ev = дом, kalmak = оставаться, yağmur yağmak = идти дождю)
«-diği için» ставится после глагольной формы (-dığı) и передаёт причину; порядок: причина → следствие.

🎯 Глагол дня — engellemek

мешать / препятствовать / блокировать

Управление и форма

engellemek + Kimi? / Neyi? (вин. падеж — кого/что блокировать)
Kim + birini / bir şeyi + engeller (кто-то блокирует кого-то/что-то)
Корень: engelle- (оканчивается на гласную «e»)

Спряжение в трёх временах

Лицо-(I)yor (наст./прош. прод.)-DI (прошедшее)-(y)EcEK (будущее)
Benengelliyorumengelledimengelleyeceğim
Senengelliyorsunengelledinengelleyeceksin
Oengelliyorengellediengelleyecek
Bizengelliyoruzengelledikengelleyeceğiz
Sizengelliyorsunuzengelledinizengelleyeceksiniz
Onlarengelliyorlarengelledilerengelleyecekler
DİKKAT ET! Корень «engelle-» оканчивается на гласную «e» → перед -yor добавляется корень как есть, но гласная «e» поглощается: «engelle-» + «-iyor» → «engelliyor» (буфер не нужен, гласная отбрасывается).

Примеры в контексте

Trafik sıkışıklığı bizi engelliyor.
engelle- + -iyor + -biz (corr. -miz) → engelliyor
Пробки нам мешают.
Bu yasa rekabeti engelledi.
engelle- + -di → engelledi
Этот закон заблокировал конкуренцию.
Onu engelleyemeyeceğim.
engelle- + -ye- + -me- + -yeceğ- + -im (отриц. будущее, 1sg)
Я не смогу его остановить.
Hükumet interneti yasaklamak istedi ama biz bunu engelledik.
yasaklamak + istemek (прошедшее) + ama + engelledik
Правительство хотело запретить интернет, но мы это заблокировали.
Geliştirmek istediğim projeyi kimse engellememeli.
geliştirmek + -istediğim (rel.clause) + engellememeli (долженств. отриц.)
Никто не должен мешать проекту, который я хочу развивать.
💡 Связанные слова: engel (препятствие / барьер), engelleyici (блокирующий / мешающий), engellenemez (непреодолимый).

📖 Новая грамматика — Каузатив

Суффиксы -DİR / -T / -IT / -ER превращают глагол в «заставить / велеть / дать возможность сделать».

Что такое каузатив?

В турецком языке каузатив — это способ показать, что субъект не сам выполняет действие, а заставляет / велит / позволяет кому-то другому его выполнить. Лицо, которое выполняет действие, ставится в дательный падеж (-e/-a) или обозначается конструкцией «-e + глагол».

[кто заставляет] + [кого заставляет -E/-A дат.] + [объект -İ/-İ вин.] + [каузативный глагол]

Выбор суффикса:
-DİR/-DIR/-DUR/-DÜR — самый частотный (большинство глаголов)
-T — после некоторых глаголов на гласную (yap- → yaptır, fakat: iç- → içir-)
-IT/-IT/-UT/-ÜT — 1-слоговые глаголы с согласным: iç- → içir-, gül- → güldür-
-ERT/-ART — редкая группа (пить, смеяться и некоторые другие)

Главное правило выбора суффикса

Тип глаголаКаузативный суффиксПример
Большинство глаголов (2+ слога)-DİR (гармония гласных)çalış → çalıştır, oku → okut / okuttur
Глаголы на гласную (оканчиваются на -а/-е)-Tdinle → dinlet, söyle → söylet, engelle → engellет
1-слоговые с согласным (iç, gör, gül, bil…)-DIR или -ER/-IRgör → gördür, iç → içir, bil → bildir
Глаголы на -t (git, sat, tat…)-TİR (удвоение)git → gittir, sat → sattır
DİKKAT ET! Суффикс -DİR подчиняется ПОЛНОЙ гармонии гласных: после «a/ı» → -dır, после «e/i» → -dir, после «o/u» → -dur, после «ö/ü» → -dür. И FSTKÇŞHP: если корень оканчивается на глухой согласный → -d → -t: «çalış» + «-tır»!

Примеры с разбором

Anne çocuğa kitap okuttu.
oku- (читать) + -t (кауз.) + -tu (прошедшее, 3sg) → окончание удвоилось: -t + -tu = -ttu
Мама заставила ребёнка прочитать книгу. / Мама читала ребёнку книгу.
Müdür raporu bana yazdırdı.
yaz- (писать) + -dır (кауз.) + -dı (прошедшее) → yazdırdı
Директор велел мне написать отчёт.
Mühendis evi bize onarttırdı.
onar- (ремонтировать) + -tır (кауз., FSTKÇŞHP: корень на «r» — нейтральный, но глагол 2сл. → -tır) + -dı
Инженер заставил нас отремонтировать дом.
Öğretmen öğrencilere proje tasarlattı.
tasarla- (проектировать, оканч. на гласную -а) + -t (кауз.) + -tı (прошедш., FSTKÇŞHP: -t → -t, удвоение)
Учитель велел студентам разработать проект.
Patron çalışanlara fazla mesai yaptırdı.
yap- (делать) + -tır (кауз., FSTKÇŞHP: «p» → -t вместо -d) + -dı
Начальник заставил сотрудников работать сверхурочно.
💡 Запомни: в каузативной конструкции есть ДВА участника. Тот, кто «заставляет» — именительный падеж. Тот, кого «заставляют» — дательный (-e/-a) или, реже, именительный в описательных контекстах.

✍️ Упражнения по грамматике

8 заданий на каузатив и новую лексику.

1. Образуй каузатив от «ağlamak» (плакать). Какой суффикс нужен? Выбери правильную форму «он заставил её плакать»:
«ağla-» оканчивается на гласную → суффикс -t; прошедшее -tı; FSTKÇŞHP: -t + -tı = -ttı.
2. Вставь каузативную форму: «Annem bana oda_____ . (Мама велела мне убрать комнату.) [toplamak = убирать]»
«topla-» (оканч. на гласную «a») → -t (кауз.) + -tı (прошедш., 3sg); FSTKÇŞHP: -t + -tı = -ttı.
3. Какой вариант означает «дизайнер заставил нас разработать логотип»? (logo tasarlamak)
«bize» — дательный падеж «мы»; «tasarla-» + -t (кауз.) + -tı (прошедш.) = «tasarlattı».
4. Переведи: «Инженер велел нам отремонтировать старую машину.» [araba = машина, eski = старый, onarmak = ремонтировать]
«onar-» (2 слога, оканч. на согласную «r») → каузатив «-t»; машина — объект (вин. падеж «arabayı»); «bize» — дат. пад. «нам».
5. Образуй каузатив с «yasaklamak» (запрещать). Выбери правильную форму «правительство запретило это» (каузативное значение: велело запретить):
«yasakla-» оканчивается на гласную «a» → суффикс -t; прошедш. -tı → «yasakla-t-tı» = «yasaklattı».
6. Вставь каузатив: «Patron çalışanlara rapor ___________. (Начальник велел сотрудникам написать отчёт.) [yazmak = писать]»
«yaz-» (1 слог, согласная «z») → каузатив -dır; прошедш. -dı → «yaz-dır-dı» = «yazdırdı».
7. Переведи: «Эта новость заставила меня плакать.» [haber = новость, ağlamak = плакать]
Каузатив: «ağla-» + «-t» + «-tı» = «ağlattı»; «beni» — вин. пад. «меня» (объект, которого заставили плакать).
8. Какое предложение использует каузатив ПРАВИЛЬНО? (teklif etmek = предлагать → каузатив: teklif ettirmek)
Каузатив составного глагола «teklif etmek»: «et-» + «-tir» (FSTKÇŞHP: «t» → «-tir» → «ettirdi»); «bize» — кому велели.

🎨 Свободная продукция

Составь 4–5 предложений о ситуации, используя каузативные конструкции и новые слова.

Сценарий: Ты менеджер проекта. Ты кому-то велел что-то сделать — например, починить сайт, разработать дизайн, запретить доступ, разрешить публикацию. Используй слова из опоры:

Опора: engellemek / tasarlamak / onarmak / yasaklamak / izin vermek / teklif etmek / geliştirmek / incelemek / desteklemek

Образец:
Ekibe yeni web sitesi tasarlattım. — Я велел команде разработать новый сайт.
Eski sistemin hatalarını onartım. — Я велел починить ошибки в старой системе. (Примечание: «onartım» — кауз. от «onarmak», 1sg)
Bazı kullanıcıların erişimini engelledim. — Я заблокировал доступ некоторых пользователей.
Desteklemek istediğim özelliğe izin verdim. — Я разрешил функцию, которую хотел поддержать.
Nihayet projeyi teklif etmeyi başardık! — Наконец-то нам удалось предложить проект!

🧭 Мини-ревью урока

  • ✅ Каузатив — способ сказать «заставить / велеть кому-то сделать что-то». Лицо-исполнитель ставится в дательный падеж (-e/-a).
  • ✅ Выбор суффикса: глагол на гласную → -t (tasarla → tasarlat-); большинство остальных → -DİR с гармонией (yaz → yazdır-); 1-сложные и особые → -DİR/-ER/-IR (gör → gördür-).
  • ✅ FSTKÇŞHP работает и здесь: если корень оканчивается на глухой согласный, -d → -t в суффиксе (çalış → çalıştır-).
  • ✅ Типичная ошибка: добавить -dir/-t дважды или перепутать суффикс (-dır вместо -t для глаголов на гласную).
  • ✅ 8 новых слов: ağlamak, teklif etmek, yasaklamak, izin vermek, engellemek, tasarlamak, onarmak, aklına gelmek.
