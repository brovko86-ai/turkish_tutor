Часть 2 · Воспроизведение (RU → TR)

Как по-турецки «защищать / охранять»? ⚠ слабое
korkmak = бояться; kurtarmak = спасать; нужный глагол — охрана, защита.
Как по-турецки «связывать / привязывать»? ⚠ слабое
Корень bağ- = связь, узел. Не путать с bağırmak (кричать).
Как по-турецки «быть в гостях / гостить у кого-то»?
misafir = гость; olmak = быть/становиться. Именно olmak даёт значение «быть в гостях».
Как по-турецки «смеяться над / подшучивать»?
dalga = волна; geçmek = проходить. Устойчивое разговорное выражение. alay etmek — более злобное насмешничество.
Как по-турецки «занавеска / штора»?
pencere = окно; duvar = стена; kapı = дверь. Нужное слово — то, что висит на окне.

Часть 5 · Переведи с русского на турецкий

«защищать» (инфинитив) ⚠ слабое

Корень — kor-; не путать с korkmak (бояться) — там дополнительная буква.

ilerlemek → ilerle- → перед -iyor финальная e выпадает → ilerliyor + суффикс biz.

⚡ Recall — быстрая проверка грамматики

Слабые темы из экзамена. Сегодня: -arak/-erek и будущее -EcEK.

⚡ -arak / -erek
Выбери правильную форму: «Она пришла, смеясь» (gülmek + -erek).
Правило: основа на гласную → просто добавь -rak/-rek. gül- (задняя ü) → -erek. Форма -arak только после задних a/ı/o/u.
⚡ Будущее время -EcEK
Переведи: «Завтра она будет защищать диссертацию» — используй korumak (защищать).

korumak → основа koru- (оканчивается на гласную) → + -yacak (буфер y) + личн. окончание o = нет окончания. Гармония: u → -acak.
⚡ Причастие -EN / -AN (тот, кто делает)
Как сказать «путешествующий человек» (gezmek + -en)?
gezmek → gez- (последняя гласная e) → причастие -en (передняя гармония). -an только после a/ı/o/u.

🎯 Глагол дня — söndürmek

söndürmek = гасить / тушить / выключать (свет, огонь, пожар)
Управление: neyi söndürmek — что именно гасить (винительный падеж)

Основа: söndür-
Структура: sön (угасать) + -dür (каузативный суффикс!) → söndür-
Уже каузатив! sönmek (гаснуть) → söndürmek (гасить = заставить угаснуть)

Спряжение в трёх временах

Лицо-(i)yor (наст.)-DI (прош.)-(y)EcEK (буд.)
bensöndürüyorumsöndürdümsöndüreceğim
sensöndürüyorsunsöndürdünsöndüreceksin
osöndürüyorsöndürdüsöndürecek
bizsöndürüyoruzsöndürdüksöndüreceğiz
sizsöndürüyorsunuzsöndürdünüzsöndüreceksiniz

DİKKAT ET! Гармония гласных: корень sön содержит ö (передняя, огублённая) → суффиксы с ü: -dür, -üyor, -üm, -ük. В будущем: söndür + -ecek → söndürecek (e остаётся передним рядом). Буква k в конце -ecek озвончается перед гласными → söndüreceğ-im/iz.

Живые примеры

Işığı söndürdüm.
ışık (свет) + -ı (вин.) | söndür + -dü + -m (ben, прош.)
Я выключил(а) свет.
İtfaiye yangını söndürdü.
itfaiye = пожарная служба | yangın = пожар | söndür + -dü (o, прош.)
Пожарные потушили пожар.
Lütfen sigaranı söndür.
sigara = сигарета | -nı = твою (посессив + вин.) | söndür = императив
Пожалуйста, потуши сигарету.
Çıkmadan önce mumları söndüreceğiz.
çıkmadan önce = перед тем как выйти | mum + -ları = свечи (мн. вин.) | söndür + -ecek + -iz (biz, буд.)
Перед тем как выйти, мы потушим свечи.
Bu müzik içimdeki acıyı söndürüyor.
içimdeki = то что внутри меня | acı = боль | söndür + -üyor (o, наст.) — метафорически
Эта музыка гасит боль внутри меня. (перен.)
Связанные слова:
• sönmek — гаснуть (сам по себе): Ateş söndü. = Огонь погас.
• söndürmek — гасить (каузатив: кто-то гасит)
• sönük — тусклый / погасший (прилагательное)
Видишь паттерн? sön- + -dür = каузатив — сама тема сегодняшнего урока!

📖 Каузатив — Сессия 2: углублённый разбор

В первой сессии мы познакомились с базовыми суффиксами. Сегодня — закрепляем выбор суффикса, разбираем двойной каузатив и тонкости управления.

Напоминание: выбор суффикса

1) Основа оканчивается на согласный → -DIR (+ гармония: -dır/-dir/-dur/-dür/-tır/-tir/-tur/-tür)
2) Основа оканчивается на гласную → -T
3) Односложные основы с определёнными согласными → -IR / -ER / -UR / -ÜR / -AR (нерегулярные)

FSTKÇŞHP в конце основы: -d → -t (озвончение суффикса отменяется!)
ОсноваТипСуффиксКаузативЗначение
okumakоканч. на гласную u-t okutmakзаставить читать
yazmakоканч. на согл. z-dır yazdırmakзаставить писать
bilmekоканч. на согл. l-dir bildirmekсообщать / уведомлять
içmekоканч. на согл. ç (FSTKÇŞHP!)-tir içirmekпоить / давать пить
gülmekоканч. на согл. l (нерег.)-dür güldürmekсмешить / заставить смеяться
korumakоканч. на гласную u-t korutmakзаставить охранять (редко)
sönmekоканч. на согл. n-dür söndürmekгасить / тушить

Двойной каузатив (кто-то велит кому-то велеть)

Можно добавить два каузативных суффикса подряд:
yıka-mak (мыть) → yıka-t-mak (заставить мыть) → yıka-t-tır-mak (велеть, чтобы заставили мыть)

Но! Два t рядом не стоят: yıkat + -tır → yıkattırmak (два t — нормально, это стык суффиксов)
Müdür sekreterine raporu yazdırdı.
müdür = директор | sekreterine = своему секретарю (дат.) | raporu = отчёт (вин.) | yaz + -dır + -dı (o)
Директор велел секретарю написать отчёт.
Annem bana odamı toplatttı.
⚠ ОШИБКА: три t невозможны! Правильно:
Annem bana odamı toplattı.
topla- (собирать) + -t (кауз., основа на гл.) + -tı (прош., t после t → tt: два t верно) | odamı = мою комнату
Мама велела мне убрать мою комнату.
Doktor hastayı uyuttu.
uyu- (спать) + -t (кауз.) + -tu (прош.) | hasta = пациент (вин. hastyı → hastayı)
Врач усыпил пациента.
DİKKAT ET! Кто кому «велит» — маркируется дательным падежом:
Anne → çocuğa (ребёнку, дат.) → ellerini yıkattı.
Мама заставила ребёнка помыть руки.

Объект каузируемого действия остаётся в винительном: ellerini (руки — его руки).

Каузатив vs. инфинитив — разница смысла

ФормаПримерЗначение
Обычный глагол Ben okumak istiyorum. Я хочу читать (сам).
Каузатив Ben sana okutmak istiyorum. Я хочу, чтобы ты читал (заставить тебя читать).
Обычный глагол Araba yıkandı. Машина помылась (пассив — сама по себе).
Каузатив Arabayı yıkattım. Я велел помыть машину (на мойке).

✍️ Упражнения по грамматике — Каузатив

1. Какой суффикс каузатива добавляется к глаголу gelmek (приходить)?
Основа: gel- (оканчивается на согласный l)
Оканчивается на l (не входит в FSTKÇŞHP) → -dir (передняя гармония, e→i).
2. Образуй каузатив от uyumak (спать) → значение «усыпить / уложить спать».
uyu- оканчивается на гласную u → суффикс -t → uyu+t = uyutmak.
3. Директор заставил нас слушать длинную речь.
Вставь правильную форму каузатива глагола dinlemek:
Müdür bize uzun bir konuşmayı ___________.

dinle- (гласная) → +t → dinlet- (согл. t) → +tir (FSTKÇŞHP: t!) → dinlettir- → +di (прош., o). Двойной каузатив здесь уместен.
4. Переведи: «Я отдал машину помыть» (arabayı yıkat- + прош. вр. ben)

yıka- (гл.) → +t → yıkat- → прош. вр. ben: -tım. Двойное t корректно: суффикс -t + -tım.
5. Какое предложение правильно выражает смысл «Учитель заставил учеников прочитать книгу»?
Каузатив: öğrencilere (дат. — кому велели) + kitabı (вин. — что читать) + okuttu (о + кауз.прош.).
6. FSTKÇŞHP — какой суффикс получится у глагола içmek (пить) в каузативе?
Основа: iç- (оканчивается на ç из FSTKÇŞHP)
ç входит в FSTKÇŞHP → суффикс -tir озвончён обратно? Нет: -dir → -tir. Но у içmek нерегулярный суффикс -ir → içirmek (исторически нерегулярный).
7. «Мама будет укладывать ребёнка спать в 9 вечера» — используй uyutmak:
Anne çocuğu saat dokuzda ___________.

uyut- оканчивается на t (согласный) → -acak (задняя гармония: u). t+acak → uyutacak. Личное окончание o = нет окончания.
8. Найди ошибку в предложении:
«Ben arkadaşımı kitap okuttum.»
Что не так?
В каузативе «тот, кого заставляют» стоит в дательном (-a/-e), а не просто с посессивом. arkadaşımı — это винительный, нужен arkadaşıma.
9. Переведи: «Она заставила его путешествовать по Европе» — используй gezmek (geztirmek):

gez- (согласная) → -dir → gezdir- → прош. вр. o: geztirdi. FSTKÇŞHP? z — нет. Но s перед этим... нет, gez- заканчивается на z, не входит. Ответ: geztirdi.
10. Как по-турецки «Я велел ей почувствовать себя лучше»?
hissetmek → hissettirmek (каузатив)
«Велеть КОМУ-ТО почувствовать» → дательный: ona (ей, дат.) + hissettirdim. «Onu» было бы объектом физического воздействия, не каузируемого лица.

🧭 Мини-ревью урока

1. Три суффикса — три правила выбора:
Основа на согласный → -DIR (с гармонией)
Основа на гласную → -T
Нерегулярные (односложные) → -IR/-ER/-UR/-ÜR
2. FSTKÇŞHP меняет -D на -T:
yazmak (z — не FSTKÇŞHP) → yazdırmak ✓
içmek (ç — FSTKÇŞHP!) → içirmek (нерег.) / иначе было бы -tir
Проверяй последний согласный основы!
3. Управление в каузативе:
Кто велит → субъект (именительный)
Кому велят → дательный (-a/-e)
Что делают → винительный (-ı/-i/-u/-ü)
4. Двойной каузатив:
doldurmak → doldur-t-mak = doldurtmak
Реальный смысл: «велеть кому-то, чтобы наполнил»
Типичная ошибка: три одинаковые буквы подряд невозможны в турецком!
toplatttı ❌ → toplattı ✓ (кауз. -t + прош. -tı = два t, не три)
