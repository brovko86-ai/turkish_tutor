Часть 5 · Переведи с русского на турецкий

«Он пригласил нас на вечеринку.» — используй davet etmek в прошедшем (-DI), мы = bizi, вечеринка = parti.
Порядок: объект + место назначения + глагол; партия требует дательного падежа -e.
«Наконец-то проблема решилась.» — problem = sorun, решилась = çözüldü.
Наречие nihayet стоит в начале предложения; пассивный глагол çözül- + прошедшее -dü.
«Учитель заставил ученика рассказать историю.» — öğretmen, öğrenciyi, hikâyeyi.
Каузатив anlat- + -tır + -dı; тот, кого заставляют, стоит в винительном (-ı/-i/-u/-ü).

⚡ Recall — быстрая проверка

Тема: -arak/-erek (слабая)

Выбери правильную форму: «Он пришёл, бежа.»
-arak после задних гласных (a/ı/o/u), -erek — после передних (e/i/ö/ü). Корень koş содержит o.
Тема: -EN/-AN relative. Какое предложение означает «книга, которую я читаю»?
Объектное причастие (-DİĞİ + посессив) = «который я [делаю]»; -EN/-AN = субъектное («который делает»).

Тема: future -EcEK (слабая)

Переведи: «Мы поддержим этот проект.» Глагол desteklemek, проект = proje.
destek-le- + -yecek + -iz; буферная -y- между гласными; гармония: e → -yecek.

Тема: instrumental -le/-la (слабая)

Выбери правильный вариант: «Я еду туда с другом.» (arkadaş)
Инструментальный падеж -la/-le (+ посессив -ım-) = «вместе с»; -tan — аблатив «от/из».

🎯 Глагол дня — dayanmak

Один глагол — глубокий разбор: спряжение, управление, живые примеры.

dayanmak — выдерживать / терпеть / опираться
Управление: dative (-e/-a) для «опираться на», «терпеть что-то»
Корень: dayan- (оканчивается на согласную → никакой буферной гласной)

Спряжение

Лицо-yor (наст.)-dı (прош.)-acak (буд.)
bendayanıyorumdayandımdayanacağım
sendayanıyorsundayandındayanacaksın
odayanıyordayandıdayanacak
bizdayanıyoruzdayandıkdayanacağız
sizdayanıyorsunuzdayandınızdayanacaksınız
onlardayanıyorlardayandılardayanacaklar

Гармония гласных и нерегулярности

Tip: Последняя гласная в корне — a → все суффиксы на заднем ряду: -ıyor, -dı, -acak. Стяжение в будущем: dayana + -acak → dayanacak (нет удвоения, т.к. корень на -n, не на гласную).

Живые примеры

Bu sıcağa dayanamıyorum!
dayan- + -ama (невозможность) + -ıyor + -um
Не могу вынести эту жару!
Duvara dayanarak bekledi.
dayan- + -arak (деепричастие)
Он ждал, опершись о стену.
Bu zorluğa dayandım.
dayan- + -dı + -m
Я выдержал эту трудность.
Ne kadar dayanacaksın?
dayan- + -acak + -sın
Сколько ты ещё будешь терпеть?
Çocuklar gürültüye dayanıyor.
dayan- + -ıyor (3sg)
Дети терпят шум.
Bu soğuğa dayanamayacağım.
dayan- + -ama + -yacak + -ım
Я не смогу вынести этот холод.
Однокоренные слова: dayanıklı (прочный / стойкий), dayanıklılık (прочность / выносливость), dayanak (опора / поддержка).

📖 Каузатив — сессия 2: углублённый разбор

В первой сессии были введены суффиксы -DIr, -t, -Ir. Сегодня — тонкости выбора варианта и сложные случаи.

Глагол → Каузатив («заставить/дать сделать»)

-DIr — основной, самый частотный: yaz → yazdırmak
-t — после длинных/производных основ и ряда глаголов на -r/-l: okut-, anlat- → anlattır
-Ir/-Er — несколько нерегулярных: çık → çıkar-, git → gider-, kork → korkut-

Каузатив «лица»: тот, кого заставляют → винительный (-ı/-i/-u/-ü)

Таблица гармонии гласных в -DIr

Последняя гласная корняСуффиксПример
a, ı-dır / -tıryaz → yazdır, sat → sattır
e, i-dir / -tirgel → geldir*, sev → sevdir
o, u-dur / -turoku → okut, koş → koştur
ö, ü-dür / -türsöyle → söylet, gör → gördür
DİKKAT ET! Если глагол оканчивается на один из FSTKÇŞHP (глухие) — вместо -dir пишем -tir: sat → sattır, koş → koştur. Двойное -t появляется именно здесь.

Каузатив новых глаголов сегодня

çekindirmek
çekin- (стесняться) + -dir → заставить стесняться / удержать
Seni çekindirmeye çalışmıyorum. — Я не пытаюсь тебя сдерживать.
dayandırmak
dayan- + -dır → заставить терпеть / укрепить (конструкцию)
Köprüyü duvara dayandırdılar. — Они опёрли мост на стену.
yansıtmak
yansı- (отражаться) + -t → отражать / передавать (каузатив)
Bu film gerçeği yansıtıyor. — Этот фильм отражает действительность.
yer aldırmak
yer almak → каузатив: включить / разместить
Projeyi rapora yer aldırdı. — Он включил проект в отчёт.
Полезно: Каузатив можно «складывать» — двойной каузатив: yaz → yazdır → yazdırt (заставить кого-то заставить написать). В разговорной речи встречается, хотя и редко.

✍️ Упражнения по грамматике

1. Образуй каузатив от глагола içmek (пить). Какой суффикс нужен?
iç → içir- (нерегулярная форма, как kork → korkut); суффикс -DIr не используется после этого корня.
2. Переведи: «Мама заставила ребёнка выпить молоко.» anne, çocuk, süt.
«Заставить пить» = içirmek; тот, кому дают пить → дательный (-a); молоко (определённый объект) → винительный (-ü).
3. Выбери правильный каузатив от yazmak:
yaz оканчивается на -z (звонкий согласный) → суффикс начинается с -d: -dır; FSTKÇŞHP здесь не применяется.
4. Образуй форму: «Он заставил её выучить слова.» — глагол öğrenmek, слова = kelimeleri, она = onu.
öğren → каузатив öğret- (нерегулярный); прошедшее: öğret + -ti (FSTKÇŞHP — t глухой → -ti); объект onu в винительном.
5. Тема FSTKÇŞHP: какой каузатив образуется от koşmak (бежать)?
koş оканчивается на -ş (входит в FSTKÇŞHP) → суффикс -DIr озвончается до -tur: koş + tur + mak.
6. Выбери верный вариант: «Директор заставил сотрудников прочитать отчёт.» (okumak)
Тот, кого заставляют → дательный -a (çalışanlara); raporu — винительный (определённый объект); прошедшее okutt-u.
7. Переведи: «Эта новость заставила его задуматься.» — haber, düşünmek (→ düşündürmek), onu.
Субъект (новость) сам «заставляет» — без агента; düşün → düşündür + прошедшее -dü (гармония: ü → -dü).
8. Образуй каузативную форму от çekinmek (стесняться) и переведи: «Не заставляй меня стесняться!»
çekin → çekindir-; отрицательный императив 2sg: -me/-ma после корня; çekindirme = «не заставляй стесняться».

🧭 Мини-ревью урока

  • Три суффикса каузатива: -DIr (основной, с гармонией: -dır/-dir/-dur/-dür / -tır/-tir/-tur/-tür после FSTKÇŞHP), -t (после длинных основ: okut-, anlat-), -Ir (нерегулярные: çık→çıkar, git→gider, iç→içir, öğren→öğret).
  • Тот, кого заставляют, стоит в дательном (-e/-a) или в винительном (-ı/-i/-u/-ü) — зависит от глагола. Чаще всего дательный: «Çocuğa sütü içirdi».
  • FSTKÇŞHP → -tır/-tir/-tur/-tür: если корень оканчивается на глухой согласный, мягкий -d меняется на -t. Запомни: koş → koştur, sat → sattır.
  • dayanmak — выдерживать/опираться (+dative); важный глагол для выражения стойкости. Каузатив: dayandırmak.
  • Типичная ошибка: писать три одинаковые буквы подряд — в турецком такого нет. sat + tır = sattır (двойное t, не тройное!).
