Тема 1 · Деепричастие -arak/-erek («делая / путём»)

Тема 2 · Будущее время -(y)EcEK

R3. Поставь в правильную форму: «Вы защитите город.» (korumak, siz)
💡 koru- оканчивается на гласную → -(y)EcEK: koruyacak-. Личное окончание siz → -sınız (задний ряд, o/u → -u-). Корень: koru- → koru + y + acak + sınız.

Тема 3 · Именное сказуемое с değil

R4. Выбери правильный перевод: «Я не иностранец.»
💡 Именное отрицание: [существительное/прилагательное] + değil + личный суффикс. 1-е лицо ед. ч.: değil + -im.

🎯 Глагол дня — yaptırmak

yaptırmak — «велеть сделать / заказать (работу) / заставить сделать»
Это каузатив от yapmak (делать): yap + -tır → yaptırmak.
Управление: кому-то (-e/-a дательный) + что сделать (прямое дополнение, -i/-ı).

📖 Новая грамматика — Каузатив (-DIR / -T / -IR / -ER)

Каузатив — это форма глагола, которая означает «заставить / велеть / дать сделать». По-русски мы иногда говорим «постричься» (= дать себя подстричь) или «заставить выучить». В турецком для этого есть специальный суффикс, вставляемый в основу глагола.

Суффиксы каузатива — четыре варианта

Основа глагола + -DIR / -DİR / -DUR / -DÜR ← самый частый
Основа глагола + -T ← после долгих/сложных основ
Основа глагола + -IR / -ER / -UR / -ÜR ← небольшая группа глаголов
Основа глагола + -IT / -ET / -UT / -ÜT ← ещё реже (двойной каузатив)

Правило выбора суффикса

Тип основыСуффиксПример
Большинство глаголов (1–2 слога) -DIR/-DİR/-DUR/-DÜR yaz → yazdırmak, iç → içirtmek*
Основа оканчивается на -r или длинная (3+ слога) -T boyamak → boyatmak, okumak → okutmak
Небольшая группа (çık-, git-, giy- и др.) -IR/-ER/-UR çık → çıkarmak, git → gittirmek*
DİKKAT! После суффикса каузатива действует FıSTıKÇı ŞaHaP: если корень оканчивается на глухой согласный (F, S, T, K, Ç, Ş, H, P), суффикс -DIR озвончается в -TIR/-TİR/-TUR/-TÜR:
• seç (ç — глухой!) → seçtirmek ✓ (не seçdirmek)
• yaz (z — звонкий) → yazdırmak ✓

✍️ Упражнения — Каузатив

G1. Выбери правильный каузатив от «okumak» (читать):
💡 Основа oku- оканчивается на гласную и является 3-сложной → суффикс -t (не -dir). Правило длинной основы.
G2. Образуй каузатив и переведи: «Учитель велел ученику написать предложение.»
(Öğretmen, öğrencisine, cümleyi, yazmak)

💡 yaz- (звонкий z) + -dır + прошедшее -dı + 3-е лицо ед. ч. (нет окончания). Итого: yaz + dır + dı = yazdırdı.
G3. «Я велел покрасить забор.» Выбери правильную форму (boyamak → каузатив, ben, прошедшее):
💡 boyamak → каузатив -t → boyatmak. Затем прошедшее: boyat + -tı (FSTKÇŞHP! t — глухой → -tı) + -m (1 л. ед.). Итого: boyat + tı + m → boyattım... Нет, подождём — boyattırdım означает двойной каузатив. Правильная форма одиночного каузатива: boyattım. Но вопрос про простой каузатив boyatmak: boyat + -tı + m = boyattım.
Пояснение к G3: boyamak → boyatmak (каузатив через -t). Прошедшее от boyatmak: boyat- + прош. суффикс. Корень оканчивается на t (глухой → FSTKÇŞHP!) → суффикс -tı: boyat + tı + m = boyattım. Обрати внимание: два «t» — один из корня, второй из суффикса. Правильный ответ выше — boyattım (одиночный каузатив, «я велел покрасить»).
G4. «Мама завязала ребёнку шнурки.» — Anne çocuğunun ayakkabısını ___________ .

💡 bağlamak длиннее 2-х слогов и основа на гласной → каузатив -t: bağlatmak. Прошедшее: bağlat- + суффикс. Корень на t (глухой) → -tı, 3 л. ед. ч. нет окончания.
G5. Что значит «Saçını kestirdi»?
💡 kestirmek = каузатив от kesmek. Субъект не стрижёт сам — он организует стрижку. «Постричься» по-турецки = saçını kestirmek.
G6. Образуй каузатив: «Они велели ему спеть песню.»
(şarkı, söylemek → söyletmek; ona, past, они)

💡 söyletmek (каузатив уже дан). Прошедшее: söylet- + суффикс. Корень на t → -ti + -ler (3 л. мн. ч.) → söylettiler. Два t: один из каузатива -t, второй из прошедшего -ti.
G7. Выбери правильный перевод: «Bu projeyi müdüre yaptıracağız.»
💡 yaptıracağız = каузатив yaptır- + будущее -(y)acak + -ız (мы). Дательный -e (müdüre) указывает на исполнителя. Это не пассив и не простое будущее.
G8. Переведи на турецкий: «Я велел другу купить билеты.»
(arkadaş → arkadaşıma, bilet → biletleri, almak → aldırmak)

💡 aldırmak: al + -dır (звонкий l → -dır). Прошедшее 1 л. ед. ч.: aldır + -dı + -m → aldırdım. Корень aldır- оканчивается на r (звонкий) → суффикс -dı.

🧭 Мини-ревью урока

  • Каузатив = «заставить / велеть / дать сделать». Субъект сам не выполняет действие.
  • Главный суффикс: -DIR/-DİR/-DUR/-DÜR (большинство глаголов) и -T (длинные основы или на -r).
  • FıSTıKÇı ŞaHaP: если корень на глухой → -DIR → -TIR: seçtirmek, doldurtmak.
  • Конструкция: субъект + исполнитель (-e) + объект (-i) + каузатив-глагол.
  • Типичная ошибка: *okudırmak → правильно okutmak (длинный глагол → -t).
Формула каузатива:
Корень + -DIR/-T/-IR + -mek = каузативный инфинитив
yaz + -dır + -mak = yazdırmak
boya + -t + -mak = boyatmak
