⚡ Тема: -arak/-erek
Выбери правильную форму: «Она вышла, улыбаясь.»
Правило: «улыбаться» = gülümsemek. Корень gülümse- оканчивается на гласную → -erek (не -arak). Форма: gülümse + erek = gülümseyerek.
⚡ Тема: повелительное наклонение (emir kipi)
Как сказать «(ты) не спи!» по-турецки? Глагол: uyumak.
Правило: отрицательный императив 2sg = корень + -ma/-me. Корень uyu- + ma → uyuma.
⚡ Тема: будущее время -EcEK
Переведи: «Они будут наблюдать за экспериментом.»
Глагол: gözlemlemek → они (onlar).
Правило: корень gözlemle- оканчивается на гласную → -yecek (буферный y). Для onlar: -ler. Форма: gözlemle + y + ecek + ler = gözlemleyecekler.
⚡ Тема: номинальное сказуемое с değil

(bu karar / tartışmalı)
Правило: в именном предложении отрицание строится через değil после прилагательного/существительного. Порядок: подлежащее + предикатив + değil.

🎯 Глагол дня — düzenlenmek

Пассив от düzenlemek (организовывать / устраивать / редактировать) → düzenlenmek = организовываться / быть организованным / проводиться. Это один из ключевых глаголов сегодняшних новых слов.

düzenle-n-mek
корень: düzenle- (оканчивается на гласную) → пассив через -n- (не -il-)
Управление: субъектом является то, что организуется; организатор → tarafından (кем-то)
Пример: Toplantı müdür tarafından düzenlendi. → Совещание было организовано директором.

Спряжение в 3 временах

Лицо -iyor (наст. врем.) -di (прош. врем.) -ecek (будущ. врем.)
bendüzenleniyorumdüzenlendimdüzenleneceğim
sendüzenleniyorsundüzenlendindüzenleneceksin
odüzenleniyordüzenlendidüzenlenecek
bizdüzenleniyoruzdüzenlendikdüzenleneceğiz
sizdüzenleniyorsunuzdüzenlendinizdüzenleneceksiniz
onlardüzenleniyorlardüzenlendilerdüzenlenecekler
DİKKAT ET! Обрати внимание: в будущем времени корень düzenle- + -ecek → düzenlenecek (ğ не появляется, потому что предшествует -n-, а не задняя гласная напрямую). Сравни: git + ecek → gidecek — там ğ потому что t перед гласной меняется.

Собрание проводится каждый понедельник.

📖 Страдательный залог — углубление (сессия 2)

Сегодня разбираем: пассив глаголов с уже существующей -l- в корне, пассив в разных временах, агент действия через tarafından, и разница -il- vs -in-/-ın-.

Когда -IL-, а когда -IN-/-IN-?

Корень оканчивается на согласную ≠ l:
  → добавляй -IL-/-ÜL-/-UL-/-IL- (гармония)
  → Пример: yaz-ıl-mak · kapat-ıl-mak · gör-ül-mek · bul-un-mak*

Корень оканчивается на -l или на гласную:
  → добавляй -IN-/-ÜN-/-UN-/-IN-
  → Пример: düzenle-n-mek · topla-n-mak · söyle-n-mek

*bulmak → bulunmak (исключение: l на конце → -un-)

Таблица гармонии гласных для пассива

Последняя гласная корня Пассивный суффикс Пример
a / ı -ıl- / -ın- yap → yapılmak · topla → toplanmak
e / i -il- / -in- gez → gezilmek · söyle → söylenmek
o / u -ul- / -un- doldur → doldurulmak · bul → bulunmak
ö / ü -ül- / -ün- gör → görülmek · düzenle → düzenlenmek

Пассив во всех временах — структура

Корень + пасс. суф. + -iyor / -di / -ecek / -miş + личное окончание
Mektup yazıldı.
yaz + ıl + dı → прошедшее очевидное
Письмо было написано.
Rapor yarın teslim edilecek.
teslim et + il + ecek → будущее, ettirmek-тип
Отчёт будет сдан завтра.
Bu şehir yüzyıllar önce kurulmuş.
kur + ul + muş → evidential past (пересказывательное)
Говорят, этот город был основан несколько веков назад.
Kapı şu an kapatılıyor.
kapat + ıl + ıyor → настоящее
Дверь сейчас закрывается.

Агент действия — tarafından

[кто действует] + tarafından + пассивный глагол
Müdür tarafından karar verildi. → Решение было принято директором.
DİKKAT ET! Пассив НЕ обязательно называет агента. Часто он нужен, когда:
• агент неважен / неизвестен: Yemek pişirildi. (Еда была приготовлена — кем — неважно)
• говорим о правилах/нормах: Burada sigara içilmez. (Здесь не курят / курение запрещено)
• официальный/газетный стиль
💡 Частотная конструкция: Запомни устойчивое выражение
Burada … -maz/-mez = здесь (нельзя делать …) — отрицательный пассив в настоящем:
Burada park edilmez. = Здесь стоянка запрещена.
Burada sigara içilmez. = Здесь курение запрещено.

✍️ Упражнения по грамматике

1. Какой пассивный суффикс нужен для açmak (открывать)?
Последняя гласная корня «aç»: a.
Правило: последняя гласная «a» → суффикс пассива -ıl- (ряд a/ı).
2. Образуй инфинитив пассива от kapatmak (закрывать).
Корень: kapat- (оканчивается на согласную t, последняя гласная a).
Правило: kapat- оканчивается на согласную, не l → -ıl-; kapat + ıl + mak. Также помни FSTKÇŞHP: t перед -ıl- остаётся (суффикс начинается с гласной, мутации нет).
3. Образуй инфинитив пассива от toplanmak — подожди! Этот глагол уже является пассивом/возвратным от toplamak. Образуй пассив от toplamak.
Правило: topla- оканчивается на гласную а → добавляем -n- (не -ıl-): topla + n + mak = toplanmak.
4. Поставь в прошедшее очевидное время (o, 3sg):
«Письмо было отправлено.» — Mektup ________. (göndermek → пассив → прошедшее)
Правило: gönder- → последняя гласная e → пассив -il-; gönder + il → gönderildi. Учти FSTKÇŞHP: r не в списке твёрдых, -di остаётся.
5. Как будет «Здесь нельзя курить» по-турецки? (sigara içmek)
Правило: запрет/правило выражается через отрицательную форму настоящего общего -maz/-mez: iç + il + mez = içilmez. Это стандартная конструкция для правил и запрещений.
6. Переведи: «Книга была написана известным писателем.»
(ünlü yazar = известный писатель; kitap; yazmak)
Правило: агент + tarafından + пассивная форма глагола. Yaz + ıl + dı = yazıldı. Порядок слов: Kitap [агент tarafından] yazıldı.
7. Выбери верный перевод: «Телефон сломался.»
Правило: boz + ul + du → прошедшее время. «Сломался» — завершённое действие в прошлом, -dı/-di форма. bozulmak = портиться/ломаться (пассив/непереходный).
8. Поставь в форму evidential past (miş), 3sg: «Говорят, фабрика была основана в 1920 году.»
(fabrika; kurmak; 1920'de)
Правило: kur + ul → kurulmuş. Evidential past (слышали/пересказываем) строится суффиксом -miş/-muş/-mış/-müş. После u → -muş: kurulmuş.
9. Почему пассив от söylemek — это söylenmek, а не söylelimek?
Правило: когда корень оканчивается на ГЛАСНУЮ, пассив добавляет -n- (а не -il-). söyle + n + mek. Если бы было -il-, получилось бы три согласных подряд — невозможно в турецком.
10. Переведи: «Эта проблема пока не решается.»
(bu sorun; çözmek → пассив; пока = henüz)
Правило: çöz + ül → çözül-; отрицание настоящего времени: -müyor (гласная ü после ö). Форма: çözül + mü + yor = çözülmüyor.

🧭 Мини-ревью урока

  • Два варианта пассивного суффикса: -IL- (если корень на согласную ≠ l) и -IN- (если корень на гласную или на -l). Пример: kapat → kapatılmak; söyle → söylenmek.
  • Гармония гласных в пассиве: a/ı → -ıl-/-ın-; e/i → -il-/-in-; o/u → -ul-/-un-; ö/ü → -ül-/-ün-. Последняя гласная корня управляет выбором.
  • Агент в пассиве: [существительное] + tarafından + пассивный глагол. Агент часто опускается, если неважен.
  • Запреты и правила: конструкция «здесь нельзя…» = burada … -maz/-mez (отрицательный пассив настоящего-общего): içilmez, park edilmez.
  • Главная ловушка: не добавляй -il- к корню, который уже оканчивается на -l или на гласную! Иначе получится три согласных подряд или двойной -ll-. Всегда проверяй последнюю букву корня.

Главная формула урока:

[Корень] + -IL-/-IN-/-UL-/-ÜL-/-UN-/-ÜN- + [время] + [лицо]
Пример: yaz + ıl + dı + (∅) → yazıldı (было написано)
