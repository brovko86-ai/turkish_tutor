🎯 Глагол дня

geçmek
проходить · миновать · сдавать (экзамен) · пройти (о времени)
+ Accusative (-i/-ı/-u/-ü) + Dative (-e/-a) при «переходе к чему-то» + Ablative (-den/-dan) «мимо чего-то»

Спряжение в трёх временах

Лицо Настоящее (-iyor) Прошедшее (-di) Будущее (-ecek)

⚠ DİKKAT ET! Корень geç- оканчивается на мягкий согласный ç, но при добавлении -di → ç не меняется на т (так как правило FSTKÇŞHP касается суффиксов, а не корня). Зато прошедшее время: geç + ti = geçti (согласная t суффикса — из-за ç в корне по правилу ФыСТыКЧы ШаХаП!). Обрати внимание: корень оканчивается на ç → суффикс -di превращается в -ti.

7 живых примеров с разбором

Время проходит очень быстро.

📖 Новая грамматика — Урок 35

Глаголы с управлением: geçmek, düşmek, evlenmek, ayrılmak, dolaşmak

Сегодня разбираем группу глаголов движения и изменения состояния. У каждого из них — своё падежное управление, и ошибиться тут легко. Разберём по группам.

Группа 1 · Глаголы с аблативом (-DEN/-DAN)

Эти глаголы требуют аблатива (от/из чего), потому что описывают движение прочь от исходной точки или источника.

ayrılmak → [место/человек + -DEN] ayrılmak
«расставаться с / уходить из»

düşmek → [откуда + -DEN] düşmek
«падать с / из»
Arkadaştan ayrıldım.
arkadaş + tan (аблатив, т.к. заканчивается на ş) + ayrıl + dı + m
Я расстался с другом.
Merdivenden düştü.
merdiven + den + düş + tü (т.к. ü → -tü)
Он упал с лестницы.
İstanbul'dan ayrılacak mısın?
İstanbul + dan + ayrıl + acak + mı + sın
Ты уедешь из Стамбула?

Группа 2 · Глаголы с инструменталисом (-LE/-LA)

Эти глаголы выражают совместность или партнёрство через инструментальный падеж.

evlenmek → [человек + -LE] evlenmek
«жениться на / выходить замуж за»

dolaşmak → [место + -DE] dolaşmak
«гулять по (месту)» ← тут -DE/локатив!
Komşu kızla evlendi.
komşu kız + la (инструм., после гласной -la) + evlen + di
Он женился на соседской девушке.
Şehirde dolaştık.
şehir + de (локатив) + dolaş + tı + k
Мы погуляли по городу.

Группа 3 · Глаголы с аккузативом (-İ/-I/-Ü/-U)

Переходные глаголы с прямым объектом — требуют аккузатива (определённый объект).

düzenlemek → [объект + -(y)İ] düzenlemek
«организовывать что-то»
Toplantıyı düzenledik.
toplantı + yı (аккуз., -yı т.к. после гласной) + düzenle + di + k
Мы организовали собрание.
Odayı düzenleyeyim mi?
düzenle + yeyim (предложительное, 1 л.) + mi (вопрос)
Давай я приберу в комнате?
⚠ DİKKAT ET! — evlenmek vs. evlendirmek
evlenmek — жениться (сам человек)
evlendirmek — женить кого-то (каузатив! заставить / помочь вступить в брак)
Annem beni evlendirmek istiyor. = Мама хочет меня женить.
💡 Запомни связку: düşmek ↔ düşürmek
düşmek = упасть (само)
düşürmek = уронить (кого-то/что-то) — каузатив!
Telefonu düşürdüm. = Я уронил телефон.

✍️ Упражнения по грамматике

1. Выбери правильный падеж: «Он упал со стула» (sandalye + ?)
Sandalyeden düştü.
Он упал со стула. düşmek требует аблатива (-den/-dan).
2. Вставь правильную форму: «Я расстался с работой» (iş + ayrılmak, прошедшее, 1 л.)
3. Переведи: «Мы организовали праздник» (parti = праздник, düzenlemek, прошедшее, мы)
4. Каузатив или не каузатив? «Мама женила сына» (oğul — сын, evlen-)
Annem oğlunu evlendirdi.
evlen + dir (каузатив) + di = «заставила жениться»
Мама женила сына. Каузативный суффикс -DIR превращает evlenmek в evlendirmek.
5. Переведи: «Я женился на своей знакомой» (tanıdık — слабое слово!)
6. Какое управление у dolaşmak? Выбери правильный вариант «Мы гуляли по парку»:
Parkta dolaştık.
park + ta (локатив -DE, т.к. k → FSTKÇŞHP → -ta) + dolaş + tı + k
Мы гуляли по парку. dolaşmak = гулять В месте (-DE/локатив).
7. Переведи: «Благодаря другу я нашёл работу» (используй: arkadaş, sayesinde, bulmak)
8. Как сказать «Давай я уйду» (ayrılmak, предложительное, 1 л.)? Выбери правильную форму:
Ayrılayım mı?
ayrıl + (a)yım ← гласная «а» (задний вокализм от ı)
Давай я уйду? Суффикс предложительного наклонения -AYIM/-EYIM.
9. Переведи: «Из-за усталости он упал» (yorgunluk = усталость, düşmek)
10. Составь предложение: «Экзамен прошёл, конечно» (sınav = экзамен, geçmek + tabii)

🧭 Мини-ревью урока

1. Управление = ключ к смыслу.
Один глагол, разные падежи — разный смысл. düşmek + -DEN = упасть с чего-то. Без аблатива предложение неполное.
2. Главные формулы сегодня:
[место/человек + -DEN] + ayrılmak / düşmek → движение прочь
[человек + -LE] + evlenmek → совместность
[место + -DE] + dolaşmak → нахождение в месте
[объект + -İ] + düzenlemek / geçmek → прямой объект
3. Глагол дня — geçmek.
Прошедшее: geçtim (ç → суффикс -ti по правилу ФыСТыКЧы). Будущее: geçeceğim. Смыслы: пройти, сдать, миновать, пройти о времени/боли.
4. Типичная ошибка.
❌ Arkadaşla evlendim (без посессива) — возможно, но неясно чей друг.
✅ Arkadaşımla evlendim — «Я женился на своём друге/подруге».
❌ Parktan dolaştık — неверно, park требует локатива!
✅ Parkta dolaştık
