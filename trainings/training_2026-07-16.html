⚡ Recall — быстрая проверка грамматики

[-arak/-erek] Выбери правильную форму деепричастия: «Она пришла домой, напевая песню.»
Деепричастие образа действия: глагол на гласную söyle- → söyle + -yerek (буфер y + гармония по e → erek).
[-EN/-AN причастие] Как сказать «человек, который работает здесь»?
Причастие настоящего времени от çalış-: çalış + -an (гармония по a → -an). Суффикс -EcEK — будущее, здесь не подходит.
[çünkü / -diği için] Переведи: «Я опоздал, потому что пробки.» Используй çünkü.
çünkü — союз «потому что», ставится в середине: [следствие] + çünkü + [причина]. «пробки» = trafik, «были» = vardı.
[future -EcEK] Поставь глагол в будущее время: «Мы (biz) поедем в Стамбул завтра.» (gitmek)
git- → корень-буква t (FSTKÇŞHP) → не влияет на -EcEK; git + -eceğ + -iz (1pl). Обрати внимание: -ecEK → -eceĞ перед гласной личного окончания.

🎯 Глагол дня — gerçekleştirmek

Значение: осуществлять / выполнять / претворять в жизнь
Управление: (bir şeyi) gerçekleştirmek — осуществить что-либо → требует винительного падежа (-i/-ı/-u/-ü)

💡 Состав слова: gerçek (настоящий / реальный) + -leş- (взаимно-возвратный суффикс «становиться») + -tir- (каузативный суффикс «заставить стать») + -mek (инфинитив) = «заставить стать реальным» → осуществить.

Живые примеры

Özgürlük sadece hayal değil — gerçekleştirilmesi gereken bir hak.

umut-larımız-ı = надежды наши (вин.) · gerçekleştirmek için = чтобы осуществить

📖 Новая тема — КАУЗАТИВ: «заставить / попросить / дать сделать»

Каузатив выражает идею «X заставляет/просит/побуждает Y сделать что-то». В русском — «заставить», «велеть», «попросить», «дать» + инфинитив. В турецком — специальный суффикс, который добавляется к глаголу.

Суффиксы каузатива

УсловиеСуффиксПримерПеревод
Большинство глаголов-DIr / -Tiryap → yaptır-заставить сделать
Глаголы на -l-ttopla → toplat-заставить собрать
Глаголы на -r (1 слог)-tsor → sort-*— (редко)
Некоторые длинные глаголы-ir / -erçık → çıkar-вынуть / вывести
Глаголы на -t-tirdüzelt → düzelttir-*заставить исправить

* Редкие формы — встречаются реже. Главные рабочие суффиксы: -DIr/-Tir и -t.

Стандартный каузатив: глагол-корень + (-DIr/-Tir) + время + личное окончание
yap- + -tır- + -dı + -m = yaptırdım — я заставил сделать
yaz- + -dır- + -ıyor + -um = yazdırıyorum — я заставляю писать
oku- + -t- + -tı + -m = okuttum — я заставил читать
⚠️ DİKKAT — FSTKÇŞHP: Если корень оканчивается на глухой согласный из пула F-S-T-K-Ç-Ş-H-P, суффикс -DIR становится -TIr (глухой вариант): yap → yaptır-, git → gittir-, seç → seçtir-.

Гармония гласных в -DIr/-TIr

Последняя гласная корняСуффикс каузативаПример
a, ı-dır / -tırbak → baktır-, yap → yaptır-
e, i-dir / -tiryaz → yazdır-, git → gittir-
o, u-dur / -turkoş → koştur-, dol → doldur-
ö, ü-dür / -türsöyle → söylet-, gör → gördür-

Примеры с разбором

Annem bana odayı temizlettirdi.
temizle- + -t- (на -l → суффикс -t) + -ti + -Ø(3sg) = temizletti → + -dir → temizlettirdi
Мама заставила меня убрать комнату.
Müdür raporu sekreterine yazdırdı.
yaz- + -dır- (последняя гласная a → -dır) + -dı + -Ø = yazdırdı
Директор продиктовал (заставил написать) отчёт секретарю.
Arabayı tamirciye tamir ettirdim.
tamir et- (составной глагол) + -tir- (после t → -tir) + -di + -m = tamir ettirdim
Я отдал машину в ремонт (заставил починить).
Bu projeyi ona üstlendirdik.
üstlen- + -dir- (последняя гласная e → -dir) + -di + -k = üstlendirdik
Мы возложили этот проект на него (заставили взять на себя).
Planı birlikte planlatacağız.
planla- + -t- (на гласную → -t) + -acak + -Ø + -ız = planlatacağız
Мы дадим спланировать это вместе (совместное планирование через третьих лиц).
💡 Кому «заставить»? Лицо, которое выполняет действие, ставится в дательном падеже (-e/-a) или иногда остаётся понятным из контекста: Ona yaptırdım — Я заставил его/её сделать.

Каузатив vs. Пассив (напоминание)

Пассив (-il/-in/-ul/-ün): Mektup yazıldı. — Письмо было написано. (кем — неважно)
Каузатив (-dir/-tir): Mektubu yazdırdım. — Я заставил написать письмо. (я — инициатор)

✍️ Упражнения — Каузатив

1. Образуй каузатив от глагола yaz- (писать). Какая форма правильная?
yaz- (последняя гласная a → суффикс -dır, корень на z — мягкий → -dır, не -tır). yazılmak — это пассив, не каузатив.
2. Выбери правильный каузатив от git- (идти):
git- оканчивается на t (FSTKÇŞHP) → суффикс -tir (глухой вариант), последняя гласная i → -tir. git + tir → gittirmek (удвоение t).
3. Переведи: «Я заставил прочитать эту книгу.» Глагол — okumak.
oku- (на гласную → суффикс -t) → okut- + -tu (гармония по u) + -m (1sg) = okuttum. «эту книгу» = bu kitabı (вин. пад.).
4. Выбери верную форму: «Директор велел составить план.» (planlamak, 3sg прошедшее)
planla- (корень на гласную -а → каузатив -t) → planla + t = planlatmak → прошедшее 3sg: planlatdı (FSTKÇŞHP: t → -tı → planlatı — но здесь -d после t в суффиксе: planla-t + -tı → planlatı... стандартно: planlatdı / planlatı). Правильная форма: planlatdı.
5. Переведи: «Он возложил на неё ответственность за проект.» (üstlenmek, каузатив)
üstlen- + -dir- (последняя гласная e → -dir) + -di + Ø(3sg) = üstlendirdi. «ей» = ona (дат.), «проект» = projeyi (вин.).
6. Какой суффикс нужен для каузатива от koş- (бежать)?
koş- последняя гласная o → суффикс -tur (гармония заднего ряда, огублённый). koş ∈ FSTKÇŞHP (ş глухой) → вариант -tur, не -dur.
7. Переведи: «Мы осуществим наши планы вместе.» (gerçekleştirmek, будущее 1pl)
«наши планы» = planlarımızı (вин.); gerçekleştir- + -eceğ- + -iz (1pl). Буква k → ğ перед гласным окончанием.
8. Как правильно сказать «Учитель заставил учеников написать сочинение»? (yazdırmak, прошедшее)
Исполнитель действия в каузативе — дательный падеж: öğrencilere (им, ученикам), не öğrencileri. yazdırdı = каузатив прошедшее 3sg.

🧭 Мини-ревью урока

1. Главная идея каузатива: «X заставляет / велит / просит Y сделать что-то». Инициатор — субъект предложения, исполнитель — в дательном падеже (-e/-a).
2. Главные суффиксы: -DIr/-TIr (большинство глаголов), -t (корни на -l и некоторые на гласную), -ir/-er/-ur/-ür (нерегулярные). Гармония гласных обязательна.
3. FSTKÇŞHP в каузативе: если корень оканчивается на глухой согласный → суффикс -TIr (глухой вариант), не -DIr: yap → yaptır, git → gittir, seç → seçtir.
4. Каузатив ≠ Пассив: Пассив убирает деятеля («было сделано»), каузатив добавляет организатора («заставил сделать»). Можно комбинировать: yaptırıldı — «было велено сделать» (каузатив + пассив).
5. Типичная ошибка: Исполнителя действия ставят в винительный падеж вместо дательного: ❌ öğrenciyi yazdırdı → ✅ öğrenciye yazdırdı (велел ученику написать).
6. Новые слова: itiraz etmek · planlamak · üstlenmek · gerçekleştirmek · umut · kanaat · özgürlük · eşitlik
