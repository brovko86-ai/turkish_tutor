🎯 Глагол дня: izlemek

«Смотреть / наблюдать / следить» — один из самых частотных глаголов в бытовой речи. Управление: кого/что + аккузатив (-i/-ı/-ü/-u).

izle + -(y)IL → izlenmek (быть просмотренным)
Корень: izle- (оканчивается на гласную → суффикс пассива: -n-)
Управление: birini / bir şeyi izlemek = смотреть кого-то/что-то

Спряжение в 3 временах

Лицо Настоящее (-IYOR) Прошедшее (-DI) Будущее (-EcEK)
Ben izliyorum izledim izleyeceğim
Sen izliyorsun izledin izleyeceksin
O izliyor izledi izleyecek
Biz izliyoruz izledik izleyeceğiz
Siz izliyorsunuz izlediniz izleyeceksiniz
Onlar izliyorlar izlediler izleyecekler

Примеры в контексте

Bu filmi daha önce izledim.
film-i = фильм (акк.) | izle-di-m = смотрел-прош.-я
Я уже смотрел этот фильм раньше.
Haberleri her sabah izliyoruz.
haber-ler-i = новости (акк. мн.ч.) | izli-yor-uz = смотрим
Мы смотрим новости каждое утро.
Film yarın sinemada izlenecek.
izle-n-ecek = будет просмотрен (ПАССИВ будущее)
Фильм будет показан в кино завтра. (пассив)
Seni izliyorlar! Dikkat et!
sen-i = тебя (акк.) | izli-yor-lar = следят
За тобой следят! Будь осторожен!
Maçı beraber izleyeceğiz.
maç-ı = матч (акк.) | izle-y-eceğ-iz = будем смотреть
Мы вместе посмотрим матч.
Связанные слова: izleyici = зритель | izleme = просмотр | gözetlemek = наблюдать (с надзором) — более официально
DİKKAT ET! Корень izle- оканчивается на гласную «e». Поэтому:
• Пассив: izle + -n- + yor = izleniyor (не -il-!)
• Будущее: izle + -y- + ecek = izleyecek (буферная -y-)
Правило гармонии: корневая гласная e → суффикс пассива -n (только -n, без -il)

📖 Пассив -IL/-IN/-ÜL/-UN: углублённая сессия

Сессия 2: переходим от формообразования к использованию в контексте — разные времена, агент, связка с другими конструкциями.

Краткое напоминание: как образуется пассив

Корень на согласную: корень + -IL/-IN/-ÜL/-UN
Корень на гласную: корень + -N

Гармония гласных:
Последняя гласная корня: a/ı → -IL / -IN
Последняя гласная корня: e/i → -İL / -İN
Последняя гласная корня: o/u → -UL / -UN
Последняя гласная корня: ö/ü → -ÜL / -ÜN

Пассив во всех временах

Время Активная форма (yazmak) Пассивная форма
Настоящее yazıyor yaz-ıl-ıyor
Прошедшее -DI yazdı yaz-ıl-dı
Будущее -EcEK yazacak yaz-ıl-acak
Перфект -MIŞ yazmış yaz-ıl-mış
Инфинитив yazmak yaz-ıl-mak

Агент пассивного действия: tarafından

В турецком пассиве можно указать «кем» было выполнено действие — с помощью tarafından (= «со стороны», «кем-то»).

Кем + tarafından + глагол в пассиве

Bu kitap Orhan Pamuk tarafından yazıldı.
= Эта книга написана Орханом Памуком.
Proje müdür tarafından incelendi.
incele-n-di = был изучен (корень на е → пассив -n) | müdür tarafından = директором
Проект был проверен директором.
Sözleşme her iki taraf tarafından imzalandı.
imzala-n-dı = был подписан (пассив) | sözleşme = договор | her iki taraf = обе стороны
Договор был подписан обеими сторонами.

Пассив + запрет / невозможность: -İLEMEZ

корень + -il + -e + -mez
yap-ıl-a-maz = это не может быть сделано
Bu sorun bu şekilde çözülemez.
çöz-ül-e-mez = не может быть решён | bu şekilde = таким образом
Эта проблема не может быть решена таким образом.
Bu kelime Türkçeye çevirilemez.
çevir-il-e-mez = не может быть переведено
Это слово не может быть переведено на турецкий.

Пассив глаголов-исключений

Глагол Корень Пассив Почему?
yapmak yap- yap-ıl-mak стандарт
görmek gör- gör-ül-mek ö → ül
vermek ver- ver-il-mek e → il
anlamak anla- anla-n-mak гласная → -n
söylemek söyle- söyle-n-mek гласная → -n
çalmak çal- çal-ın-mak a → ın
DİKKAT ET! Возвратные глаголы (рефлексивы) уже содержат -n- в корне: hazırlanmak (готовиться), giyinmek (одеваться). Они похожи на пассив, но НЕ являются им — субъект сам делает действие для себя. Пассив же означает, что кто-то другой воздействует на субъект.

Трансформация: активная → пассивная конструкция

АКТИВНАЯ
Müdür sözleşmeyi imzaladı. (Директор подписал договор.)
↓ объект становится подлежащим, субъект → tarafından или исчезает
ПАССИВНАЯ
Sözleşme (müdür tarafından) imzalandı. (Договор был подписан [директором].)
АКТИВНАЯ
Çocuklar filmi izliyor. (Дети смотрят фильм.)
↓
ПАССИВНАЯ
Film (çocuklar tarafından) izleniyor. (Фильм просматривается [детьми].)

🧭 Мини-ревью урока

✅ Ключевые тезисы сессии 2:
1. Пассив в разных временах:
yazılıyor (сейчас) → yazıldı (прошлое) → yazılacak (будущее) → yazılmış (перфект)
Суффикс пассива добавляется между корнем и суффиксом времени.
2. Агент: tarafından
«Кем-то» = [кем] tarafından. Необязательный элемент — можно опустить.
Anlaşma müdür tarafından imzalandı.
3. Невозможность: -İLEMEZ / -NEMEZ
Пассив + возможность: yapıl-abilir (может быть сделано)
Пассив + невозможность: yapıl-amaz (не может быть сделано)
4. Пассив vs. рефлексив:
-IL/-IN = страдательный: действие направлено НА субъект извне
-N (рефлексив) = субъект делает что-то ДЛЯ СЕБЯ
Контекст помогает различить: hazırlandı = он/она приготовился (сам)
⚠ Типичная ошибка:
❌ izle + il + iyor = ~~izleiliyor~~
✅ izle (гласная) + n + iyor = izleniyor
Корень на гласную → пассивный суффикс только -N, не -IL!
ГЛАВНАЯ ФОРМУЛА:
[корень на согл.] + -IL/-IN/-ÜL/-UN + [суффикс времени] + [личн. окончание]
[корень на гласн.] + -N + [суффикс времени] + [личн. окончание]
