Тема: -arak/-erek. Переведи: «Он пришёл, напевая» (напевать = mırıldanmak).
-arak/-erek = «делая X». Корень mırıldan- + -arak; глагол-результат в прошедшем -dI.
Тема: -deki. Как сказать «книга, которая (лежит) на столе»?
-DE (локатив) + -ki = прилагательное «тот, что там»: masa-da-ki kitap.
Тема: будущее -EcEK. Поставь в нужную форму: «Мы ответим завтра» (cevap vermek, biz).
ver- + -eceğ + -iz (biz). Буква g смягчается перед -iz: vereceğiz.
Тема: instrumental -le/-la. Выбери верное предложение: «Я еду на работу на автобусе».

🎯 Глагол дня — olmak

Самый многозначный глагол турецкого. Без него невозможно описать состояние, изменение или факт существования.

Значения и управление

olmak
1. быть / являться (состояние)
olmak
2. стать / превратиться (изменение)
olmak
3. случаться / происходить (событие)
olmak
4. быть готовым / оказаться подходящим

Управление: существительное / прилагательное без падежного суффикса → olmak.

Спряжение

Лицо-iyor (наст.)-dı (прош.)-ecek (буд.)
benoluyorumoldumolacağım
senoluyorsunoldunolacaksın
ooluyorolduolacak
bizoluyoruzoldukolacağız

onlaroluyorlaroldularolacaklar
DİKKAT ET! В будущем времени: ol + acak → olacak. Перед личным суффиксом -ım/-ız буква k → ğ: olacağım, olacağız.

Живые примеры

Doktor olmak istiyorum.
doktor + olmak + iste-iyor-um
Я хочу стать врачом.
Bugün hava çok soğuk oldu.
hava + soğuk + ol-du
Сегодня погода стала очень холодной.
Ne oldu?
ne + ol-du
Что случилось?
Bu iş yarın olacak.
bu iş + ol-acak
Это дело будет (готово/состоится) завтра.
Onur sahibi bir insan olmak zor değil.
onur + sahibi + insan + ol-mak
Быть человеком с достоинством — не сложно.
Güvensizlik olunca, kıskançlık başlar.
güvensizlik + ol-unca → когда случается недоверие
Когда возникает недоверие, начинается ревность.

Пассивная форма

ol- + -un → olunmak (использоваться в безличных конструкциях)
Буду пройдено сегодня → olundu (было сделано / случилось безлично)
СВЯЗЬ: olmak стоит в основе многих пассивных и безличных конструкций. Сегодня в теме пассива вы будете видеть его постоянно!

📖 Новая тема — ПАССИВ: суффиксы -IL / -IN / -N

Пассив (страдательный залог) показывает, что действие совершается над подлежащим, а исполнитель неизвестен или неважен. Аналог русского «быть сделанным».

Основная формула

Глагольный корень + -IL / -IN / -N + время + лицо

yazmak → yaz + -ıl → yazılmak «быть написанным»
okumak → oku + -n → okunmak «быть прочитанным»
sevmek → sev + -il → sevilmek «быть любимым»

Правила выбора суффикса

Корень оканчивается наСуффиксПримерПассив
согласную (кроме L)-IL/-İL/-UL/-ÜLyaz-yazılmak
гласную-Noku-okunmak
-L-İN/-IN/-UN/-ÜNbul-bulunmak
DİKKAT ET! Если корень оканчивается на -l, нельзя добавить ещё один -l. Используем -in/-ın/-un/-ün: bul → bulunmak (находиться / быть найденным).

Гармония гласных в суффиксе -IL

Последняя гласная корняСуффикс
a, ı-ıl
e, i-il
o, u-ul
ö, ü-ül

Примеры с декомпозицией

Bu kitap çok okundu.
oku + n + du (корень на гласную → -n; прошедшее -du)
Эта книга была много читана. / Эту книгу много читали.
Mektup bugün gönderildi.
gönder + il + di (корень на согл. r → -il; прошедшее -di)
Письмо было отправлено сегодня.
Vicdan sesi her zaman duyulur.
duy + ul + ur (корень на согл. y → -ul; аорист -ur)
Голос совести всегда слышен / слышится.
Sorun çözüldü.
çöz + ül + dü (корень на согл. z, гласная ö → -ül; прошедшее -dü)
Проблема была решена.
Onurum hiç zedelenmedi.
zedele + n + medi (корень на гласную е → -n; отрицательное прошедшее)
Моё достоинство никогда не ущемлялось.
Güven kolayca kırılır.
kır + ıl + ır (корень на согл. r, гласная ı → -ıl; аорист -ır)
Доверие легко разрушается.
СВЯЗЬ с предыдущей темой: Каузатив (уроки 57) → пассив каузатива. yazdır-mak (заставить написать) → yazdırıl-mak (быть заставленным написать). Можно «стекать» суффиксы!

✍️ Упражнения по грамматике

1. Образуй пассив: yazmak → ?
Корень yaz- оканчивается на z (согласная, не l). Последняя гласная a → суффикс -ıl.
2. Образуй пассив: bulmak → ?
Корень bul- оканчивается на -l. Нельзя добавить ещё один l → используем -un (гласная u).
3. Переведи в пассив прошедшего времени: «Письмо было написано» (mektup, yazmak).
yaz + -ıl + -dı. Подлежащее «письмо» — именительный падеж, объектный суффикс не нужен.
4. Вставь правильную форму: «Посылка будет отправлена завтра» (paket, göndermek, будущее).
gönder + -il (согл. r, гласная e → -il) + -ecek (будущее). Нет личного суффикса = 3 лицо ед.ч.
5. Образуй пассив: söylemek → ?
Корень söyle- оканчивается на гласную е → суффикс -n. söyle + n = söylenmek.
6. Выбери правильную пассивную форму от görmek (видеть):
gör + -ül (гласная ö → -ül) + -dü (прошедшее). Форма 3 лица ед.ч. — без личного суффикса.
7. Переведи: «Голос совести был услышан» (vicdan sesi, duymak).
duy + -ul (гласная u → -ul) + -du. vicdan sesi = «голос совести» — именной оборот с посессивом.
8. Составь предложение: «Проблема ревности не решается быстро» (kıskançlık sorunu, çözmek, отрицание пассива, наст. вр.).
Пассив + отрицание настоящего: çözül + -m + üyor. Время — настоящее (не прошедшее и не причастное).

🎨 Свободная продукция

Напиши 4–5 предложений о ситуации, когда доверие или совесть «проявляются» в жизни. Используй пассивные глаголы и новые слова из сегодняшней тренировки.

Опорные слова: güven (доверие), vicdan (совесть), onur (честь), kıskançlık (ревность), olmak (быть/стать), yaşamak (жить), bitmek (заканчиваться), hissetmek (чувствовать), nihayet (наконец-то), geliştirmek (развивать)

Шаблон: «Güven bir kez kırılınca, [пассив + время]. Vicdan sesi [глагол-пассив]. Kıskançlık [действие]. Nihayet, ...»

Пример:
Güven bir kez kırılınca, kolay kolay yeniden kurulmaz. Vicdan sesi her zaman duyulur, ama bazen görmezden gelinir. Kıskançlık hissedildiğinde, onur zarar görür. Nihayet, güven geliştirilerek ilişki düzeltildi. Yaşamak demek vicdan sahibi olmak demektir.

Разбор: kurulmaz (kur+ul+maz — не строится), duyulur (duy+ul+ur — слышится), gelinir (gel+in+ir — игнорируется безлично), hissedildiğinde (hisset+il+diği+nde — когда ощущается), görür (видит, причиняет).

🧭 Мини-ревью урока

  • Пассив в турецком = суффикс -IL/-İL/-UL/-ÜL (корень на согласную, не -l), -N (корень на гласную), -IN/-UN/-ÜN/-IN (корень на -l).
  • Гармония гласных: последняя гласная корня определяет вариант суффикса (a/ı → -ıl, e/i → -il, o/u → -ul, ö/ü → -ül).
  • Главная формула: корень + пассивный суффикс + суффикс времени + личное окончание.
  • Типичная ошибка: добавлять -ıl/-il к корню на -l (bul + *-ul-ul → неверно! → bulunmak).
  • Связь с новой лексикой: güven kırılır (доверие разрушается), vicdan duyulur (совесть слышится), onur zedelenir (достоинство ущемляется) — пассив делает речь богаче и точнее.
