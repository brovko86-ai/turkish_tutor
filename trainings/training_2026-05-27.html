🎯 Глагол дня — değiştirmek

Менять / изменять (что-то) — один из самых частотных глаголов в повседневной турецкой речи

Базовая информация

değiştirmek   →   менять / изменять (что-то) Управление: -i/-ı/-u/-ü (винительный — объект меняется) Корень: değiş- + каузативный суффикс -tir + -mek (değişmek = меняться само → değiştirmek = менять что-то) Гармония гласных: последняя гласная корня i → суффикс -tir

Спряжение в трёх временах

Лицо-(i)yor (наст.)-di (прошед.)-(y)ecek (будущ.)
bendeğiştiriyorumdeğiştirdimdeğiştireceğim
sendeğiştiriyorsundeğiştirdindeğiştireceksin
odeğiştiriyordeğiştirdideğiştirecek
bizdeğiştiriyoruzdeğiştirdikdeğiştireceğiz
sizdeğiştiriyorsunuzdeğiştirdinizdeğiştireceksiniz

renk+i = цвет+вин. | di вопр. mi

Связанные слова

değişmek — меняться (само собой) → Hava değişiyor. Погода меняется.
değişiklik — изменение (существительное) → Büyük bir değişiklik. Большое изменение.
değişken — переменчивый / изменчивый
Каузатив: değiş-tirmek = «заставить измениться» = изменить что-то. Это ключевой образец каузатива -tir — учим его сегодня!
DİKKAT ET! değiştir + ecek = değiştirecek, но в письме — değiştireceğim (смягчение k→ğ перед гласным суффиксом). Это стандартное правило: любое слово на -k перед гласным суффиксом → -ğ.

📖 Новая грамматика — Каузатив -DIr / -t / -İr / -Ar

Каузатив («заставительный залог») отвечает на вопрос: кто заставил, велел, дал возможность кому-то что-то сделать?
По-русски часто переводится «заставить», «велеть», «дать», «сделать так, чтобы».

Формула

Инфинитив без -mek/-mak = корень Корень + КАУЗАТИВНЫЙ СУФФИКС + обычные суффиксы времени/лица Кто? = субъект (делает другому) Кому? = агент (тот, кого заставляют) → стоит в дативе (-e/-a) Что? = объект → винительный (-i/-ı/-u/-ü)

Какой суффикс выбрать?

СуффиксКогда используетсяПримеры
-DIr Большинство глаголов (2+ слога или заканчивается на согласный) yap → yaptır, iç → içir, git → gittiр
-t Односложные глаголы на гласную + двусложные на -l, -r, -n ye → yetir*, oku → okut, bekle → beklet
-İr / -Ar Нерегулярные (надо запомнить) çık → çıkar, gör → göster*, bil → bildir
Главное правило для начала: если не уверен — ставь -DIr. В 80% случаев это будет верно. Нерегулярные формы запоминаются со временем.

Гармония гласных в -DIr

Последняя гласная корняСуффиксПример
e, i-dirdeğiş → değiştir, iç → içir
a, ı-dıryap → yaptır, bak → baktır
o, u-durkoş → koştur, dol → doldur
ö, ü-dürgöç → göçtür, öl → öldür
DİKKAT ET! После глухих согласных (FSTKÇŞHP) -d- → -t-:
yap + tır = yaptır ✓ (а не *yapdır)
iç + ir = içir ✓ (здесь корень заканчивается на ç — глухой → -t, но суффикс краткий)

5 живых примеров

Annesi ona ödevi yaptırdı.
yap + tır (кауз.) + dı (прош.) | ana → ана заставила
Мама заставила его сделать домашнее задание.
Arabayı boyatacağım.
boya + t (кауз.) + acak + ım | boyamak = красить → boyatmak = заставить покрасить
Я отдам машину покрасить (закажу покраску).
Müdür raporu bize okuttu.
oku + t (кауз.) + tu | bize = нам (дат)
Директор заставил нас прочитать доклад.
Bilgisayarı çalıştıramazsın.
çalış + tır + ama + z + sın | невозможность
Ты не сможешь запустить компьютер.
Formu doldurun, lütfen.
doldur (уже каузатив от dolmak) + un | повелит. 2мн
Заполните форму, пожалуйста. (dolmak → doldurmak — каузатив лексикализован)
Интересно: Многие турецкие глаголы — это уже «замороженный» каузатив: doldurmak (заполнять = делать полным), çalıştırmak (запускать = заставлять работать), değiştirmek (менять = заставлять меняться). Когда видишь -tır/-tir/-tur/-tür в основе глагола — это след каузатива!

✍️ Упражнения по грамматике

1. Какой каузатив от yazmak (писать)?
💡 yaz- → последняя гласная a → суффикс -dır (корень на согласный z, не глухой) → yazdırmak
2. Какой каузатив от okumak (читать)?
💡 oku- → двусложный, оканчивается на гласную → суффикс -t → okutmak
3. Переведи фразу: «Она велела нам ждать.»
beklemek → каузатив bekletmek; bize = нам (дат); прошедшее время
4. Выбери правильный каузатив от dolmak (наполняться):
💡 dol- → последняя гласная o → -dur → doldurmak ✓
5. Какой суффикс у глагола boyamak (красить) → каузатив?
Корень: boya- | последняя гласная?
💡 boya- → двусложный, оканчивается на гласную а → -t → boyatmak
6. Переведи: «Я запущу (включу) машину.»
çalıştırmak; araba + Acc; будущее время, 1ед
7. Что означает конструкция «Bana söyletme!»?
söylemek → каузатив söyletmek; bana = мне (дат); -me = запрет
💡 söylet + me = отрицательный императив от каузатива. «Не заставляй меня это произносить!» — частая живая фраза.
8. Поставь нужный суффикс: «Bu formu doldur____» (прошедшее, он)
doldurmak + -du/-di/-tu/-ti (прошед.)? Корень: dolduR — глухой R? Нет. Последняя — r, звонкий → -du
💡 doldurmak → корень doldur- → последняя гласная u → -du (r — звонкий) → doldurdu
9. Переведи всю фразу: «Учитель попросил детей читать эту книгу.»
öğretmen; çocuklar → çocuklara (дат.); bu kitabı (вин.); okutmak; прошедшее

🧭 Мини-ревью урока

1
Каузатив = «заставить/велеть/дать сделать». Формула: корень + -DIr/-t/-İr/-Ar + обычные суффиксы.
Гармония: e/i → -dir, a/ı → -dır, o/u → -dur, ö/ü → -dür. После глухих согласных d→t.
2
Агент каузатива — в дативе. «Кого заставляют» стоит в форме -e/-a:
Müdür bize raporu okuttu. — Директор заставил нас читать доклад.
3
Суффикс -t — для глаголов на гласную (двусложных): oku→okut, boya→boyat, bekle→beklet.
Суффикс -DIr — для большинства остальных: yap→yaptır, yaz→yazdır, değiş→değiştir.
4
Типичная ошибка: забыть согласование гласных или поставить -d- после глухого согласного.
❌ yapdırmak → ✅ yaptırmak (yap- оканчивается на p — глухой!)
5
Главная формула урока:
[Субъект] + [Агент-Dat] + [Объект-Acc] + [Корень + -DIr/-t + время + лицо]
Annem bana odayı temizletti. — Мама заставила меня убрать комнату.
