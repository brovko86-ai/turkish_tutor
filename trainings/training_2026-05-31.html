🎯 Глагол дня

hatırlamak новый
вспоминать / помнить
управление: hatırlamak + кого/что (винительный -ı/-i/-u/-ü)

Корень: hatırla- — от hatır «память, воспоминание». Гласная основы: a → группа a/ı → суффиксы с «а» и «ı».

Спряжение в трёх временах

Лицо Наст. (-ıyor) Прош. (-dı) Буд. (-acak)
Benhatırlıyorumhatırladımhatırlayacağım
Senhatırlıyorsunhatırladınhatırlayacaksın
Ohatırlıyorhatırladıhatırlayacak
Bizhatırlıyoruzhatırladıkhatırlayacağız
Sizhatırlıyorsunuzhatırladınızhatırlayacaksınız
Onlarhatırlıyorlarhatırladılarhatırlayacaklar
DİKKAT ET! Перед суффиксом -(ı)yor конечная «a» основы отпадает: hatırla- + ıyor → hatırlıyor (не hatırlaıyor). Это стандартное правило для основ на -a/-e.

Живые примеры

Onun adını hatırlamıyorum.
hatırla-mıyor-um = вспоминать-НЕ-я
Я не помню его имени.
Çocukluğunu hatırladı mı?
hatırla-dı mı = вспомнил ли?
Он вспомнил своё детство?
Seni her zaman hatırlayacağım.
hatırla-y-acağ-ım = буду помнить тебя всегда
Я всегда буду тебя помнить.
Anahtarımı nereye koyduğumu hatırlamıyorum.
koyduğumu = куда я положил (косв. речь)
Я не помню, куда положил ключ.
Beni hatırlıyor musun?
hatırlı-yor mu-sun = помнишь ли меня
Ты меня помнишь?
Однокоренные слова:
hatır — память, воспоминание; уважение (к кому-то)
hatıra — воспоминание / сувенир
hatırlatmak — напоминать (каузатив от hatırlamak!)
hatırlama — воспоминание (отглагольное существительное)

📖 Новая грамматика — Каузатив: суффикс -DIR / -T / -IT / -ÜT

Каузатив — это конструкция «заставить кого-то сделать что-то» или «дать кому-то сделать». По-русски: «я заставил его написать», «она покрасила стену (наняв маляра)».

Формула

Глагол (корень) + -dir/-dır/-dur/-dür + личный суффикс

yazmak → yaz + -dır → yazdırmak → «заставить написать»
okumak → oku + -t → okutmak → «заставить читать»
yıkamak → yıka + -t → yıkatmak → «заставить помыть»

Какой суффикс выбрать?

Суффикс Когда используется Примеры
-dir/-dır/-dur/-dür Основной вариант для большинства глаголов (корень на согласный) yaz→yazdır, giy→giydир, dön→döndür
-t Глаголы с основой на гласную (oku-, yıka-, ağla-...) oku→okut, yıka→yıkat, ağla→ağlat
-ıt/-it/-ut/-üt Некоторые односложные глаголы на согласный (кор. 1 слог) uç→uçurt, bat→batır(≠), iç→içir
-ir/-ır/-ur/-ür Отдельные глаголы (запомни как исключения) iç→içir («напоить»), geç→geçir («проводить»)
DİKKAT ET! FSTKÇŞHP: после твёрдых согласных суффикс озвончается: -tır/-tir → но само слово ПЕРЕД суффиксом не изменяется. Пример: koş (ş — твёрдый) → koş-tur (заставить бегать).

Кто «исполнитель» действия?

Субъект-каузатор + объект (-e/-a дат. или -e) + каузативный глагол

Anne çocuğa resim çizdirdi. — Мама заставила ребёнка нарисовать рисунок.
Müdür raporu sekretere yazdırdı. — Директор велел секретарю написать отчёт.

Примеры с декомпозицией

Öğretmen öğrencilere metni okuttu.
oku + t + tu = читать + кауз. + прош.
Учитель заставил учеников прочитать текст.
Anneme saçımı taratıyorum.
tara + t + ıyor + um = расчёсывать + кауз. + наст. + я
Я даю маме расчёсывать мне волосы. / Мама расчёсывает мне волосы.
Bu film beni ağlattı.
ağla + t + tı = плакать + кауз. + прош.
Этот фильм заставил меня плакать.
Arabamı yıkattım.
yıka + t + tım = мыть + кауз. + прош. + я
Я помыл машину (велел / на автомойке).
Çocuğu güldürdüm.
gül + dür + düm = смеяться + кауз. + прош. + я
Я рассмешил ребёнка.
Patronum bana fazla mesai yaptırdı.
yap + tır + dı = делать + кауз. + прош.
Шеф заставил меня сделать сверхурочную работу.
Лайфхак: Каузатив часто используется, когда ты платишь или просишь кого-то выполнить услугу. Saçımı kestirdim = «Я постриг(ла) волосы» (в парикмахерской). Elbisemi diktirdim = «Я сшила платье» (у портного).

🧭 Мини-ревью урока

  • Каузатив выражает «заставить / велеть / дать кому-то сделать». Английский аналог: causative.
  • Основной суффикс — -dir/-dır/-dur/-dür для глаголов с основой на согласный: yaz → yazdır.
  • Суффикс -t — для основ на гласную: oku → okut, yıka → yıkat.
  • Помни FSTKÇŞHP: после твёрдых согласных -d → -t: koş → koştur.
  • Исполнитель действия ставится в дательный падеж (-e/-a): Müdür sekreterE yazdırdı.
Типичная ошибка: Смешать каузатив с пассивом. Yazdırıldı = «было велено написать» (пассив + кауз.), а Yazdırdı = «он велел написать». Разные суффиксы, разные смыслы!
