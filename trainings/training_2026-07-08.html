📖 Страдательный залог — суффикс -IL/-IN

Страдательный залог (пассив) превращает «кто-то делает что-то» в «что-то делается / сделано». В русском — это форма на -ся/-сь или «быть сделанным».
В турецком для этого служит суффикс -IL / -IN, который присоединяется к корню глагола.

Активный: özne + nesne + fiil
   Mehmet mektubu yazdı. → Мехмет написал письмо.

Пассивный: nesne + fiil-IL/-IN + tense
   Mektup yazıldı. → Письмо было написано.

Как присоединяется суффикс пассива

УсловиеСуффикс пассиваПример
Корень на согласный (не -l) -IL / -İL / -UL / -ÜL yazılmak, satılmak, bulunmak*
Корень оканчивается на -l -IN / -İN / -UN / -ÜN silinmek, bilinmek, bulunmak
Корень на гласный -N söylenmek, anlanmak
💡 Гармония гласных в -IL:
Последняя гласная корня a/ı → -ıl: yaz → yazıl
Последняя гласная корня e/i → -il: sev → sevil
Последняя гласная корня o/u → -ul: boz → bozul
Последняя гласная корня ö/ü → -ül: gör → görül
DİKKAT! Если корень оканчивается на -l, добавляем -in/-ın/-un/-ün, а не -il (иначе получится три буквы lll). Пример: sil → silinmek ✓ (а не silil — такого нет!).

Спряжение пассива во временах

После пассивного суффикса добавляем стандартные временны́е суффиксы:

ВремяФормулаПример (yazmak → писать)
Настоящее -ıl + -ıyor Mektup yazılıyor. — Письмо пишется.
Прошедшее -ıl + -dı Mektup yazıldı. — Письмо было написано.
Будущее -ıl + -acak Mektup yazılacak. — Письмо будет написано.
Долженствование -ıl + -malı Mektup yazılmalı. — Письмо должно быть написано.

Деятель в пассивном предложении

Если нужно указать, кем совершено действие, используем суффикс -tarafından («со стороны кого-то») или просто притяжательный оборот:

Bu kitap Orhan Pamuk tarafından yazıldı.
tarafından = «со стороны / кем» (агент пассива)
Эта книга была написана Орханом Памуком.

1. Выбери правильную пассивную форму глагола görmek (видеть):

2. Образуй пассивную форму (инфинитив) от глагола satmak (продавать):

💡 tamamlan- = пассив от tamamlamak (завершать). -dı = прошедшее.
4. Переведи в пассив прошедшего времени: «Документы были изучены» (belge = документ, мн.ч. = belgeler):

💡 incele- заканчивается на гласный -e → пассив через -n → incelendi (прош. врем.).
5. Как сказать «Письмо было написано директором»?
💡 Агент пассива обозначается через [имя] + tarafından («со стороны»).
6. «Граница будет защищена» — переведи на турецкий (sınır = граница):

💡 koru- оканчивается на гласный -u → пассив -n → korun- + будущее -acak (гласн. u → -acak).
7. Какое предложение грамматически правильное?
💡 gözlemle- + -n (пассив от гласной основы) + -iyor = gözlemleniyor.
8. Переведи в пассив: «Öğretmen tahtayı sildi» → «Доска была вытерта» (tahta = доска, silmek = вытирать):

💡 sil- оканчивается на -l → пассив через -in (не -il!) → silin- + -di.
9. Пассив от bilmek (знать) — какая форма правильная?
💡 bil- оканчивается на -l → правило: суффикс пассива -in (не -il). bil + in = bilin-.
10. «Новость уже слышна / была услышана» (haber = новость, duymak = слышать):
Используй прошедшее время пассива.

💡 duy- → согласный на конце, последняя гласная u → пассив -ul → duyul- + -du.

🧭 Мини-ревью урока

1. Главная формула пассива:
Корень + -IL / -IN / -N + временной суффикс
yaz → yazılmak · sil → silinmek · söyle → söylenmek
2. Гармония гласных в -IL:
a/ı → -ıl  |  e/i → -il  |  o/u → -ul  |  ö/ü → -ül
3. Правило -l на конце корня:
Если корень заканчивается на -l → суффикс пассива -in/-ın/-un/-ün (не -il!)
bil → bilin · sil → silin · bul → bulun
4. Агент пассива:
Кем выполнено действие — обозначаем через tarafından:
Bu roman Tolstoy tarafından yazıldı.
Типичная ошибка: смешать пассив (-il) и рефлексив (-in). Формально похожи, но значение разное! «silindi» = «было вытерто» (пассив — кто-то вытер). В контексте важно понимать: пассив убирает деятеля или переносит фокус на объект.
✅ Итог сессии: сегодня ты разобрал страдательный залог (пассив). В следующей сессии: практика более сложных форм пассива — пассив + модальность (-abil- + -il), пассив в отрицании, и закрепление через перевод целых абзацев.
