⚡ Recall — быстрая проверка слабые темы

Тема: -arak/-erek · Выбери правильную форму деепричастия от koşmak (бежать).
Гармония гласных: последняя гласная корня «o» → задний ряд → -arak (не -erek).
Тема: -deki · Переведи: «книга, лежащая на столе».
-deki = локатив -da + суффикс -ki, образующий относительное прилагательное «тот, что на/в».
Тема: instrumental -le/-la · Как сказать «с поездом» (tren)?
Инструментальный падеж «с/на (транспорте)»: -la/-le (гармония гласных по последней гласной слова).

🎯 Глагол дня — seyretmek

seyretmek — смотреть / наблюдать (за чем-то). Управление: прямое дополнение в винительном падеже (-i/-ı/-u/-ü) для определённого объекта.

seyret- + время + личное окончание
Корень оканчивается на t (FSTKÇŞHP!) → суффикс прошедшего -ti, не -di

DİKKAT ET! Корень seyret-: перед гласными суффиксами конечная t озвончается в d → seyrediyor, seyredecek. Но перед согласными остаётся t → seyretti. Это стандартное FSTKÇŞHP-поведение.

Живые примеры

Dün akşam neşeli bir film seyrettim.
seyret + ti + m → прошедшее 1л. ед.ч.
Вчера вечером я смотрел весёлый фильм.
Sinirli insanlar genellikle sakin insanları seyreder.
geniş zaman → seyret + er (широкое настоящее)
Раздражительные люди обычно наблюдают за спокойными.

seyreded + ecek + sin + mi? → будущее вопрос 2л. ед.ч.
Ты будешь смотреть матч?
Takım yenildiğinde öfkeyle seyrediyorduk.
seyret-iyor + d + uk → прошедшее продолженное 1л. мн.ч.
Когда команда проигрывала, мы смотрели со злостью.
Bu belgesel iki kez seyredildi.
seyret + il (пассив) + di → прошедшее пассив 3л.
Этот документальный фильм смотрели дважды.
Связанные слова: seyir (просмотр, ход событий) · seyirci (зритель) · seyahat (путешествие, схожий корень по значению «наблюдать мир»).

📖 Новая грамматика — ПАССИВ: суффиксы -IL / -IN / -ÜL / -UN

Пассивный залог показывает, что действие совершается над подлежащим, а не самим подлежащим. По-русски — «дом построен», «письмо было отправлено».

Формула образования пассива

Корень глагола + -IL / -IN / -ÜL / -UN + (время) + (личное окончание)

Правило выбора суффикса:
• Корень оканчивается на согласную (не l) → добавляем -IL/-IN/-ÜL/-UN (по гармонии)
• Корень оканчивается на -l → добавляем -IN/-ÜN/-AN/-EN (избегаем ll)
• Корень оканчивается на гласную → добавляем -N

Таблица гармонии гласных пассивного суффикса

Последняя гласная корняСуффикс пассиваПример
a, ı-ılyap → yapılmak (быть сделанным)
e, i-ilsev → sevilmek (быть любимым)
o, u-ulgör → görülmek... нет: ö→ -ül; o/u→ -ul
ö, ü-ülgör → görülmek (быть увиденным)
Корень на -l-in/-ın/-ün/-unbil → bilinmek (быть известным)
Корень на гласную-noku → okunmak (читаться)

Примеры с разбором

Mektup gönderildi.
gönder + il (пассив, e→il) + di (прошедшее) → 3л. ед.ч.
Письмо было отправлено.
Bu kitap çok okunuyor.
oku + n (пассив, корень на гласную) + uyor → настоящее 3л.
Эту книгу много читают / эта книга много читается.
Ev yapılacak.
yap + ıl (пассив, a→ıl) + acak → будущее 3л.
Дом будет построен.
Sesi uzaktan duyuldu.
duy + ul (пассив, u→ul) + du → прошедшее 3л.
Его голос был слышен издалека.
Takım yenildi.
yen + il (пассив, e→il) + di → прошедшее 3л.
Команда была побеждена / потерпела поражение.
DİKKAT ET! «Кем» совершено действие в пассиве — добавляй tarafından: Kapı polis tarafından açıldı — Дверь была открыта полицией. Можно также -dan/-den: polisten, но это разговорнее.
Связь с предыдущей темой (каузатив): можно совмещать пассив и каузатив! anlatttır-... нет: anlat + tır (кауз.) + ıl (пасс.) = anlattırıl- → «быть заставленным рассказать». Это сложная, но реальная форма.

✍️ Упражнения по грамматике — пассив

1. Образуй пассивный инфинитив от açmak (открывать). Какой суффикс?
Последняя гласная корня «a» → пассивный суффикс -ıl; корень оканчивается на согласную ç.
2. Образуй пассивный инфинитив от söndürmek (гасить). Помни: каузативный корень söndür- оканчивается на r → пассив?
Последняя гласная «ü» → пассивный суффикс -ül; корень не оканчивается на -l, поэтому используем -ül, не -ün.
3. Переведи: «Решение было принято.» (karar vermek → karar verilmek)
ver + il (пассив, e→il) + di (прошедшее) → 3-е лицо ед.ч. «karar» — подлежащее.
4. Какой пассив правильный для bilmek (знать)? Корень bil- оканчивается на l!
Корень на -l → избегаем двойного «ll», поэтому вместо -il используем -in (гласная «i» по гармонии).
5. Переведи: «Фильм будет снят (çekmek).»
çek + il (пассив, e→il) + ecek (будущее) → 3-е лицо ед.ч.
6. «Эту песню слышно отовсюду» — выбери правильный пассив от duymak.
«Слышно» = продолженное действие сейчас → настоящее время -yor; duy + ul (пассив, u→ul) + uyor.
7. Добавь «tarafından» — кем: «Книга была написана Орханом Памуком.»
yaz + ıl (пассив, a→ıl) + dı (прошедшее); деятель → «Orhan Pamuk tarafından».
8. «Новость была услышана» — от duymak, прошедшее время.
Прошедшее пассива: корень + пассив-суффикс + -dı/-di/-du/-dü по гармонии.

🧭 Мини-ревью — урок 60

  • Пассив в турецком образуется суффиксом -IL/-IN/-ÜL/-UN (по гармонии гласных) или -N (если корень на гласную).
  • Корень на -l → избегаем ll → используем -in/-ın/-ün/-un: bil → bilinmek.
  • После пассивного суффикса добавляются обычные временные формы: gönderil + di, yapıl + acak, okunuyor.
  • «Кем» совершено действие → конструкция tarafından (tarafından = со стороны): polis tarafından.
  • Новые слова дня: yenilmek, seyretmek, ulaşmak, varmak, sinirli, sakin, neşeli, öfke.
