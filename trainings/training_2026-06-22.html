🎯 Тема: -ARAK / -EREK («делая что-то / посредством»)

Выбери правильную форму деепричастия -arak/-erek для глагола koşmak (бежать):
«Он пришёл ___ (бегом).»
💡 Правило: последняя гласная корня a/ı/o/u → -arak; e/i/ö/ü → -erek. В koşmak последняя гласная — o → -arak.
Переведи предложение с деепричастием -erek:
«Она объяснила задание, говоря медленно.»
(задание = ödevi; медленно говоря = yavaş konuşarak / yavaşça konuşarak)

💡 Порядок: наречие + деепричастие (konuşarak) + объект + глагол. «Объяснила» = açıkladı (прошедшее от açıklamak).

🎯 Тема: -DEKİ («который находится в/на»)

Переведи: «Книга, лежащая на столе, моя.» Используй суффикс -deki.
(стол = masa; книга = kitap; моя = benim / benimki)
💡 -deki = -de (местный падеж «на/в») + -ki (суффикс «который там»). Masa + -da + -ki = masadaki («тот, что на столе»).

🎯 Тема: Будущее время -(y)EcEK

Поставь глагол gelmek в форму будущего времени для «они» (onlar):
«Они придут завтра.»
💡 Будущее -(y)EcEK: корень + -ecek/-acak + личное окончание. Для onlar: -ler/-lar. gel + ecek + ler = gelecekler.

🎯 Тема: Орудный падеж -LE / -LA

Переведи: «Я еду в Анкару на поезде.»
(Анкара = Ankara; поезд = tren)

💡 Орудный падеж транспорта: tren + -le = trenle (последняя гласная e → -le); Ankara → Ankara'ya (дательный, направление).

📖 Новая грамматика: Пассивный залог -IL/-IN/-UL/-ÜN

Пассивный залог в турецком — это когда действие совершается над кем-то, а не кем-то. Аналог русского «строится», «было сделано», «читается». Субъект либо неважен, либо выражается через tarafından (кем/чем).

Формула

Корень глагола + -IL / -IN / -UL / -ÜN + время + личное окончание

Гармония гласных: корень с задними гласными (a, ı, o, u) → -IL → -ıl корень с передними гласными (e, i, ö, ü) → -IL → -il корень на -o/-u → -ul корень на -ö/-ü → -ül

Если глагол уже оканчивается на гласную → вставляется -n-: oku- + n + ur = okunur (читается) söyle- + n + ir = söylenir (говорится)

Таблица суффиксов по гармонии

Последняя гласная корняПассивный суффиксПример
a, ı-ılyaz- → yazılmak (быть написанным)
e, i-ilsev- → sevilmek (быть любимым)
o, u-ulbul- → bululmak → правильно: bulunmak*
ö, ü-ülgör- → görülmek (быть увиденным)
оканчивается на гласную-noku- → okunmak (читаться)

*Особый случай: bulmak → bulunmak (для благозвучия, -ul+ul избегается).

💡 Связь с каузативом (вчерашняя тема): суффиксы часто комбинируются!
yapmak → yaptırmak (заставить сделать) → yaptırılmak (быть принуждённым к действию)
«Ev boyatıldı» — Дом был покрашен (кем-то).

Пассив в разных временах

На примере глагола yazmak → yazılmak (быть написанным)

Кем совершается действие? → tarafından

Деятель + tarafından + пассивный глагол
Bu köprü mühendisler tarafından inşa edildi. → Этот мост был построен инженерами.

Примеры с декомпозицией

Bu kitap Türkçeye çevrildi.
çevir- (переводить) + -il (пассив, последняя гласная i) + -di (прошедшее)
Эта книга была переведена на турецкий язык.
Toplantı yarın yapılacak.
yap- (делать) + -ıl (пассив, последняя гласная a) + -acak (будущее)
Встреча состоится завтра (будет проведена).
Kapı açıldı ama kimse girmedi.
aç- + -ıl + -dı (прошедшее) → açıldı (была открыта)
Дверь открылась, но никто не вошёл.
Bu şarkı herkesçe seviliyor.
sev- + -il (пассив, последняя гласная e) + -iyor; herkesçe = всеми
Эту песню любят все / она всеми любима.
Sözleşme imzalanacak mı?
imzala- (подписывать, оканчивается на гласную -a) + -n (пассив для глаголов на гласную) + -acak + mı
Контракт будет подписан?
Haber bana geç söylendi.
söyle- + -n + -di; bana (мне); geç (поздно)
Новость мне сообщили поздно (была сказана поздно).
⚠ DİKKAT ET! Не путай пассив с рефлексивом (-in/-ın/-un/-ün «делать себе»)!
yıkamak (мыть) → yıkanmak (мыться — рефлексив, «мыть себя»)
yıkamak → yıkanmak — здесь же форма похожа! Контекст решает всё.

✍️ Упражнения по пассивному залогу

1. Образуй пассивную форму инфинитива

Образуй пассивный инфинитив от okumak (читать):

💡 Корень oku- оканчивается на гласную -u, поэтому пассивный суффикс — -n (не -ul). Добавь -mak.
Образуй пассивный инфинитив от görmek (видеть):

💡 Корень gör-, последняя гласная ö → суффикс пассива -ül. Добавь -mek.
Образуй пассивный инфинитив от bulmak (находить):

💡 Корень bul-, последняя гласная u. Технически -ul, но два -ul подряд (bul-ul) — неблагозвучно, поэтому используется -un: bulunmak.

2. Поставь пассивную форму в нужное время

Переведи: «Эта дверь всегда открыта (открывается).»
Используй пассив от açmak в широком времени (-r/-ir).
💡 Широкое время (аорист) -ır/-ir/-ur/-ür передаёт «вообще происходит, обычно». açıl- + -ır = açılır.
Переведи: «Контракт будет подписан в пятницу.»
sözleşme = контракт; Cuma = пятница; imzalamak = подписывать

💡 imzala- + -n (пассив для глаголов на гласную) + -acak (будущее). Порядок: подлежащее + время + глагол.
Переведи: «Новость была услышана всеми.»
haber = новость; duymak = слышать; herkes = все → herkesçe (всеми)

💡 duy- (слышать), последняя гласная u → пассив -ul, но duy-ul → благозвучно. Прошедшее: duyuldu.

3. Найди ошибку

В этом предложении есть ошибка в пассивной форме. Найди и исправь:
«Bu proje geçen yıl tamamlanıldı.»
(tamamlamak = завершать)
💡 tamamla- оканчивается на гласную -a, значит пассив -n: tamamlan-. Прошедшее: tamamlandı. Двойной суффикс -n-ıl здесь лишний.
Переведи активное предложение в пассивное:
Активное: Öğretmen soruyu cevapladı. (Учитель ответил на вопрос.)
Пассивное: «Вопрос был отвечен...»
soru = вопрос; cevaplamak = отвечать

💡 cevapla- + -n (пассив, глагол на гласную) + -dı (прошедшее). Деятель выражается через tarafından: öğretmen tarafından.

4. Переведи на турецкий

«В этом ресторане готовят очень вкусную еду.»
(ресторан = restoran; вкусная еда = lezzetli yemek; готовить = pişirmek)

💡 pişir- + -il (пассив, последняя гласная i) + -ir (широкое время = «вообще готовят»). Место: restoran + -da.
«Этот фильм был снят в Стамбуле.»
(фильм = film; снять/снимать фильм = çekmek; Стамбул = İstanbul; в = -de)

💡 çek- + -il (пассив, последняя гласная e → -il) + -di (прошедшее). İstanbul + -da (FSTKÇŞHP: l — не твёрдая, поэтому -da, не -ta).

🧭 Мини-ревью урока 48

  • Пассивный залог выражает, что действие происходит над чем-то, а деятель неважен или неизвестен: Kitap okundu — Книга была прочитана.
  • Суффикс по гармонии: a/ı → -ıl, e/i → -il, o/u → -ul, ö/ü → -ül; глагол на гласную → -n.
  • Деятель (если нужен) выражается через tarafından: mühendisler tarafından inşa edildi — было построено инженерами.
  • Типичная ошибка: не путай пассив (-il/-ıl) с рефлексивом (-in/-ın). Контекст и значение глагола подскажут нужное.
  • Комбо с каузативом: yapmak → yaptırmak (каузатив) → yaptırılmak (пассив каузатива) — «быть принуждённым сделать».
АКТИВНЫЙ: Anne çorba pişirdi. → Мама сварила суп. ПАССИВНЫЙ: Çorba pişirildi. → Суп был сварен. С ДЕЯТЕЛЕМ: Çorba anne tarafından pişirildi.
