⚡ Recall — грамматика

Слабые темы по диагностике. Сегодня: Будущее время -EcEK и Причастие -EN/-AN.

🔹 Будущее время -(y)EcEK

Выбери правильную форму: «Мы завтра пойдём в кино.»
💡 Будущее время: корень + -(y)ecek/-(y)acak + личное окончание. Для «biz» (мы): -eceğiz/-acağız. Обрати внимание: k→ğ перед гласным!
Переведи: «Она будет читать книгу завтра.»

💡 Глагол okumak, корень oku-. Будущее: -yacak (после гласной добавляется -y-). 3л. ед.ч. — личное окончание ноль (нет окончания)

🔹 Причастие -EN/-AN (relative)

Суффикс -en/-an превращает глагол в прилагательное: «тот, кто делает».

gelen adam
gel (приходить) + -en → «приходящий»
мужчина, который (при)шёл / приходящий мужчина
Как сказать «студент, который учит турецкий»?
💡 Причастие настоящего времени -en/-an: глагол + -en (передние гласные) или -an (задние). öğrenmek → öğren + -en = öğrenen
Вставь форму причастия: «Женщина, ___ (которая говорит) по-русски — моя подруга.»
Rusça ___ kadın benim arkadaşım.

💡 konuşmak → konuş + суффикс причастия. Последняя гласная в корне — «u» (задняя) → нужен вариант с задним гласным

🎯 Глагол дня — yapmak

yapmak — делать / создавать / совершать. Один из самых частотных глаголов турецкого языка. Управляет винительным падежом (-ı/-i/-u/-ü) для определённого объекта.

Спряжение yapmak в 3 временах

Лицо Наст. -yor Прош. -DI Буд. -(y)EcEK
benyapıyorumyaptımyapacağım
senyapıyorsunyaptınyapacaksın
oyapıyoryaptıyapacak
bizyapıyoruzyaptıkyapacağız
sizyapıyorsunuzyaptınızyapacaksınız
onlaryapıyorlaryaptılaryapacaklar
⚠ DİKKAT ET! yapmak оканчивается на твёрдую согласную -p (буква П входит в правило FıSTıKÇı ŞaHaP). Поэтому суффикс прошедшего времени: -dı → -tı! yaptı, а не ~~yapdı~~.
💡 В будущем времени: yapmak → yap + -acak → yapacak. Перед гласным личного окончания: yapacak→ yapacağım (k→ğ перед -ım).

yap + -acak + -ız → yapacağız (k→ğ перед гласной)
Завтра мы проведём встречу.

Вопросительное: суффикс -mi после слова, -tın в конце глагола

📖 Новая грамматика — Пассив -IL/-IN/-UL/-ÜL

Пассивный залог отвечает на вопрос: «что происходит с объектом?» вместо «кто что делает». По-русски — «быть сделанным», «строиться», «читаться». В турецком для этого есть специальный суффикс, который добавляется к основе глагола.

Формула

КОРЕНЬ ГЛАГОЛА + -IL/-IN/-UL/-ÜL + (буферная гласная -I-, если нужна) + ЛИЧНОЕ ОКОНЧАНИЕ

yazmak → yaz + -ıl → yazılmak («быть написанным»)
okumak → oku + -n → okunmak («быть прочитанным») ← особый случай
yapmak → yap + -ıl → yapılmak («быть сделанным»)
satmak → sat + -ıl → satılmak («быть проданным»)

Таблица гармонии гласных

Последняя гласная корня Суффикс пассива Пример
a, ı-ılyapılmak, açılmak
e, i-ilsevilmek, bul— ?
o, u-ulkurulmak, bozulmak
ö, ü-ülgörülmek, söylenmek*
💡 Особый случай: Если корень уже оканчивается на -l, суффикс пассива не может добавить ещё одну -l. В этом случае используется -in/-ın/-un/-ün (суффикс с -n).
• bulmak (найти): bul + -un → bulunmak («быть найденным»)
• söylemek (сказать): söyle + -n → söylenmek («говориться / бурчать»)
• bilmek: bil + -in → bilinmek («быть известным»)

Примеры с разбором

Bu kitap Türkçe'den Rusça'ya çevrildi.
çevir (переводить) + -il + -di | прошедшее пассива
Эта книга была переведена с турецкого на русский.
Yeni bir köprü inşa ediliyor.
inşa et- + -il + -iyor | настоящее пассива
Строится новый мост. (букв. новый мост строится)
Bu karar yarın verilecek.
ver (давать→принимать решение) + -il + -ecek | будущее пассива
Это решение будет принято завтра.
Ev temizlendi.
temizle + -n (корень на -e → буферный -n) + -di
Дом был убран / Дом убрали.
Bu şehirde Rusça da konuşuluyor.
konuş + -ul + -uyor | задняя гласная u → -ul
В этом городе говорят и по-русски.
⚠ DİKKAT ET! Пассив в турецком часто используется там, где в русском мы говорим «неопределённо-личное»: «Говорят, что...», «Здесь продают...», «Это называется...». Деятель (кем?) выражается творительным/послеложной конструкцией с tarafından: Kitap öğrenci tarafından okundu — «Книга была прочитана учеником».

✍️ Упражнения — Пассив -IL/-IN/-UL/-ÜL

1. Образуй пассивную форму: yazmak (писать) → инфинитив пассива

💡 Последняя гласная корня yaz — «a» (задний ряд, нелабиализованный) → нужен вариант суффикса с гласной заднего ряда
2. Образуй пассивную форму: görmek (видеть) → инфинитив пассива

💡 Последняя гласная «ö» (передний лабиализованный) → нужен суффикс переднего ряда с огублённой гласной
3. bulmak → инфинитив пассива (особый случай!)

💡 Корень оканчивается на «-l» → нельзя добавить ещё -l. Используется суффикс с другой согласной
4. Переведи: «Дверь была закрыта.» (kapatmak)

💡 kapı = дверь. Пассив от kapatmak: корень kapat- + суффикс пассива + прошедшее время. Последняя гласная «a» → нужен вариант суффикса с «-ı»
5. Выбери правильную пассивную форму для «Bu ev satılıyor» — что это означает?
💡 satmak = продавать. Пассив satılmak = быть продаваемым. Суффикс -ıyor = настоящее время.
6. Переведи: «Это здание было построено в 1950 году.» (inşa etmek)

💡 bina = здание. inşa etmek → пассив: inşa edilmek (et- → edilmek). Год + локатив -da/-de: 1950 yılında
7. Выбери правильную форму пассива от «sevmek» (любить):
💡 Последняя гласная корня sev — «e» (передний нелабиализованный). Выбери суффикс переднего ряда без огублённости.
8. Переведи активное предложение в пассивное:
Öğrenci kitabı okudu. → «Книга была прочитана (учеником).»

💡 В пассиве объект становится подлежащим (без окончания вин. пад.). okumak — корень oku- оканчивается на «-u», но заканчивается на «-l»? Нет, oku не на -l. u (задний огублённый) → суффикс с «-u». Но корень оканчивается на гласную → суффикс -n!
9. Составь предложение с пассивом, используя слово dalmak (нырять / погружаться). ⚠ weak
Например: «Denize derin bir şekilde dalındı.» → «В море ныряли глубоко.»
Вставь пассивную форму «dalmak» в настоящем времени (3л. ед.ч.):

💡 Корень dal-, последняя гласная «a» (задний ряд) → суффикс пассива с «ı». Корень заканчивается на «-l» → используем вариант с -n! Потом добавляем -ıyor
10. Переведи: «Новый магазин откроется на следующей неделе.»

💡 açmak (открывать) → пассив açılmak. Будущее пассива: açılacak. «На следующей неделе» = gelecek hafta (без падежа!)

🎨 Свободная продукция

Составь 4–5 предложений о своём городе или стране, используя пассив. Опиши что строится, продаётся, открывается, изучается. Обязательно включи хотя бы одно из слов: gezmek, kaybetmek, ilerlemek, hatırlamak.

🧭 Мини-ревью урока 46

1. Главная формула пассива
корень + -ıl/-il/-ul/-ül + личное окончание
Исключение: корень на -l → используем -ın/-in/-un/-ün
2. Гармония гласных в пассиве
a/ı → -ıl  |  e/i → -il  |  o/u → -ul  |  ö/ü → -ül
3. Пассив работает с любым временем
satılmak + -ıyor → satılıyor (продаётся)
satılmak + -dı → satıldı (было продано)
satılmak + -acak → satılacak (будет продано)
4. Деятель в пассивной конструкции
«кем» = tarafından (после родительного):
Kitap öğrenci tarafından okundu. — Книга была прочитана учеником.
⚠ Типичная ошибка
Не добавляй два -l подряд: ~~bulllmak~~ → правильно: bulunmak
Не путай пассив (-IL) с возвратным залогом (-IN): yıkanmak = мыться (самому себя мыть) ≠ yıkalmak (не существует).

Следующая тренировка: сессия 2 по теме «Пассив -IL/-IN» → больше упражнений на трансформацию активных предложений в пассивные.
