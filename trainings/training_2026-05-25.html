📖 Грамматика — суффикс -CE/-CA: продвинутые случаи

Сегодня — сессия 3 по этой теме. Базу ты уже знаешь: языки, мнения, наречия образа действия. Сегодня углубляемся в числительные + -CE, -CE как «как X» и сложные прилагательные + -CE.

1. Быстрый recap: формула

основа + -ce / -ca
последняя гласная e, i, ö, ü → -ce
последняя гласная a, ı, o, u → -ca
⚠ FıSTıKÇı ŞaHaP: основа на глухую согл. → -çe / -ça
Türkçe
Türk (турок) + -çe [к → глухая → ç]
по-турецки / турецкий язык
sakince
sakin + -ce [последняя гласная i → -ce]
спокойно

2. -CE с числительными → «десятки / по …»

В турецком суффикс -lerce / -larca (мн.ч. -ler/-lar + -ce/-ca) образует слово со значением «множество, десятки»:

sayı + -lerce / -larca → «десятки/сотни X»
onlarca insan
on (десять) + -lar + -ca → onlarca
десятки людей
yüzlerce kitap
yüz (сто) + -ler + -ce → yüzlerce
сотни книг
binlerce kişi geldi
bin (тысяча) + -ler + -ce → binlerce
Тысячи человек пришли.
DİKKAT ET! Форма onlarca пишется слитно и является устоявшимся словом. Не путай с личным местоимением onca (по его/её мнению) — там нет -lar!
onca = on (он/она) + -ca = по его мнению
onlarca = on (десять) + -lar + -ca = десятки

3. -CE как «как X / по-X-ски» от существительных

Суффикс -CE можно добавлять к существительным, обозначающим «стиль, манеру»:

insanca davranmak
insan (человек) + -ca → insanca
вести себя по-человечески
kahramanca savaştı
kahraman (герой) + -ca → kahramanca
Он сражался героически.
Japonca konuşmak
Japon (японец) + -ca → Japonca
говорить по-японски

4. -CE от сложных прилагательных

Сложные прилагательные тоже принимают -CE:

açıkgözce hareket etti
açıkgöz (хитрый) + -ce [последняя гласная ö → -ce]
действовал хитро / смышлёно
mantıklıca düşün
mantıklı (разумный/логичный) + -ca [ı → -ca]
думай разумно / логично
💡 HATIRLA (помни): -CE почти никогда не меняет ударение слова и всегда стоит в самом конце, после всех других суффиксов. Язык + -CE образует названия языков. Местоимение + -CE образует «по мнению X». Прилагательное/существительное + -CE образует наречие.

🎨 Свободная продукция

Составь предложения по шаблонам. Нет единственно правильного ответа — нажми «Показать пример», чтобы сверить свой вариант.

1. Расскажи своё мнение о чём-нибудь. Используй bence / sence / bizce.
Например: о погоде, о фильме, о путешествии.
Пример:
Bence bu film çok güzel. — По-моему, этот фильм очень красивый.
Bizce İstanbul'a gitmek lazım. — По-нашему, нужно поехать в Стамбул.
Sence hangi dil daha kolay — Türkçe mi, Japonca mı? — По-твоему, какой язык легче — турецкий или японский?
2. Составь предложение с «десятки/сотни/тысячи» (onlarca / yüzlerce / binlerce).
Тема: люди, книги, машины, города…
Примеры:
Onlarca araba park yerinde bekliyordu. — Десятки машин ждали на парковке.
Yüzlerce öğrenci bu dersi aldı. — Сотни студентов прошли этот курс.
Binlerce yıl önce burada büyük bir şehir vardı. — Тысячи лет назад здесь был большой город.
3. Опиши, как кто-то делает что-то — используй наречие с -CE/-CA.
Можно использовать: insanca (по-человечески), mantıklıca (разумно), açıkgözce (хитро), sakince (спокойно), sessizce (тихо)…
Примеры:
Çocuk sessizce uyudu. — Ребёнок тихо спал.
Müdür bize insanca davrandı. — Директор обращался с нами по-человечески.
O her şeyi açıkgözce halletti. — Он решил всё хитро/смышлёно.
