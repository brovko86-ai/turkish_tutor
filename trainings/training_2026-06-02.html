🎯 Глагол дня — incelemek

incelemek — изучать / рассматривать / проверять / исследовать
Управление: -(y)i / -(y)ı / -(y)u / -(y)ü (прямое дополнение в вин. падеже)

Спряжение в трёх временах

Лицо-iyor (наст.)-di (прош.)-(y)ecek (буд.)
beninceliyorumincelediminceleyeceğim
seninceliyorsuninceledininceleyeceksin
oinceliyorincelediinceleyecek
bizinceliyoruzinceledikinceleyeceğiz
sizinceliyorsunuzinceledinizinceleyeceksiniz
onlarinceliyorlarinceledilerinceleyecekler
💡 Гармония гласных: корень incele- оканчивается на e → суффикс настоящего времени: -iyor (передний ряд, нелабиализованный). Суффикс будущего: -yecek. Буква ğ в inceleyeceğim — это смягчение k перед гласным.

Живые примеры

Müdür sözleşmeyi inceliyor.
sözleşme + yi (вин.) | incele + iyor
Директор изучает договор.
Doktor raporları dikkatli bir şekilde inceledi.
rapor + ları (вин.мн.) | incele + di
Врач внимательно изучил отчёты.
Bu projeyi yarın inceleyeceğim.
proje + yi (вин.) | incele + yecek + im
Завтра я изучу этот проект.
Polis olayı inceledi ve bir tanıdık buldu.
olay + ı (вин.) | tanıdık = знакомый/свидетель
Полиция изучила случай и нашла знакомого (свидетеля).
Bu haberi neden inceliyorsun?
haber + i (вин.) | neden = почему
Почему ты изучаешь эту новость?
Öğretmen ödevleri inceledi ama bir şey bulmadı.
ödev + leri (вин.мн.) | bulmak → bulmadı (не нашёл)
Учитель проверил домашние задания, но ничего не нашёл.

Родственные слова

ince — тонкий, изящный (корень)
inceleme — изучение / проверка / исследование (отглагольное сущ.)
incelemeye almak — взять на рассмотрение / принять к изучению
Синоним: araştırmak — исследовать (более глубоко), kontrol etmek — проверять (более быстро)

📖 Новая грамматика — Пассив: суффикс -IL / -IN / -ÜL / -UN

В турецком языке пассивный залог (страдательный) образуется с помощью суффикса -(I)l или -(I)n, который добавляется к корню глагола. Это аналог русского «быть сделанным», «делается», «было написано».

Формула пассива:
Глагольный корень + -(I)l + время + личный суффикс

görülmek — быть увиденным (видеть → görülemk)
yazılmak — быть написанным (yazılemk)
yapılmak — быть сделанным (yapmak)
satılmak — быть проданным (satmak)

Если корень кончается на гласную → суффикс -n:
okunmak — быть прочитанным (okumak)
anlaşılmak ← сложнее (reflexive/recip.)
içilnmek → içilmek — быть выпитым (içmek)

Гармония гласных в суффиксе пассива

Последняя гласная корняСуффикс пассиваПример
a, ı-ıl / -ınyaz → yazılmak
e, i-il / -ingör → görülmek ✗ / bil → bilinmek
o, u-ul / -unbul → bulunmak
ö, ü-ül / -üngör → görülmek
💡 Правило: корень на согласный → берём -Il. Корень на гласный → берём -In (чтобы не было двух гласных подряд).
oku + nmak = okunmak ✓  |  yaz + ılmak = yazılmak ✓

Пассив в разных временах

Пассивная основа — это новый инфинитив, к которому можно добавлять любые суффиксы времён.

Bu mektup yazılıyor.
yaz + ıl + ıyor → настоящее время
Это письмо пишется / сейчас пишут это письмо.
Sözleşme imzalandı.
imzala + n + dı → пассив от imzalamak (на гласную → -n) + прошедшее -dı
Договор был подписан.
Kapı açıldı.
aç + ıl + dı → прошедшее время пассива
Дверь открылась / была открыта.
Bu kitap çok okunuyor.
oku + n + uyor → настоящее время пассива
Эту книгу много читают. (букв. Эта книга много читается.)
Proje yarın incelenecek.
incele + n + ecek → будущее время пассива (корень на гласную → -n)
Проект будет изучен завтра.

Деятель в пассивной конструкции — суффикс -tarafından

Если нужно указать, кем совершено действие, используется конструкция с tarafından («со стороны», «от»):

Bu roman ünlü bir yazar tarafından yazıldı.
ünlü bir yazar tarafından = известным писателем
Этот роман был написан известным писателем.
Toplantı müdür tarafından düzenlendi.
düzenle + n + di → пассив от düzenlemek
Собрание было организовано директором.
⚠️ DİKKAT ET! Не путай пассив с возвратным (reflexive) залогом! Суффикс -il/-ıl = пассив («быть сделанным»). Суффикс -in/-ın тоже бывает пассивным (после гласной), но может быть и рефлексивным. Различай по контексту: если объект стоит на месте подлежащего — это пассив.
⚠️ DİKKAT ET! FıSTıKÇı ŞaHaP! Суффикс пассива начинается с гласной ı/i/u/ü. Правило FSTKÇŞHP не применяется к самому суффиксу пассива — оно действует при добавлении суффиксов времён: yazıl + dı = yazıldı (d не озвончается, т.к. перед ним л — мягкий согласный).

🧭 Мини-ревью урока

Главное за сегодня:

  1. Пассив = корень + -(I)l + суффикс времени
    Корень на согласный → -ıl/-il/-ul/-ül; корень на гласный → -ın/-in/-un/-ün
  2. Гармония гласных: a/ı → -ıl, e/i → -il, o/u → -ul, ö/ü → -ül
  3. Деятель в пассиве — tarafından:
    Müdür tarafından yazıldı. = Было написано директором.
  4. Пассив работает во всех временах: yazılıyor / yazıldı / yazılacak
  5. Типичная ошибка: корень на гласную + -il = ❌ okuil → ✅ okunmak (нужен -n, а не -l)
Новые слова: anlaşmak · ilerlemek · incelemek · imzalamak · icat etmek · hazırlık · toplum · mağaza
