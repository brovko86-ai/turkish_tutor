🔹 Деепричастие -arak / -erek («делая / путём»)

Выбери правильную форму для «смеясь» (gülmek + -erek):
💡 Правило: если последняя гласная в корне — e/i/ö/ü, берём -erek; если a/ı/o/u — -arak. gül → ü → -erek.
Переведи на турецкий: «Он пришёл, бегя / бегом» (koşmak + geldi)
💡 koş- → последняя гласная o → суффикс -arak. Порядок: деепричастие стоит перед основным глаголом.

🔹 Причастие -EN / -AN («который делает»)

Образуй причастие от çalışmak («тот, кто работает»):
💡 Причастие -en/-an от глагола: корень + -en/-an. çalış → последняя гласная ı → задний ряд → -an.
Переведи: «Человек, который читает книгу»
kitap + okumak (причастие настоящего)
💡 oku → последняя гласная u → задний ряд → -yan (после гласной вставляем -y-). Причастие стоит перед существительным.

🔹 Повелительное наклонение (imperative)

Как сказать вежливо «Объясни, пожалуйста» (açıklamak, вежливая форма 2 л.)?
💡 Формы: açıkla (неформ. ед.ч.) / açıklayın (неформ. мн.ч. / вежл.) / açıklayınız (офиц. вежл.). Перед -ın/-iniz нужен буфер -y- после гласной основы.

🎯 Глагол дня — koymak

koymak — класть / помещать / ставить / вкладывать
Управление: что? → винительный (-ı/-i/-u/-ü) | куда? → дательный (-a/-e)

[кто] + [что]-ı/i/u/ü + [куда]-a/e + koy + суффикс времени + личное окончание

Спряжение

Лицо-(I)yor (наст.)-DI (прошедшее)-(y)EcEK (будущее)
benkoyuyorumkoydumkoyacağım
senkoyuyorsunkoydunkoyacaksın
okoyuyorkoydukoyacak
bizkoyuyoruzkoydukkoyacağız
sizkoyuyorsunuzkoydunuzkoyacaksınız
onlarkoyuyorlarkoydularkoyacaklar
⚠ DİKKAT: Корень koy- оканчивается на согласный -y. В настоящем времени буфер -u- добавляется перед -yor → koy-u-yor. В будущем: koy + -acak → koyacak (последняя гласная o → задний ряд → -acak). В форме 1 л. ед.ч. и 1 л. мн.ч. будущего: koyacak + -ım → koyacağım (k → ğ перед гласной!).

Живые примеры

Kitabı masaya koydum.
kitab-ı (книгу, вин.) + masa-ya (на стол, дат.) + koy-du-m
Я положил книгу на стол.
Telefonu nereye koydun?
telefon-u (телефон, вин.) + nereye (куда?) + koy-du-n
Куда ты положил телефон?
Çantama anahtarımı koyacağım.
çanta-m-a (в мою сумку) + anahtar-ım-ı (мой ключ, вин.) + koy-acak-ım
Я положу ключ в свою сумку.
Şekeri kahveme koymuyorum.
şeker-i + kahve-m-e + koy-mu-yor-um (отрицание -mu-)
Я не кладу сахар в свой кофе.
Bu sorunları bir kenara koyalım.
sorun-ları + bir kenara (в сторону) + koy-alım (побудит. 1 мн.)
Давай отложим эти проблемы в сторону.
Çorbanın içine tuz koydu.
çorba-nın içi-ne (в суп) + tuz (соль, без артикля) + koy-du
Она положила соль в суп.
💡 Однокоренные / связанные слова:
koymak (класть) → пассив: konulmak (быть положенным) — прекрасный мостик к сегодняшней теме!
Фразеологизм: bir kenara koymak = «отложить в сторону» (букв. «положить в угол»)

📖 Новая грамматика — Пассивный залог

Пассивный залог отвечает на вопрос: «что происходит с предметом?», а не «кто делает?». В турецком пассив образуется суффиксом, который добавляется к корню глагола.

Формула

Корень глагола + пассивный суффикс + суффикс времени + личное окончание

Суффиксы пассива:
после гласной: -n- → yapa → yapıl… / iç → içil…
после согласной (общее): -il/-ıl/-ul/-ül
после согласной -l: -in/-ın/-un/-ün (чтобы не было -ll-)

Таблица суффиксов

Окончание корняСуффикс пассиваПример (активный → пассивный)
На гласную -n- yıka → yıkanmak (мыться)
На согласную (не -l) -il/-ıl/-ul/-ül yap → yapılmak (делаться); sev → sevilmek (любиться)
На согласную -l -in/-ın/-un/-ün bul → bulunmak (находиться/быть); bil → bilinmek (быть известным)
⚠ FSTKÇŞHP — помни! Если корень кончается на глухой согласный из FıSTıKÇı ŞaHaP, суффикс пассива добавляется как обычно (согласные суффикса не меняются — меняются только суффиксы, начинающиеся с -d/-t в окончаниях времён).

Гармония гласных пассивного суффикса

Последняя гласная корняПассивный суффикс
a, ı-ıl- / -ın-
e, i-il- / -in-
o, u-ul- / -un-
ö, ü-ül- / -ün-

Примеры с разбором

Bu kitap çok okunuyor.
oku (читать, корень на -u) → oku + n (пассив после гласной) + uyor → okunuyor
Эта книга много читается / пользуется популярностью.
Kapı açıldı.
aç (открывать) → aç + ıl (пассив, последняя гласная a → -ıl) + dı (прошедшее)
Дверь открылась / была открыта.
Bu söz ona söylendi.
söyle (говорить, корень на -e) → söyle + n (пассив) + di
Эти слова были сказаны ему.
Hata bulundu.
bul (находить, корень на -l) → bul + un (пассив после -l) + du
Ошибка была найдена.
Şehir 1453'te fethedildi.
fethet (завоёвывать) → fethet + il + di → fethedildi (d становится ç после т)
Город был завоёван в 1453 году.
Bu ev kiralanacak.
kirala (арендовать, корень на -a) → kirala + n + acak
Этот дом будет сдан в аренду.
💡 Исполнитель в пассивных предложениях:
Если нужно указать, кем что-то было сделано, используют послелог tarafından («со стороны / кем»):
Bu roman ünlü bir yazar tarafından yazıldı. — Этот роман был написан знаменитым писателем.

✍️ Упражнения по грамматике — Пассив

1. Какая форма пассива от yazmak (писать)? Последняя гласная: a.
💡 yaz- (согласная, не -l). Последняя гласная a → суффикс -ıl-. Инфинитив пассива: yaz + ıl + mak.
2. Образуй пассив от bulmak в прошедшем времени, 3 л. ед.ч. («было найдено»):
💡 bul- оканчивается на -l → пассив -un-. Прошедшее -du. Итого: bul + un + du = bulundu.
3. Что значит «Yemek pişirildi»?
💡 piş-ir (каузатив: варить/готовить) → piş-ir + il + di = пассив прошедшего времени
4. Образуй пассив от sevmek в настоящем времени, 3 л. ед.ч. («любят / пользуется любовью»):
💡 sev- (согласная, не -l). Последняя гласная e → суффикс -il-. Настоящее: + iyor → seviliyor.
5. Как по-турецки «Книга была написана учителем»?
💡 Пассив + исполнитель через tarafından. Порядок: подлежащее (пациент) + исполнитель + tarafından + глагол в пассиве.
6. Образуй пассив от kiralamak в будущем времени, 3 л. ед.ч. («будет арендовано / сдано»):
kirala- = корень на гласную -a
💡 kirala- (на гласную) → пассив -n-. Будущее -acak (последняя гласная a → задний ряд). Итого: kirala + n + acak.
7. Переведи активное предложение в пассивное:
Активное: «Müdür karar verdi.» (Директор принял решение.) → Пассив: «Решение было принято.»
💡 ver- (давать) + пассив: последняя гласная e → -il-. Прошедшее -di. Субъект (müdür) убираем или добавляем tarafından. Karar = «решение» становится подлежащим.
8. Какая форма пассива от bilmek (знать)?
💡 bil- оканчивается на -l → нельзя добавить -il- (получилось бы -ll-). Поэтому для корней на -l используем -in-/-ın-/-un-/-ün. Последняя гласная i → -in-.
9. Образуй пассив от koymak (класть) в прошедшем, 3 л. ед.ч. («было положено / поставлено»):
💡 koymak имеет нерегулярный пассив: koymak → konulmak (не koyulmak). Корень kon- + ul + du = konuldu. Это нерегулярная форма, которую нужно запомнить!
10. Что значит «Bu şehir kurulacak»?
💡 kur- (основывать) + ul (пассив) + acak (будущее). Признак будущего: -acak/-ecek.

🧭 Мини-ревью урока

  • Пассивный залог — суффикс меняет «кто делает» на «что происходит с объектом».
  • После гласных: суффикс -n- (yıka → yıkan-, oku → okun-).
  • После согласных (не -l): -il/-ıl/-ul/-ül по гармонии (sev → sevil-, yap → yapıl-).
  • После корней на -l: -in/-ın/-un/-ün (bul → bulun-, bil → bilin-).
  • Исполнитель указывается через tarafından: «öğretmen tarafından yazıldı».
  • Типичная ошибка: добавить -il- после корня на -l → получается двойная -l. Запомни: bil → bilin, bul → bulun.
  • Исключение! koymak → пассив konulmak (нерегулярный).
