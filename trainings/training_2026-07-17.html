⚡ Recall — быстрая проверка

Темы из диагностики — ускоренное повторение.

1 · Суффикс -arak/-erek (слабая тема)

Выбери правильную форму: «Он объяснил задачу, смеясь.»
-arak/-erek = «делая, посредством действия»; güle- + -rek (передняя гласная e → -erek).

⚡ Recall — быстрая проверка (продолжение)

2 · Будущее время -EcEK (слабая тема)

Переведи: «Завтра она будет защищать проект.» — выбери правильную форму глагола korumak в будущем времени для 3 лица ед.ч.
Будущее -EcEK: koru- + -(y)acak; задние гласные o/u → -acak; 3 л. ед.ч. — без личного окончания.

3 · Инструментальный падеж -le/-la (слабая тема)

Дополни: «Она едет на поезде» — Trenle mi trenin ile mi? Выбери грамматически верную запись.
Инструментальный: tren + -le (последняя гласная e → -le); обозначает «на чём / с помощью чего».

4 · Причастие -EN/-AN (слабая тема)

«Девушка, изучающая турецкий» — выбери правильную форму:
-EN/-AN = действующее причастие (кто делает действие); öğren- + -en (передняя e → -en); не путай с -İLEN (пассив).

🎯 Глагол дня — tanıştırmak

tanıştırmak — знакомить (кого-то с кем-то). Каузатив от tanışmak (знакомиться друг с другом). Управление: birini biriyle tanıştırmak = «познакомить кого-то с кем-то».

tanış- → tanış-tır-mak
Кого? → Accusative (-ı/-i/-u/-ü)
С кем? → Instrumental (-la/-le)
Пример: seni onunla tanıştırmak = познакомить тебя с ним

Спряжение по временам

Живые примеры

Seni kardeşimle tanıştırmak istiyorum.
seni (тебя-Acc) | kardeşim-le (с моим братом-Instr) | tanıştır-mak iste-iyor-um
Я хочу познакомить тебя с моим братом.
Müdür bizi yeni çalışanla tanıştırdı.
müdür (директор) | bizi (нас-Acc) | yeni çalışan-la (с новым сотрудником-Instr) | tanıştır-dı
Директор познакомил нас с новым сотрудником.
Bu kitap beni farklı kültürlerle tanıştırdı.
bu kitap (эта книга) | beni (меня-Acc) | farklı kültürler-le (с разными культурами-Instr) | tanıştır-dı
Эта книга познакомила меня с разными культурами.
Sizi birbirinizle tanıştıracağım.
sizi (вас-Acc) | birbir-iniz-le (друг с другом-Instr) | tanıştır-acağ-ım
Я познакомлю вас друг с другом.
Ahmet bizi komşusuyla tanıştırıyor.
Ahmet | bizi (нас-Acc) | komşu-su-yla (со своим соседом-Instr) | tanıştır-ıyor
Ахмет знакомит нас со своим соседом.
💡 Однокоренные слова: tanımak (знать/узнавать) → tanışmak (знакомиться взаимно) → tanıştırmak (знакомить кого-то). Суффикс -tır = каузатив, -ış = взаимное действие.

📖 Каузатив — углублённый разбор (сессия 2)

В первой сессии мы разобрали базовую логику. Сегодня — нюансы выбора суффикса и сложные глаголы.

Какой суффикс выбрать?

1) Глагол ≥ 2 слогов или оканчивается на гласную → -DIR/-DİR/-DUR/-DÜR
(с учётом гармонии гласных и FSTKÇŞHP)

2) Односложные на согласный:
• большинство → -DIR: bak- → baktır-, iç- → içtir-
• группа «тихих»: gör- → gör-t-, geç- → geç-ir-, koş- → koş-tur-

3) Уже каузативный глагол + ещё -DIR → двойной каузатив:
yaz- → yazdır- → yazdırt- (заставить заставить написать)

Гармония гласных суффикса -DIR

Последняя гласная корняСуффиксПример
a, ı-dır / -tırbak- → baktır-
e, i-dir / -tirgez- → gezdir-
o, u-dur / -turkoş- → koştur-
ö, ü-dür / -türsön- → söndür-
DİKKAT! FSTKÇŞHP: если корень оканчивается на глухой согласный (f,s,t,k,ç,ş,h,p) — -d → -t. Пример: iç- → içtir- (не içdir), yap- → yaptır- (не yapdır).

Примеры с новыми словами

Müdür raporu inceletti.
incele- (двусложный, оканчивается на гласную) → incele + -t → inceletti
Директор велел проверить отчёт.
Öğretmen öğrencilere becerilerini geliştirtti.
geliştir- + -t (двойной каузатив) → geliştirtti
Учитель заставил учеников развить свои навыки.
Şirket planı gerçekleştirdi.
gerçekleştir- + -di (здесь нет дополнительного каузатива)
Компания осуществила план.
💡 Как распознать каузатив в тексте: ищи -tır-/-dir-/-tur-/-dür- внутри глагола между корнем и личным окончанием: yap-tır-dı = заставил сделать.

✍️ Упражнения по грамматике

1. Образуй каузатив

Глагол okumak (читать) → каузатив (заставить прочитать) в форме инфинитива:
oku- оканчивается на гласную → каузатив -t; oku + t = okutmak.
Глагол söndürmek (тушить) → каузатив (заставить потушить) в форме инфинитива:
söndür- уже содержит каузатив -dür; двойной каузатив: söndür + -t + -ür = söndürttürmek.

2. Переведи предложение с каузативом

«Менеджер заставил сотрудника проверить документы.» → переведи (используй incelemek + каузатив + прошедшее).
incelettirmek или incelettmek? incel-e- оканчивается на гласную → -t; прошедшее -di/-di → inceletti; belgeler требует вин. пад. определённого объекта.
Выбери правильную каузативную форму от söndürmek в прошедшем времени, 3 л. ед.ч.:
Двойной каузатив: söndür + -t (FSTKÇŞHP: r не глухой, значит -t без изменений) + прошедшее -tü (r+t → tt) = söndürttü.

3. FSTKÇŞHP — выбери верный суффикс

Глагол koşmak (бежать) → каузатив. Выбери правильную форму инфинитива:
koş- оканчивается на ş (входит в FSTKÇŞHP) → d→t; последняя гласная o → -tur; koş + tur = koşturmak.
Глагол yazmak (писать) → каузатив 1 л. ед.ч. настоящее время:
yaz- оканчивается на z (звонкий, не в FSTKÇŞHP) → суффикс -dır; последняя гласная a → -dır; +настоящее -ıyor + m = yazdırıyorum.

4. Переводи с русского

«Ты заставил меня предположить неправильное.» (varsaymak + каузатив + прошедшее, 2 л. ед.ч.)
varsay- оканчивается на гласную y → каузатив -t; двойная буква: -tt-; прошедшее -ı + -dın (2 л. ед.ч.).
«Директор велел им развить навыки.» (beceri, geliştirmek + каузатив + прошедшее)
geliştir- уже каузатив → двойной: geliştir + -t → geliştirtti; beceri + possessive -leri + Acc → becerilerini.
«Опыт научил меня понимать справедливость.» — переведи свободно, используя tecrübe и adalet.
öğretmek (учить/преподавать) — каузатив от öğrenmek; adalet + Acc = adaleti; anlamak → anlama-yı (отглагольное существительное Acc).

🎨 Свободная продукция

Напиши 4–6 предложений о ситуации, где кто-то кого-то заставлял что-то делать — например, на работе, в школе или дома. Используй новые слова и weak_words.

Опора: используй хотя бы 3 слова из списка: tanıştırmak, varsaymak, sezmek, beceri, tecrübe, adalet, hayal и хотя бы 2 из weak_words: ilerlemek, korumak, pekiştirmek, anlattırmak.

Шаблон-подсказка (можно не следовать точно):

«[Кто] [кого] [с кем] tanıştırdı. [Кто] [кого] [что] yazdırdı / anlattırdı. [Что] beni [с чем/кем] tanıştırdı...»

Образец:
Müdür bizi yeni ekiple tanıştırdı. Tecrübeli çalışan bize becerileri pekiştirmeyi öğretti. Ben başta yanlış varsaydım ama nihayet adaleti anladım. Proje boyunca ilerledik ve hayalimizi gerçekleştirdik. Lider bizi çevreyi korumaya yönlendirdi. Öğretmen öğrenciye konuyu anlattırdı.

Перевод: Директор познакомил нас с новой командой. Опытный сотрудник научил нас закреплять навыки. Сначала я предполагал(а) неверное, но наконец понял(а) справедливость. На протяжении проекта мы прогрессировали и осуществили нашу мечту. Лидер направил нас на защиту окружающей среды. Учитель велел ученику объяснить тему.
