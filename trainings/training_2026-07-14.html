🎯 Глагол дня — kavramak

kavramak — постигать / схватывать / понимать (глубоко)
Управление: -ı/-i/-u/-ü (прямой объект, винительный падеж)

DİKKAT! Корень kavra- оканчивается на гласную a.
При добавлении -yor буферный гласный выпадает: kavra-yor → kavrıyor (гласная усекается, добавляется ı).
В будущем времени: kavra- + -(y)acak → kavrayacak (буфер -y- между двумя гласными).

Примеры в контексте

kavra- + -dı + -m (1sg прошедшее)
Я сразу понял / уловил это правило.
Konuyu tam olarak kavrayamazsın böyle.
kavra- + -yama- (отрицат. потенциал) + -z + -sın
Ты так не сможешь полностью постичь тему.
Öğrenciler yeni gramer yapısını kavramaya çalışıyor.
kavra- + -ma (инф.) + -ya (дат. пад.) + çalışmak (стараться делать)
Студенты стараются усвоить новую грамматическую структуру.
Nihayet kavradık!
kavra- + -dı + -k (1pl прошедшее)
Наконец-то мы поняли!
Bu kavramı kavramak zor değil.
kavram (понятие/концепция) ← того же корня, что и kavramak
Понять эту концепцию не сложно.
Fikri ilk dinleyişte kavrayan biri olmadı.
kavra- + -yan (причастие -AN) = «тот, кто понял»
Не нашлось никого, кто понял бы идею с первого раза.
СВЯЗЬ С ОДНОКОРЕННЫМИ:
kavramak (глагол) → kavram (сущ. = «понятие / концепция»)
→ kavrayış (сущ. = «понимание / восприятие»)
→ kavranılmak (пассив = «быть понятым / усвоенным»)
Схожий по смыслу: anlamak (понимать — более общее), kavramak — глубже, на уровне концепции.

📖 Страдательный залог — суффикс -IL / -IN / -UL / -ÜL

Страдательный залог (пассив) в турецком позволяет сделать объект действия подлежащим предложения — либо когда исполнитель неизвестен, неважен или намеренно скрыт.
Ты уже видел его в действии: bilinmek, gönderilmek, yapılmak — все они были в словаре!

Формула суффикса

Корень глагола + пассивный суффикс + временной суффикс + личное окончание

ПРАВИЛО 1: Корень на согласную → суффикс -il / -ıl / -ul / -ül (по гармонии)
yaz- → yaz-ıl-mak (писать → быть написанным)
gönder- → gönder-il-mek (отправлять → быть отправленным)

ПРАВИЛО 2: Корень на гласную → суффикс -n
oku- → oku-n-mak (читать → читаться)
söyle- → söyle-n-mek (говорить → говориться)

ИСКЛЮЧЕНИЕ: -l → -in
Если корень заканчивается на -l, пассив делается через -in/-ın/-un/-ün
bul- → bul-un-mak (находить → находиться/обнаруживаться)
söyle- → söyle-n-mek → (через -n, т.к. гласная)

Таблица гармонии гласных в суффиксе

Последняя гласная корняСуффикс (корень на согласную)Пример
a, ı-ıl-yaz → yazılmak
e, i-il-gönder → gönderilmek
o, u-ul-topla → (но корень на гласную → -n!) / koru → korunmak
ö, ü-ül-çöz → çözülmek

Подробные примеры с декомпозицией

Bu mektup dün yazıldı.
yaz- + -ıl- (пассив) + -dı (прошедшее) + (3sg без окончания)
Это письмо было написано вчера.
Rapor yarın gönderilecek.
gönder- + -il- (пассив) + -(y)ecek (будущее) + (3sg)
Отчёт будет отправлен завтра.
Bu ses her yerden duyulur.
duy- + -ul- (пассив) + -ur (настоящее-общее, аорист) + (3sg)
Этот звук слышен отовсюду.
Sorun çözüldü.
çöz- + -ül- (пассив, т.к. ö) + -dü (прошедшее) + (3sg)
Проблема решилась.
Bu kitap çok okunuyor.
oku- (на гласную) + -n- (пассив) + -uyor (настоящее)
Эту книгу очень много читают. / Эта книга очень читается.
Söylenenleri dikkatle dinliyorum.
söyle- + -n- + -en (причастие) = «то, что говорится»
Я внимательно слушаю то, что говорится.
DİKKAT ET! Пассив vs. Рефлексив:
Суффикс -n- (после гласной) используется и для пассива, и для рефлексива («делать для себя»).
Контекст помогает различить:
söylenmek = «говориться» (пассив) ИЛИ «ворчать / бурчать» (рефлексив)
hazırlanmak = «готовиться» (рефлексив, «готовить себя») — эти слова ты уже знаешь!
СОВЕТ: Чтобы указать исполнителя действия в пассивной конструкции, используется суффикс -tarafından (со стороны / кем-то):
Bu proje müdür tarafından hazırlandı. — Этот проект был подготовлен директором.

✍️ Упражнения — страдательный залог

1. Какой вариант является правильным пассивом от açmak (открывать)?
💡 Корень açı- оканчивается на согласную ç, последняя гласная — a (задний ряд) → суффикс -ıl-.
2. Поставьте глагол в пассивную форму настоящего времени:
«Bu yazı her gün sosyal medyada ________ (paylaşmak).»
(Этот текст каждый день распространяется в соцсетях.)
💡 paylaş- (согласная ş, задняя гласная a/ı) → суффикс -ıl-, затем настоящее время -(ı)yor.
3. Как образуется пассив от глагола temizlemek (убирать/чистить)?
💡 Корень temizle- оканчивается на гласную e → пассивный суффикс -n- (а не -il-).
4. Переведите с указанием исполнителя:
«Отчёт был проверен директором.»
(rapor / müdür tarafından / incelemek / прошедшее)
💡 incele- оканчивается на гласную e → пассив -n-, затем прошедшее -di, 3sg без окончания.
5. В каком предложении глагол стоит в страдательном залоге (пассив)?
💡 Ищи форму с суффиксом пассива (-il-, -ıl-, -ul-, -ül-, -n-) перед временным суффиксом.
6. Особый случай: корень оканчивается на -l.
Поставьте глагол bulmak (находить) в пассивную форму прошедшего времени (3sg):
«Anahtarlar çantanın içinde ________.»
(Ключи нашлись / были найдены внутри сумки.)
💡 bul- оканчивается на -l → пассив -un- (а не -ul-!), затем прошедшее -du, 3sg без окончания.
7. Как спросить по-турецки: «Когда будет открыт магазин?» (mağaza / açmak / будущее)
💡 açı- (согласная ç, гласная a → задний ряд) → суффикс -ıl- + будущее -acak.
8. Переведите полное предложение:
«Эта трудная проблема так и не решилась.»
(Bu zor sorun / çözmek / пассив / hâlâ (до сих пор) / olmak-değil форма)
💡 Отрицательный потенциал пассива: çöz- + -ül- + -eme- (отриц. способность в прошедшем) + -di, 3sg.

🎨 Свободная продукция

Составь 3–4 предложения о любом событии или ситуации, используя пассивный залог. Можно придумать что угодно — репортаж, новость, описание процесса.

ОПОРНЫЕ СЛОВА И ФРАЗЫ:
🔴 Слабые слова: ilerlemek, korumak, hissetmek, nihayet, pekiştirmek, söndürmek, geliştirmek
🟣 Новые слова: başvurmak, kavramak, çekinmek, hedeflemek, kaygı, öncelik, gerekçe
📌 Пассивные глаголы: gönderilmek, duyulmak, çözülmek, yazılmak, incelenmek, korunmak, geliştirilmek

Шаблон-подсказка:
«[Объект] [временной маркер] [исполнитель + tarafından] [глагол в пассиве].»
Например: «Bu kaygı nihayet dile getirildi.» — Это беспокойство наконец-то было высказано вслух.
Что проверить самостоятельно:
✦ Суффикс пассива соответствует конечному звуку корня (согласная → -il-/-ıl- и т.д.; гласная → -n-).
✦ Гармония гласных в суффиксе соблюдена.
✦ Порядок: пассивный суффикс → временной суффикс → личное окончание.
✦ Если указан исполнитель — использован -tarafından (или -den/-dan с некоторыми глаголами).
✦ Слабые слова употреблены в правильном контексте.

🧭 Мини-ревью урока

  • Страдательный залог в турецком образуется суффиксом -IL-/-IL-/-UL-/-ÜL- (корень на согласную) или -N- (корень на гласную).
  • Если корень оканчивается на -L — особый суффикс -IN-/-IN-/-UN-/-ÜN-: bul- → bulunmak.
  • Порядок суффиксов: корень + пассив + время + лицо. Гармония гласных работает по последней гласной корня.
  • Исполнитель в пассивной конструкции указывается через -tarafından («со стороны / кем-то»).
  • Типичная ошибка: путать суффикс пассива с рефлексивом (-n- используется для обоих). Контекст решает: hazırlandı = «подготовился» (рефл.) vs. hazırlandı = «был подготовлен» (пассив) — часто совпадают по форме, но смысл из контекста.
