⚡ Recall — быстрая грамматика

1. [Instrumental -le/-la] Выбери правильную форму: «Мы едем на автобусе».

Инструментальный падеж (-le/-la) выражает «с помощью чего»; -DEN = «от/из», -DE = «в/на» (место), -E = «к» (направление).

2. [-arak/-erek] «Он вошёл в комнату, улыбаясь» — вставь правильную форму глагола gülümsemek.

Суффикс -arak/-erek означает «делая что-то попутно»; корень gülümse- оканчивается на гласную → -yerek (буфер y).

3. [Future -EcEK] Переведи: «Она завтра придёт» — выбери верное.

Будущее время: корень + -(y)EcEK + личное окончание; для 3 л. ед.ч. окончание нулевое.

🎯 Глагол дня — selamlamak

selamlamak — приветствовать, здороваться (с кем-то). Управление: kimi? (винительный падеж — кого?).

Корень: selamla-
selamla-r (настоящее-будущее общее)  |  selamla-dı (прошедшее -DI)  |  selamla-yacak (будущее -EcEK)
Гласная основы: a → суффиксы задние: -ıyor, -dı, -yacak, -malı

Спряжение в трёх временах

Лицо-(I)yor (наст.вр.)-DI (прош.)-(y)EcEK (буд.)
Benselamlıyorumselamladımselamlayacağım
Senselamlıyorsunselamladınselamlayacaksın
Oselamlıyorselamladıselamlayacak
Bizselamlıyoruzselamladıkselamlayacağız
Sizselamlıyorsunuzselamladınızselamlayacaksınız
Onlarselamlıyorlarselamladılarselamlayacaklar
DİKKAT! Корень selamla- оканчивается на гласную a. При добавлении -ıyor буферного согласного нет, но последняя гласная корня выпадает: selamla + ıyor → selamlıyor (стяжение). Это стандартная модель для глаголов на -la/-le.

Примеры в контексте

Misafirleri kapıda selamladı.
selamla + dı (прошедшее -DI, 3 л. ед.ч.)
Он/она поприветствовал(а) гостей у двери.
Her sabah komşularımı selamlıyorum.
selamla + ıyor + um (настоящее, 1 л. ед.ч.)
Каждое утро я здороваюсь со своими соседями.
Sizi toplantıda selamlayacağız.
selamla + yacak + ız (будущее, 1 л. мн.ч.)
Мы поприветствуем вас на встрече.
Bu adet göre konukları güler yüzle selamlıyorlar.
selamla + ıyor + lar (настоящее, 3 л. мн.ч.)
По этому обычаю гостей встречают с улыбкой.
Kibar bir insan herkesi selamlar.
selamla + r (настоящее-будущее общее, 3 л. ед.ч.)
Вежливый человек здоровается со всеми.
Родственные слова: selam (привет/приветствие) → selamlamak (приветствовать) → selamlama (приветствие, действие) → selamlaşmak (здороваться друг с другом, взаимный суффикс -ş).

📖 Новая грамматика — Плюсквамперфект -mIştI

Плюсквамперфект описывает действие, которое уже завершилось до другого прошедшего момента. По-русски: «уже сделал», «к тому времени было сделано».

Формула: Глагол-основа + -mIş + -tI + личное окончание

git → gitmiştim — я уже ушёл (к тому времени)
gel → gelmişti — он уже пришёл
yap → yapmıştık — мы уже сделали
oku → okumuştun — ты уже прочитал

Гармония гласных в -mIş

Последняя гласная корняСуффикс -mIşПример
a, ı-mışkaldır → kaldırmış + tı
e, i-mişgelmiş + ti
o, u-muşkonuşmuş + tu
ö, ü-müşgörmüş + tü
DİKKAT! FSTKÇŞHP: суффикс -tI начинается на t, потому что -mIş оканчивается на ş (в списке FıSTıKÇı ŞaHaP). Это объясняет -tİ, а не -dİ.

Личные окончания (после -mIştI)

ЛицоОкончаниеПример (gelmek)
Ben-mgelmiştim
Sen-ngelmiştin
O∅ (нулевое)gelmişti
Biz-kgelmiştik
Siz-niz/-nızgelmiştiniz
Onlar-ler/-largelmişlerdi
Onlar: форма особая — gelmiş + ler + di (суффикс -di, а не -ti, потому что после -ler идёт -di; некоторые спрягают как gelmişlerdi). В разговорном языке часто просто gelmişti для всех 3-х лиц.

Когда используется?

Плюсквамперфект нужен, когда есть два прошедших события и одно предшествует другому:

Biz geldiğimizde, misafirler zaten gitmişti.
git + miş + ti (нулевое окончание, 3 л. ед.ч.)
Когда мы пришли, гости уже ушли.
Toplantı başlamadan önce, Ali raporu hazırlamıştı.
hazırla + mış + tı (3 л. ед.ч.)
До начала встречи Али уже подготовил доклад.
Seni selamlamıştım ama görmemişsin.
selamla + mış + tı + m (1 л. ед.ч.)
Я уже поздоровался с тобой, но ты не заметил.
O evi kaldırmışlardı çoktan.
kaldır + mış + lar + dı (3 л. мн.ч.)
Они давно уже снесли/убрали тот дом.
Davetiyeyi göndermiştin mi?
gönder + miş + ti + n + mi (2 л. ед.ч., вопрос)
Ты уже отправил приглашение?
Adet olduğu için, ev sahibi herkesi selamlamıştı.
selamla + mış + tı (3 л. ед.ч.)
По обычаю, хозяин уже успел поприветствовать каждого.

✍️ Упражнения по грамматике

1. Выбери правильную форму плюсквамперфекта: «Мы уже пригласили их» (davet etmek, biz).

Плюсквамперфект biz: корень + -mIş + -tI + -k; -DI past = простое прошедшее, -(y)EcEK-tI = «собирались».

2. Образуй плюсквамперфект 3 л. ед.ч. от глагола kaldırmak (он уже убрал).

Последняя гласная корня kaldır- — «ı» (задний ряд) → суффикс -mış; затем -tı (FSTKÇŞHP: ş → t); окончание 3 л. ед.ч. — нулевое.

3. Выбери верное объяснение разницы между -dı и -mıştı.

Вспомни: плюсквамперфект — это «уже сделал к тому моменту»; -dı — стандартное прошедшее очевидного факта.

4. Переведи: «Когда она пришла, я уже попрощался» (veda etmek, ben).

Фразовый глагол veda et-: основа оканчивается на -t (согласная) → -miş (передние гласные e, i); затем -ti + m (1 л. ед.ч.).

5. Вставь нужный суффикс -mIş: Onlar bizi zaten davet et___lerdi.

Глагол davet et-: последняя гласная основы — e (передний, нелабиализованный) → суффикс -miş.

6. Образуй плюсквамперфект 1 л. мн.ч. от konuk etmek (мы уже приняли гостей).

Основа konuk et-: последняя гласная e → -miş; далее -ti + k (biz).

7. Переведи: «К концу курса я уже сделал большой прогресс» (ilerlemek, ben, çok).

Глагол ilerle-: последняя гласная e → -miş; -ti + m (ben); основа оканчивается на гласную — буфер не нужен.

8. Что неверно в этой форме? Selamlamıştı — выбери правильное объяснение.

Проверь по правилу FSTKÇŞHP: -mış оканчивается на ş → следующий суффикс начинается на t, а не d; 3 л. ед.ч. имеет нулевое окончание.

🧭 Мини-ревью урока

  • Плюсквамперфект = -mIş + tI + личное окончание. Описывает действие, завершённое до другого прошедшего момента: «уже сделал к тому времени».
  • Гармония гласных в -mIş: a/ı → -mış, e/i → -miş, o/u → -muş, ö/ü → -müş. Определяется последней гласной основы глагола.
  • Почему -tI, а не -dI? Потому что -mIş оканчивается на ş — твёрдый согласный (FıSTıKÇı ŞaHaP). Следующий суффикс начинается на t.
  • Нулевое окончание для O (3 л. ед.ч.): gelmişti, selamlamıştı — ничего не добавляем.
  • Сегодняшняя лексика: selamlamak (приветствовать) · konuk etmek (принять гостей) · veda etmek (прощаться) · kaldırmak (поднимать/убирать) · adet (обычай) · cömert (щедрый) · kibar (вежливый) · kaba (грубый).
