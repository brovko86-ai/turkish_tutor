⚡ Recall — быстрая грамматическая проверка

Тема: -arak/-erek. Как сказать «Я пришёл, бегу» (= пришёл бегом)?
Деепричастие образа действия: koş + -arak (задний ряд); geldim = прошедшее 1 л. ед.ч.
Тема: future -EcEK. Переведи: «Она не придёт завтра».
Отрицательное будущее: gel + -me + -yecek (передний ряд); личное окончание 3 л. — нулевое.
Тема: instrumental -le/-la. Чем отличаются эти предложения? Выбери правильный перевод «Я пишу ручкой».
Инструментальный падеж «с помощью чего» = -(y)le/la; kalem оканчивается на согласную → kalem-le.
Тема: nominal predicate değil. Как сказать «Он не учитель»?
Отрицание именного сказуемого: [существительное] + değil; никаких суффиксов к имени не нужно.

🎯 Глагол дня — sıkılmak

sıkılmak — скучать / надоедать / чувствовать усталость от чего-либо. Это возвратно-пассивная форма от sıkmak (сдавливать, наскучивать). Управление: -DEN sıkılmak (скучать от чего-то).

Основа: sıkıl- (sık + -ıl, пассив/возвратный)
Управление: [чем/кем] + -DEN sıkılmak
Гармония: задний ряд ı → суффиксы на ı/a

Спряжение в трёх временах

Лицо-ıyor (сейчас)-dı (прош.)-(y)acak (буд.)

osıkılıyorsıkıldısıkılacak

Живые примеры

Bu derslerden sıkılıyorum.
sıkıl + -ıyor + -um | -DEN → «от этих уроков»
Мне надоедают эти уроки.
Çocuklar evde sıkıldı.
sıkıl + -dı → прош.вр., 3 л. мн.ч.
Дети заскучали дома.
Toplantıdan çabuk sıkılırsın.
sıkıl + -ır (aorist) + -sın | предположение
Ты быстро заскучаешь на совещании.
Rahatsız olduğunda sıkılmak normaldir.

Когда тебе некомфортно, скучать — нормально.
Hiç sıkılmayacağım, çünkü yeni bir kitabım var.
sıkıl + -ma (отриц.) + -y-acak + -ım

📖 Пассив — закрепление теории (Сессия 2)

Сессия 2 — углубляем: пассив в разных временах, агент действия, особые случаи.

Пассив: глагольная основа + -IL/-İL/-UL/-ÜL (после согласной)
глагольная основа + -N (после гласной)

+ стандартные суффиксы времени и лица

Таблица гармонии гласных

Последняя гласная корняСуффикс пассиваПример
a / ı-ıl / -ınyazmak → yazılmak
e / i-il / -inkesmek → kesilmek
o / u-ul / -unbulmak → bulunmak
ö / ü-ül / -ünçözmek → çözülmek

Агент действия: tarafından

Bu eser ünlü bir şair tarafından yazıldı.
yaz + -ıl + -dı → yazıldı | «автором» = tarafından
Это произведение было написано знаменитым поэтом.
Mektup müdür tarafından imzalanacak.
imzala + -n (осн. на гл.) + -acak → imzalanacak
Письмо будет подписано директором.

Пассив в разных временах

Rapor inceleniyor.
incele + -n + -iyor → настоящее продолженное
Отчёт сейчас рассматривается/проверяется.
Sorun çözülecek.
çöz + -ül + -(y)ecek → будущее время
Проблема будет решена.
Özgürlük herkes tarafından savunulmalı.
savun + -ul + -malı → долженствование в пассиве
Свобода должна защищаться каждым.
DİKKAT ET! Глаголы, оканчивающиеся на -l, образуют пассив с -ın/-in/-un/-ün, а не -il:
bulmak → bulunmak (а не bulılmak!). То же: almak → alınmak, salmak → salınmak.
💡 Пассив + -ken (пока): Kitap okunurken ses çıkarma. — Пока читают книгу, не шуми. Пассив прекрасно сочетается с -ken для одновременных действий.

✍️ Упражнения по грамматике

1. Образуй пассив: kesmek (резать) → ?
Основа kес- оканчивается на согласную; последняя гласная е → пассивный суффикс -il.
2. Образуй пассив: yakalamak (поймать) → ?
Основа yakala- оканчивается на гласную а → пассив суффикс -n; yakala + -n → yakalanmak.
3. Поставь в пассив настоящего времени (3 л. ед.ч.): «Документ рассматривается» (belge incelemek).
incelemek → основа incele- + пассив -n → inceleniyor; belge — подлежащее, глагол в 3 л. ед.ч.
4. Вставь правильную пассивную форму прошедшего времени: «Свобода была объявлена» (özgürlük ilan etmek).
ilan etmek — составной глагол; пассив образуется от et-: et + -il → edildi (передний ряд, e → i).
5. Переведи: «Проект был развит (усовершенствован) нашей командой» — используй пассив от geliştirmek.
geliştirmek → geliştir + -il → geliştirildi; «нашей командой» = ekibimiz tarafından.
6. Выбери правильный вариант: «Равенство должно соблюдаться всеми» (eşitlik, gözetmek).
Пассив долженствования: gözetilmeli; агент «всеми» = herkes tarafından.
7. Образуй пассив будущего от göndermek (отправить), 1 л. ед.ч.: «Я буду отправлен».
Пассив от göndermek → gönderil-; будущее -(y)ecek + смягчение к→ğ перед гласной + -im для ben.
8. Переведи на турецкий: «Знания закрепляются на практике» (bilgiler pekiştirmek / uygulama).
pekiştirmek → pekiştir + -il → pekiştirilir (аорист пассив для регулярных фактов); «на практике» = uygulamayla (инструментальный).

🧭 Мини-ревью урока

  • ✅ Пассив от согласной основы: корень + -IL/-İL/-UL/-ÜL → zap-ıl, kes-il, bul-ul, çöz-ül
  • ✅ Пассив от гласной основы: корень + -N → yakalanmak, okunmak, söylenmek
  • ✅ Исключение: основа на -l → пассив через -ın/-in/-un/-ün: bulmak → bulunmak
  • ✅ Агент в пассивной конструкции: [агент] + tarafından + пассивный глагол
  • ✅ Пассив работает во всех временах — просто добавляй -yor/-di/-ecek/-meli после пассивного суффикса
  • ⚠️ Частая ошибка: Не путай -il (пассив) и -dir (нарративное прошлое) — разные суффиксы с разными функциями!
Формула пассива: [корень] + [-IL/-N] + [-время] + [-лицо]
Пример: göndermek → gönder + -il + -ecek + -im = gönderileceğim
