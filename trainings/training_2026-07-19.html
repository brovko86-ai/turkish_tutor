⚡ Recall — быстрые проверки

-arak/-erek (слабая тема): Выбери правильную форму деепричастия для глагола koşmak (бежать):
-arak после задних гласных (a/ı/o/u), -erek после передних (e/i/ö/ü). Корень koş → последняя гласная o → задняя.
Инструменталис -le/-la (слабая тема): Вставь верную форму: «Я еду на автобусе» → Otobüs___ gidiyorum.
Последняя гласная в «otobüs» — ü (передняя) → суффикс -le. Твёрдый согласный на конце: просто -le без йотации.
Future -EcEK (слабая тема): Проспрягай «мы напишем» от yazmak:
yaz- (задняя a) → -acak + личное окончание 1pl -ız; буфер -ğ- перед гласным окончанием: yaz-acak → yazacağız.
FSTKÇŞHP: Верно ли добавлен суффикс прошедшего времени? «kitap + -dı = kitapda»
FıSTıKÇı ŞaHaP: слово на -p → суффикс с -d меняется на -t. Местный падеж: -ta/-te, не -da/-de.

🎯 Глагол дня — kararlaştırmak

kararlaştırmak — решать / договариваться (принять совместное решение)

Управление: ne yapmaya karar vermek (что сделать) — kararlaştırmak уже содержит идею «принятия решения» внутри себя. Сочетается с прямым объектом в винительном падеже.

📖 Новая грамматика — Пассивный залог (-IL / -IN / -N)

Пассивный залог в турецком отвечает на вопрос «что было сделано?» — без указания исполнителя (или с ним через суффикс -tarafından / -ce). Добавляется между корнем глагола и временным суффиксом.

Корень глагола + ПАССИВНЫЙ суффикс + временной суффикс + личное окончание

Выбор пассивного суффикса:
— Корень на согласный (кроме -l): + -il / -ıl / -ul / -ül (4-вариантная гармония)
— Корень на -l: + -in / -ın / -un / -ün (чтобы не было двух -l подряд)
— Корень на гласный: + -n

Таблица гармонии гласных

Последняя гласная корняСуффикс (корень на согл.)Пример
a / ı-ılyaz → yazılmak (быть написанным)
e / i-ilsev → sevilmek (быть любимым)
o / u-uloku → okunmak* (быть прочитанным) *корень на гл. → -n
ö / ü-ülgör → görülmek (быть увиденным)

Примеры с декомпозицией

Bu kitap çok okunuyor.
oku (читать, на гласную) + -n (пассив) + -uyor (наст. вр.)
Эту книгу очень читают. / Эта книга очень читается.
Mektup dün yazıldı.
yaz (писать) + -ıl (пассив, a→ıl) + -dı (прошед.)
Письмо было написано вчера.
Karar yarın açıklanacak.
açıkla (объявлять, на гласную) + -n (пассив) + -acak (будущ.)
Решение будет объявлено завтра.
Pencereler temizlendi.
temizle (на гласную) + -n (пассив) + -di (прошед.)
Окна были вымыты.
Bu şehirde çok dil kullanılıyor.
kullan (использовать, -n на конце) + -ıl (пассив, a→ıl) + -ıyor
В этом городе используется много языков.
Haberi duydunuz mu? Rapor bildirildi.
bildir (сообщать) + -il (пассив, i→il) + -di
Вы слышали новость? Доклад был объявлен.
DİKKAT! Пассив -IL и каузатив -DIR можно перепутать:
• yaz-ıl-dı = было написано (пассив — кто-то написал)
• yaz-dır-dı = заставил написать (каузатив — приказал кому-то написать)
Ключ: -IL/-IN/-N = пассив (исполнитель скрыт); -DIR/-T/-IR = каузатив (есть тот, кто приказал).
💡 Исполнитель в пассиве добавляется через tarafından (буквально «со стороны»): Kitap yazar tarafından imzalandı — книга была подписана автором.

✍️ Упражнения по грамматике

1. Выбери верную пассивную форму глагола göndermek (отправлять) для «посылка была отправлена»:
gönder- (передний e) + -il (пассив) + -di (прошед.): gönder-il-di. Основа не на -l, значит -il, не -in.
2. Какой суффикс пассива нужен для bulmak (находить, корень: bul-)? Основа оканчивается на -l.
Когда корень оканчивается на -l, берём вариант -un/-ün/-ın/-in (чтобы избежать двух l подряд). Последняя гласная u → -un.
3. Переведи пассив на турецкий: «Эта песня слышится повсюду.» (duyulmak, her yerde, bu şarkı)
duyu- (слышать) оканчивается на гласную → пассив -l → duyul- + -uyor (настоящее).
4. Чем пассив отличается от каузатива? Определи: «Öğretmen ödevi yazdırdı» — это...
yazdır- = yaz- + каузатив -dır. Учитель (субъект) воздействует на кого-то другого, кто пишет. Это каузатив, не пассив.
5. çözülmek — это пассив от çözmek. Переведи: «Проблема решилась сама по себе.»
çöz- (передний ö) + -ül (пассив) + -dü (прошед.): çözüldü. Слово «само по себе» = kendiliğinden.
6. Выбери правильную пассивную форму для «решение было принято» (kararlaştırılmak):
kararlaştır- оканчивается на -r (согласный, не -l) → пассив -ıl (последняя гласная a/ı → -ıl) → kararlaştır-ıl-dı.
7. Вставь верную форму пассива: «Новый закон будет объявлен на следующей неделе.» (bildirilmek, gelecek hafta, yeni kanun)
bildir- (передний i) + -il (пассив) + -ecek (будущее, передняя гласная): bildir-il-ecek.
8. Определи: в каком предложении использован пассив (а не каузатив)?
Пассив — субъекта нет, объект сам «подвергается» действию. Ищи -ıl/-il/-ul/-ül/-n/-in/-ın после корня.

🧭 Мини-ревью урока

  • Пассивный залог в турецком отвечает на «что было сделано?» — исполнитель скрыт или добавлен через tarafından.
  • Три варианта суффикса: корень на согласный (не -l) → -ıl/-il/-ul/-ül; корень на -l → -ın/-in/-un/-ün; корень на гласную → -n.
  • Пассивный суффикс ставится МЕЖДУ корнем и временным суффиксом: yaz + ıl + dı = yazıldı.
  • Главное отличие от каузатива: -IL = исполнитель скрыт (что-то случилось с объектом); -DIR/-T = есть тот, кто приказал/заставил.
  • Глагол дня kararlaştırmak: karar + laş + tır — содержит и взаимный, и каузативный суффиксы; пассив от него: kararlaştırıldı.
