⚡ Recall — быстрая проверка

Темы из диагностики — закрепляем слабые места.

🔸 -ARAK / -EREK — «делая / путём»

Выбери правильную форму: «Он вошёл в комнату, не постучав.»
💡 «Не делая» = -madan/-meden (отрицательный деепричастный суффикс). -arak/-erek — только для «делая» (утвердительного).

🔸 Будущее время -EcEK

Поставь в будущее время: «seyahat etmek» — «мы будем путешествовать»
💡 Корень et- → перед -EcEK буква t озвончается: ed-eceğiz. Личное окончание для «biz» (мы) — -iz.

🔸 Суффикс -DEKİ

Переведи: «Книга на столе (та, что на столе) очень интересная.»
Используй: masa, kitap, ilginç
💡 -deki = (-da локатив) + (-ki «тот, который»). Masa + -da = masada → masada + -ki = masadaki. Затем kitap (подлежащее) и сказуемое.

🔸 Инструментальный падеж -LE/-LA

Выбери правильный вариант: «Она поехала в Стамбул на поезде.»
💡 Транспорт + -le/-la = «на чём». Tren оканчивается на n (мягкий согласный) → -le (передний вокал? нет, e → -le). Tren → trenle.

🎯 Глагол дня: hazırlanmak

Значение: готовиться / подготавливаться
Управление: -e / -a (к чему? для чего?)
Состав: hazırla- (готовить) + -n (пассивно-возвратный суффикс) + -mak

Состав слова: hazır (готовый) → hazırla-mak (готовить) → hazırlan-mak (готовиться самому). Суффикс -n — это рефлексивный суффикс: действие направлено на себя.

Спряжение в трёх временах

Лицо-(I)yor (сейчас)-DI (прошедшее)-(y)EcEK (будущее)

DİKKAT! Корень hazırlan- оканчивается на -n (согласный). В прошедшем времени -DI: последний согласный n — мягкий (не входит в FSTKÇŞHP), значит суффикс -dı/-di/-du/-dü (не -tı). Задние гласные в корне (a, ı) → -dı.

На завтра нужно подготовить очень много всего.

📖 Новая грамматика: Каузатив — суффикс -DİR / -T / -IR

Каузатив позволяет сказать «заставить кого-то сделать» или «сделать так, чтобы что-то произошло». В турецком это реализуется суффиксом, который вставляется между корнем глагола и стандартными суффиксами времени.

Формула

КОРЕНЬ + -DİR / -T / -IR / -ER / -AR + суффикс времени + личное окончание

yazmak (писать) → yaz + dır + mak = yazdırmak (заставить написать)
okumak (читать) → oku + t + mak = okutmak (заставить читать / учить)
gitmek (идти) → git + tir + mek = gittirmek (отправить / заставить уйти)

Три основных суффикса и когда что выбирать

СуффиксКогда применяетсяПримеры
-DİR / -DIR / -DUR / -DÜR Самый распространённый. Добавляется к большинству глаголов, оканчивающихся на согласный yaz-dır, gel-dir, koş-tur, gör-dür
-T Краткий вариант. Для коротких корней на гласную (1–2 слога) и для ряда исключений oku-t, uyu-t, içi-t → iç-ir
-IR / -ER / -AR Для некоторых часто встречающихся глаголов с коротким корнем — исторически сложившаяся форма çık-ar (вывести), bat-ır (утопить), düş-ür (уронить)
DİKKAT! Гармония гласных работает и здесь:
• Последняя гласная корня a/ı → -dır / -tır
• Последняя гласная e/i → -dir / -tir
• Последняя гласная o/u → -dur / -tur
• Последняя гласная ö/ü → -dür / -tür

Также действует правило FıSTıKÇı ŞaHaP: если последний согласный корня — твёрдый (ç, f, h, k, p, s, ş, t), то -d → -t: koş-tur, iç-ir.

✍️ Упражнения — Каузатив

1. Выбери правильную каузативную форму: «заставить бежать» (koşmak)
💡 Корень koş- оканчивается на ş — это буква из FSTKÇŞHP, значит мягкий суффикс -d становится -t. Гласная в корне o/u → суффикс -tur.
2. «Мама уложила ребёнка спать» — выбери верный вариант (uyumak).
💡 Короткий корень uyu- (оканчивается на гласную) → каузатив -t: uyu-t. Прошедшее время: uyut-tu (FSTKÇŞHP: t → -tu).
3. Образуй каузатив: yaz-mak → «я заставил написать» (прошедшее, 1л. ед.ч.)
💡 yaz- + dır (гласная a → -dır) + -dı (прошедшее, FSTKÇŞHP нет) + -m (я) = составь последовательно.
4. «Он рассмешил всех» — образуй форму от gülmek (прошедшее, 3л. ед.ч.)
💡 Корень gül- (гласная ü → -dür) + суффикс -dür + прошедшее -dü + личное ∅ (3л.). Обрати внимание на согласование гласных в каждом суффиксе.
5. Что значит: Köpeği korkuttum.?
💡 korkut- = кауз. от korkmak. Köpeği — винительный (собаку). Подлежащее ben (я). Каузатив → действие исходит от подлежащего к объекту.
6. Переведи: «Они заставили нас ждать целый час.»
Опорные слова: beklemek, bir saat, bizi
💡 bekle- + t (короткий корень на гласную) = beklet. Прошедшее 3л.мн.ч.: -tiler. Объект bizi (нас) стоит перед глаголом.
7. Как сказать «накормить ребёнка» (от yemek — есть)?
💡 yemek — нерегулярный глагол. Корень ye- → каузатив ye-dir → при слиянии: ye-dir → yedir-mek → yeDir → но историческая форма yedir-. Запомни как исключение.
8. Что разного в этих двух предложениях? Выбери верное объяснение:
А) Mektup yazıldı.
Б) Ona mektup yazdırdım.
💡 Пассив (-IL/-IN) убирает исполнителя. Каузатив (-DIR/-T) добавляет «организатора» — того, кто велел сделать.
9. Составь предложение по схеме: «Директор заставил нас готовиться к собранию.»
Слова: müdür, biz, toplantı, hazırlanmak
💡 hazırlan- (готовиться) → кауз.: hazırla-t (убираем -n возвратный, добавляем -t). Bizi = нас (винительный). Toplantıya = к собранию (дательный). Прошедшее 3л.: -tı.
10. Выбери единственно правильную каузативную форму от içmek (пить) в смысле «заставить выпить».
💡 iç- оканчивается на ç (из FSTKÇŞHP). Для этого глагола исторически сложился суффикс -ir: iç-ir. Гармония: гласная i → суффикс -ir.
