Тема: -ARAK / -EREK (деепричастие «делая»)

Выбери правильную форму деепричастия от глагола gülmek (смеяться) для предложения: «Она вышла из комнаты, смеясь.»
💡 Посмотри на последнюю гласную корня: gül- → передняя гласная (ü) → суффикс -erek. -arak идёт после задних гласных (a/ı/o/u).
Переведи на турецкий: «Он объяснил, показывая рукой.»
Используй: göstermek (показывать) + -erek.
💡 Корень göster- → передняя гласная (e) → -erek. «Рукой» = eliyle (el + посессив i + -yle). «Объяснил» = açıkladı.

Тема: Будущее время -EcEK

Поставь глагол öğrenmek (учиться/узнавать) в будущее время для «мы»:
«Bu yıl Türkçe _______.» (В этом году мы выучим турецкий.)
💡 -EcEK + личное окончание «biz» = -eceğiz (k → ğ перед гласным окончанием). Корень öğren- → передняя гласная → -ecek.

Тема: -DİĞİ İÇİN («потому что сделал»)

Выбери правильный вариант для предложения: «Она пришла поздно, потому что опоздала на автобус.»
Otobüsü _______ geç geldi.
💡 Вербальное имя с причинным значением: корень + -tığı/-diği + için. kaç- → твёрдый согласный Ç (FSTKÇŞHP!) → -tığı için.

🎯 Глагол дня

pişirmek ГЛАГОЛ
готовить (еду) / варить / жарить / запекать
Управление: pişirmek → объект в вин. падеже (-i/-ı/-u/-ü)

pişirmek — каузативная форма от pişmek (готовиться, вариться само по себе). То есть буквально: «заставить что-то приготовиться» → «готовить»! Это живой пример каузатива, встроенного в лексику языка.

pişmek (готовиться) + -ir = pişirmek (готовить)

Спряжение

Живые примеры

Annem her sabah kahvaltı pişiriyor.
annem (моя мама) · kahvaltı (завтрак, вин. не нужен — неопр.) · pişir-iyor (готовит)
Моя мама каждое утро готовит завтрак.
Bu yemeği ağabeyim pişirdi.
bu yemeği (это блюдо, вин.) · ağabeyim (мой старший брат) · pişir-di (приготовил)
Это блюдо приготовил мой старший брат.
Makarnayı nasıl pişiriyorsun?
makarnayı (макароны, вин.) · nasıl (как) · pişir-iyor-sun (ты готовишь)
Как ты готовишь макароны?
Yarın arkadaşlarıma yemek pişireceğim.
yarın (завтра) · arkadaşlarıma (друзьям, дат.) · yemek (еда) · pişir-ecek-im (приготовлю)
Завтра я приготовлю еду для друзей.
Çocukluğumda annem bana masal anlatarak yemek pişirirdi.
çocukluğumda (в детстве) · annem (мама) · bana (мне) · masal anlatarak (рассказывая сказки) · yemek pişirirdi (готовила еду, привычное прошлое)
В детстве мама готовила мне еду, рассказывая сказки.
🔗 Родственные слова:
pişmek — готовиться (о еде само по себе): Çorba pişiyor. (Суп варится.)
pişmiş — приготовленный, сваренный
çiğ — сырой (антоним: çiğ sebze — сырые овощи)
piş-ir-t-mek — заставить кого-то приготовить (двойной каузатив!)
DİKKAT ET! pişmek (готовиться само) ≠ pişirmek (готовить/варить).
Çorba pişti. (Суп сварился.) — само по себе
Çorbayı pişirdim. (Я сварил/а суп.) — кто-то приготовил
Буква -ir- — это и есть каузативный суффикс!

📖 Каузатив — углублённый разбор (Сессия 2)

Сегодня идём дальше: смотрим на цепочки каузативов, на нюансы управления и на отличие от пассива. Это поможет читать живые тексты и строить сложные предложения.

Напоминание: выбор суффикса

Односложные глаголы с согласным на конце → -DIR / -DİR / -DUR / -DÜR
gitmek → gittirmek · içmek → içirmek (исключение!)

Глаголы на гласную → -T
okumak → okutmak · boyamak → boyatmak

Многосложные глаголы → -IR / -ER / -UR / -ÜR (гармония!)
pişmek → pişirmek · kork- → korkutmak

Двойной каузатив (редко, но встречается)

Иногда каузативный суффикс добавляется дважды — «заставить заставить»:

Müdür ona raporu yazdırtacak.
yaz + dır + t → yaz-dır-t-mak (заставить кого-то заставить написать)
Директор прикажет ему заставить написать отчёт. (редко в обиходной речи)
DİKKAT ET! Каузатив ≠ Пассив
Kauzatif: «я заставляю кого-то делать» → субъект активен
Pasif: «что-то делается» → субъект не упоминается

Kauzatif: Öğretmen öğrenciye kitabı okuttu. (Учитель заставил ученика прочитать книгу.)
Pasif: Kitap okundu. (Книга была прочитана.)

✍️ Упражнения по каузативу

1. Какой каузативный суффикс нужен для глагола gelmek (приходить)?
💡 gel- — односложный корень, заканчивается на согласную. Применяется тот суффикс, который идёт с односложными. Гармония гласных: e → передняя гласная.
2. Образуй каузатив от oturmak (сидеть/жить).
💡 otur- — многосложный, на согласную → суффикс -t (краткий вариант для многосложных). o/u — задние гласные, → форма с у.
3. Переведи: «Учитель заставил учеников прочитать текст.»
Используй: okumak → okutmak · metin (текст) · öğrencilere (ученикам)
💡 «Ученикам» = дательный падеж (-e). «Текст» = metin → вин. падеж (metni, согл. конец + i). Прошедшее от okutmak: okut- → окончание -tu (FSTKÇŞHP: t → tt → okuttu).
4. Преврати в каузатив: ağlamak (плакать). Вставь правильную форму:
«Bu film beni çok _______.» (Этот фильм меня очень расстроил / довёл до слёз.)
💡 ağla- заканчивается на гласную → суффикс -t. Прошедшее время от 3-го лица: -tı (задняя гласная а). FSTKÇŞHP: t → tt перед -ı/-i.
5. Вставь правильные падежные окончания:
«Annem biz___ oda___ temizlett___»
(Мама заставила нас убрать комнату.)
💡 Тот, кого заставляют = дательный (-e/-a). Объект действия = винительный (-i/-ı). temizle- + t (гласная конец) + ti (прош. вр.) → temizletti.
6. Переведи вопрос: «Кто заставил тебя это написать?»
Используй: yazmak → yazdırmak · bunu (это)
💡 Тебя = sana (дательный). yaz- + dır + -dı → yazdır-dı (прошедшее). Вопрос: kim (кто) + вопросительный порядок слов (стандартный).
7. Какое из предложений построено правильно?
💡 Тот, кого заставляют, стоит в дательном падеже (-e/-a), а не в винительном или аблативном. ben → bana (1 лицо, дат.).
8. В каком из слов НЕТ каузативного суффикса, а -ir/-er — часть корня?
💡 Подумай: есть ли базовый глагол, от которого это образовано прибавлением суффикса? У одного из вариантов -r — это просто часть инфинитивного глагола.

🎨 Свободная продукция

Составь 3–5 предложений на тему: «Что ты заставляешь / заставлял других делать — или что тебя заставляли делать?»
Используй каузативные формы, которые сегодня учили.

💡 Опорные слова и структуры:
• ağabeyim / kardeşim / arkadaşım — мой старший брат / брат или сестра / друг
• tanımak → «beni ona tanıttı» (познакомил меня с ним — каузатив от tanımak!)
• pişirmek → «bize yemek pişirtti» (заставил нас приготовить)
• dolayı: «yorgunluk dolayı» — из-за усталости
• ağlatmak, korkutmak, güldürmek — расстроить, напугать, рассмешить
• müdür / öğretmen → -e metni okutt-, raporu yazdırt-
Примеры с разбором:

🔹 Annem bize erken yatmayı söyletti.
→ anne (мама) · bize (нам, дат.) · erken yatmayı (раннее укладывание, вин.) · söyle-t-ti (заставила сказать/сказала, что...)

🔹 Ağabeyim dolayı eve geç geldim. ← ошибка! dolayı требует -den:
✅ Ağabeyim yüzünden eve geç geldim. (Из-за брата пришёл домой поздно.)

🔹 Öğretmen bizi ağlattı — çok zor bir sınav yaptı.
→ ağla-t-tı (расстроила/довела до слёз) · zor sınav (трудный экзамен)

🔹 Arkadaşımı tanıttırdım. — Я познакомил (кого-то с кем-то).
→ tanı + t (каузатив) + tır (ещё один каузатив!) → tanıttır-; в обиходной речи чаще: tanıştırdım (через tanışmak)

🧭 Мини-ревью урока

1. Суффиксы каузатива:

-DIR/-DİR/-DUR/-DÜR → односложные на согласную (gitmek → gittirmek)
-T → на гласную (okumak → okutmak)
-IR/-ER/-UR/-ÜR/-T → многосложные (pişmek → pişirmek)

2. Падежи в каузативном предложении:

Кто заставляет → именительный (без суффикса)
Кого заставляют → дательный -E / -A
Что делают (объект) → винительный -İ / -I / -U / -Ü

3. Главная формула:

[СУБЪЕКТ] + [кого заставляют, -E] + [объект, -İ] + ГЛАГОЛ-каузатив + время + лицо

4. Типичная ошибка:

❌ Annem beni yemek yedirdi. (beni = винительный — ошибка)
✅ Annem bana yemek yedirdi. (bana = дательный — верно)
Тот, кого заставляют, всегда в дательном падеже!

5. Полезные каузативы из обихода:

güldürmek — смешить
pişirmek — готовить (еду)
çalıştırmak — включать / запускать
öğretmek — учить (нерегулярный каузатив от öğrenmek!)
