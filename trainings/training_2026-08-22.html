⚡ Recall — быстрая проверка

Слабые темы по экзамену: -arak/-erek и future -EcEK.

Задание 1 · -arak/-erek

Выберите правильную форму: «Он пришёл, напевая песню.» (şarkı söylemek — петь)
-erek = «делая что-то» (корень оканчивается на гласную → -yerek); «пришёл» = прошедшее время.

Задание 2 · Будущее время -EcEK

Заполните: «Они поддержат этот проект.» → Bu projeyi _______.
desteklemek → корень destekle- + -yecek (буфер y, т.к. корень на гласную) + -ler (3 мн.ч.).

Задание 3 · Instrumental -le/-la

Выберите правильный вариант: «Я поеду поездом.»
Инструменталь -le/-la: последняя гласная слова tren — e (передняя) → суффикс -le.

🎯 Глагол дня — kaydetmek

kaydetmek
kayıt (запись) + etmek (делать) → записывать / сохранять
Управление: neyi kaydeder? (что записывает? — винительный падеж)

Спряжение

Лицо-yor (наст.)-DI (прош.)-(y)EcEK (буд.)
benkaydediyorumkaydettimkaydedeceğim
senkaydediyorsunkaydettinkaydedeceksin
okaydediyorkaydettikaydedecek
bizkaydediyoruzkaydettikkaydedeceğiz
sizkaydediyorsunuzkaydetdinizkaydedeceksiniz
onlarkaydediyorlarkaydettilerkaydedecekler
DİKKAT ET! kaydetmek — сложный глагол (kayıt + etmek). В спряжении используется усечённый корень kaydet-, но перед гласным суффиксом происходит озвончение: kayded- (t → d). Это стандартное правило FSTKÇŞHP наоборот: перед гласным t озвончается в d.

Примеры

Dersi kaydettim.
kaydet- + -ti + -m → прошедшее, 1-е лицо
Я записал(а) урок.
Lütfen bunu kaydedin.
kaydet- + повелительное 2-е мн.ч. / вежливое
Пожалуйста, сохраните это.
Telefonu kaydedecekler.
kayded- + -ecek + -ler → будущее, 3-е мн.ч.
Они запишут звонок.
Bu uygulamayla kolayca kaydedebilirsin.
kayded- + -ebil- (мочь) + -ir + -sin
С этим приложением ты можешь легко сохранить.
Verimli bir toplantıyı kaydetmek önemlidir.
инфинитив как подлежащее
Записывать продуктивное совещание — важно.
Однокоренные слова: kayıt (запись, существительное) · kayıtlı (зарегистрированный) · kayıt defteri (журнал / тетрадь) · kaydol- (зарегистрироваться, разг.)

📖 Новая грамматика — Каузатив: суффиксы -DIr / -t / -Ir

Каузатив — конструкция «заставить / велеть / дать кому-то сделать что-то». В турецком это суффикс, который добавляется к корню глагола — и всё выражается одним словом.

Корень глагола + каузативный суффикс + обычные суффиксы времени
yaz- → yazdır-mak (заставить писать)
oku- → okut-mak (заставить читать)
gül- → güldür-mek (рассмешить / заставить смеяться)

Подлежащее (кто заставляет) + [кого/кому — дат. или вин.] + объект + глагол-каузатив

Три основных суффикса

СуффиксКогда используетсяПример
-DIr / -Dır / -Dur / -DürБольшинство глаголов (самый частый)yaz → yazdır, iç → içir → içirt (редко)
-tГлаголы на -r, -l, -n, -ş (сонорные), а также некоторые на гласнуюoku → okut, uyu → uyut, gez → gezdir / gezdir
-Ir / -ArНесколько нерегулярных глаголов (учить отдельно)çık → çıkar, git → götür (супплетив)
Практическое правило: Если не знаешь, какой суффикс брать — попробуй -DIr. Для глаголов на -r, -l, -n, -ş — -t. Это покрывает ~85% случаев.

Гармония гласных суффикса -DIr

Последняя гласная корняСуффиксПример
a, ı-dıryaz → yazdır, kır → kırdır
e, i-dirbil → bildir, sev → sevdir
o, u-dursor → sordur, uç → uçtur (FSTKÇŞHP!)
ö, ü-dürgül → güldür, öl → öldür
DİKKAT ET! FSTKÇŞHP: Если корень оканчивается на глухой согласный (ç, k, p, t, ş, s, f, h) — -d в суффиксе каузатива оглушается до -t:
uç → uçtur (заставить лететь) · sat → sattır (заставить продать)

Примеры с разбором

Anne çocuğa kitap okuttu.
oku-t (каузатив от okumak) + -tu (прош.) → oku + t + tu → okuttu
Мама заставила ребёнка читать книгу.
Müdür raporu bana yazdırdı.
yaz + -dır (каузатив) + -dı (прош.) + имплицитное «мне» через dat.
Директор велел мне написать отчёт.
Bu film bizi çok güldürdü.
gül (смеяться) + -dür (каузатив, ö/ü) + -dü (прош.) + -bizi (нас, вин.)
Этот фильм нас очень рассмешил.
Öğretmen öğrencilere şarkıyı söylettti değil, söyletti.
söyle (петь) + -t (каузатив от глагола на -e) + -ti (прош.)
Учитель заставил учеников петь песню. (не söylettti — три t невозможно!)
Кто «исполнитель»? Тот, кого заставляют, стоит в дательном падеже (-e/-a): «Bana yazdırdı» = велел МНЕ написать. Если исполнитель не назван — он подразумевается из контекста.

✍️ Упражнения по грамматике

1. Образуйте каузатив от глагола silmek (стирать): какой суффикс?
silmek — корень на сонорный -l → каузатив -dir (последняя гласная i → -dir).
2. Переведите: «Я заставлю его поддержать проект.» (desteklemek + каузатив + будущее)
destekle- + -t (каузатив, корень на -e) + -(y)eceğim; onu = его (вин. пад.).
3. Какой каузативный суффикс нужен для глагола uçmak (летать)?
uç оканчивается на ç (глухой из FSTKÇŞHP) → -d оглушается до -t; последняя гласная u → -tur.
4. Выберите верное предложение: «Директор велел нам записать встречу.»
«Кому велел» = дательный -e/-a; каузатив от kaydetmek = kaydetdir → kaydet+tir+di → kaydettirdi.
5. Образуйте каузативную форму от uyumak (спать) в прошедшем, 1-е лицо: «Я усыпила ребёнка.»
uyu- + -t (каузатив, корень на гласную) + -tu + -m; çocuğu = ребёнка (вин. пад.).
6. Что означает davet ettirdi?
davet et- + -tir (каузатив, т.к. корень оканчивается на t — глухой) + -di → «заставил/велел пригласить».
7. Переведите: «Эта реклама эффективно привлекла внимание.» (dikkat çekmek — привлекать внимание; etkili bir şekilde)
dikkat çekmek — «привлекать внимание», прошедшее -DI, 3-е лицо; etkili bir şekilde = эффективным образом.
8. Выберите правильный каузатив от gülmek (смеяться):
gül — последняя гласная ü (передняя, огублённая) → суффикс -dür; l = сонорный, но здесь применяется -dür, т.к. корень gül (не на глухой).

🧭 Мини-ревью урока

  • Суть Каузатив = «заставить / велеть кому-то сделать». Строится суффиксом к корню глагола.
  • Суффиксы -DIr/-Dır/-Dur/-Dür (большинство глаголов) · -t (корень на сонорный или гласную) · нерегулярные (учить отдельно).
  • FSTKÇŞHP Корень на глухой → -d суффикса оглушается до -t: uç → uçtur, sat → sattır.
  • Исполнитель Тот, кого заставляют — дательный падеж (-e/-a): «Bana yazdırdı» = велел МНЕ написать.
  • Типичная ошибка Не пиши три одинаковые буквы подряд: söyle-t-ti = söyletti (не söylettti). В турецком это невозможно!
