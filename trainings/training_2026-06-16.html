⚡ Recall — быстрая грамматика

Темы из слабых зон экзамена. Два задания — разные темы.

Задание 1 · -ARAK/-EREK (делая / посредством)

Выбери правильную форму деепричастия от глагола koşmak («бежать»): «Он добрался до станции, бегом.»
💡 Правило: задние гласные (a/ı/o/u) → -arak; передние (e/i/ö/ü) → -erek. Последняя гласная koşmak — «o»

Задание 2 · Именное сказуемое + değil

Составь отрицание: «Это НЕ гость, это сосед.» (bu / misafir / değil / komşu)

💡 değil стоит сразу после именной части, перед запятой; порядок: Bu + [существительное] + değil

Задание 3 · Будущее время -(y)EcEK

Проспрягай: «Мы встретим гостей завтра.» (karşılamak + biz + yarın + misafirler)

💡 karşıla- оканчивается на гласную → -(y)acak (задние гласные) + личный суффикс biz: -ğız. Итого: karşıla-y-acak-ğız

Задание 4 · Вопросительные слова (ne/kim/nerede)

💡 ilgilenmek управляет с -le/-la. «Чем» = ne + -yle (вопросит. слово с инструментальным суффиксом)

🎯 Глагол дня — temizlemek (убирать / чистить)

temizlemek
temiz (чистый) + -le (глагольный суффикс) + -mek (инфинитив)
убирать, чистить, наводить порядок

Управление

Прямой объект (вин. падеж -i/-ı/-u/-ü): что чистишь?
evi temizlemek — убирать дом
dişleri temizlemek — чистить зубы

Спряжение

Лицо-iyor (наст.)-di (прош.)-(y)ecek (буд.)
bentemizliyorumtemizledimtemizleyeceğim
sentemizliyorsuntemizledintemizleyeceksin
otemizliyortemizleditemizleyecek
biztemizliyoruztemizlediktemizleyeceğiz
siztemizliyorsunuztemizlediniztemizleyeceksiniz
onlartemizliyorlartemizledilertemizleyecekler
DİKKAT! temizlemek оканчивается на гласную (-e), поэтому:
• перед -yor добавляется -i-: temizle + i + yor → temizliyor
• перед -(y)ecek вставляется -y-: temizle + y + ecek → temizleyecek
• в прошедшем -di присоединяется напрямую: temizle + di → temizledi

Живые примеры

Her sabah odamı temizliyorum.
oda-m-ı = комната-моя-вин. | temizli-yor-um = убираю
Каждое утро убираю свою комнату.
Annem mutfağı temizledi.
mutfak + -ı = кухню (вин.) | temizle + di = убрала
Мама убрала кухню.
Yarın evi beraber temizleyeceğiz.
temizle + y + ecek + ğiz = мы уберём
Завтра вместе уберём дом.
Dişlerini temizle! (повелит.)
temizle = imperativ 2-го л. ед.ч.
Почисти зубы!
Bu ilacı kullanarak yarayı temizleyebilirsin.
temizle-y-ebil-ir-sin = можешь очистить (потенциалис)
Используя это лекарство, можешь очистить рану.

Каузатив: temizletmek

💡 temizlemek + каузатив -t → temizletmek = заставить убраться / отдать в чистку
Arabamı temizlettim. — Я отдал машину в мойку (заставил почистить).
Обрати внимание: суффикс -t (не -dir), потому что корень оканчивается на гласную.

📖 Каузатив — углубление: двойной каузатив и тонкости

Быстрое повторение: какой суффикс выбрать?

Корень на согласную (большинство) → -DIr : okumak → okutmak*
Корень на гласную → -T : yemek → yedirmek  /  okumak → okutmak
Длинный корень (3+ слогов) → -IT/-UT/-ÜT/-IR : anlamak → anlatmak
* okumak — исключение: oku (гласная) → okutmak (не okudurmak)

Двойной каузатив

Турецкий допускает двойной каузатив — «заставить кого-то заставить кого-то»:

yemek → yedirmek → yedirilmek*
* yedirmek + пассив -il = «быть накормленным кем-то»
есть → кормить → быть накормленным
öldürmek → öldürtmek
öldür (убить) + -t = заставить убить
убивать → приказать убить

Управление падежами в каузативе

💡 Ключевое правило:
• Кто «заставляет» → именительный (подлежащее): Anne
• Кого заставляют → дательный -e/-a (если исходный глагол непереходный): çocuğa uyuttu
• Кого заставляют → дательный -e/-a (если переходный — объект остаётся в вин. падеже): çocuğa sebze yedirdi
Müdür sekretere mektubu yazdırdı.
sekreter + -e = дат. (кому приказал) | mektup + -u = вин. (что написать) | yaz + dır + dı = приказал написать
Директор заставил секретаря написать письмо.
Anne çocuğa uyuttu.
çocuğ + -a = дат. (кого уложила) | uyu + -t + tu = уложила спать
Мама уложила ребёнка спать.
DİKKAT! Разница между -dir и -t:
Если корень оканчивается на гласную: -t (okumak → okutmak, yemek → yedirmek*)
*yemek: ye- + dir = yedir (исключение — -dir, потому что корень односложный на гласную)
Если корень оканчивается на согласную: -dir/-dır/-dür/-dur с гармонией гласных

✍️ Упражнения по грамматике

1. Образуй каузатив от uyumak («спать»). Какая форма правильная?
💡 uyu- оканчивается на гласную -u. Для таких глаголов используй -t. Суффикс -dur добавляется к согласным.
2. Образуй каузатив от gülmek («смеяться»). Правильная форма?
💡 gül- оканчивается на согласную -l. Применяется -dür (передние гласные: ü). Гармония: ü → -dür.
3. Переведи на турецкий: «Учитель заставил детей прочитать книгу.» (okumak + çocuklar + kitap)

💡 oku- (гласная) + -t = okut-. Прошедшее: okuttu. Дети = çocuklar + -a (дат.). Книга = kitap + -ı (вин., определённый объект).
4. Какой падеж нужен для «кого заставляют», если исходный глагол непереходный?
💡 Непереходный глагол не имеет своего объекта → «жертва» каузатива получает дат. падеж.
5. Образуй каузатив от içmek («пить»). Какая форма?
💡 iç- оканчивается на согласную -ç. Гармония: последняя гласная -i → -ir. içirmek = поить.
6. Переведи на турецкий: «Я отдал машину в чистку.» (temizletmek + araba)

💡 temizletmek — каузатив от temizlemek. Прошедшее от temizlet-: основа + -ti + личный суффикс. ben: temizlet + tim → temizlettim (удвоение t).
7. Найди ошибку: «Anne çocuğu uyuttu.» Всё ли верно?
💡 uyumak — непереходный. «Кого укладывают» = дательный падеж, не винительный.
8. Переведи на турецкий: «Менеджер заставит нас работать допоздна.» (çalıştırmak + biz)

💡 çalıştırmak — уже в твоём словаре! Будущее время: çalıştır + acak (задн. гласные: ı). bizi = нас (вин. падеж, biz + -i). Müdür çalıştıracak = менеджер заставит работать.
9. Образуй каузатив от anlamak («понимать»). Какая форма?
💡 anlamak — длинный корень (3 слога, -a на конце). Для таких глаголов используется -t. anla + t = anlat- (рассказывать / объяснять) — это уже в твоём словаре!
10. Переведи на турецкий: «Мама поит ребёнка водой.» (içirmek + çocuk + su)

💡 içirmek — переходный каузатив. «Кому поит» = çocuğ + -a (дат.). Воду = su (неопределённый объект — без -yu). Наст. вр.: içir + iyor.

🧭 Мини-ревью урока

1. Каузатив = «заставить сделать». Суффикс выбирается по последнему звуку корня:
согласный → -DIr (с гармонией)  |  гласная (долгий корень) → -T  |  гласная (короткий) → -Dir
Запомни парами: uyumak→uyutmak, içmek→içirmek, gülmek→güldürmek
2. Падежи в каузативе:
• Кого заставляют = дательный -e/-a
• Объект действия (если есть) = винительный -i/-ı
Пример: Müdür sekretere raporu yazdırdı.
3. Многие знакомые глаголы — уже каузативы!
öğretmek (учить) ← öğrenmek | çalıştırmak ← çalışmak | güldürmek ← gülmek | anlatmak ← anlamak
4. Двойной каузатив: возможен, но редко используется в разговорной речи. Чаще встречается в юридических/литературных текстах: öldürtmek (приказать убить).
5. Типичная ошибка: поставить «жертву» каузатива в винительный, а не в дательный.
❌ Anne çocuğu uyuttu.    ✅ Anne çocuğa uyuttu.
