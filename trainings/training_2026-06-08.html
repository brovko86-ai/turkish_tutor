⚡ Recall — Повторение грамматики

Быстрые проверки по темам, которые требуют закрепления.

Тема 1 · Деепричастие -arak/-erek («делая что-то»)

Переведи: «Он ушёл, не сказав ни слова.» (hiç + konuşmak + -madan / Используй отрицательное деепричастие -madan)
💡 Отрицательное деепричастие: глагол + -madan/-meden. gitmek в прошедшем = gitti.
Выбери правильную форму: «Я позвонил другу, идя домой.»
Evime gider_____ arkadaşımı aradım.
💡 -arak/-erek = «делая/по пути как»; gitm → gide + rek. Последняя гласная корня e → суффикс -erek.

Тема 2 · Будущее время -(y)EcEK

Поставь глагол в форму будущего времени 1-го лица мн.ч.:
«Мы найдём решение.» (bulmak)
💡 Корень bul- + -acak (задние гласные) + личное окончание 1pl. Перед -acak мягкий согласный.

Тема 3 · Причастие -EN/-AN («тот, кто делает»)

Выбери верный перевод: «ребёнок, который играет» — это…?
💡 -EN/-AN — суффикс причастия настоящего/будущего (субъект действия). oyna + yan = oynayan.

📖 Каузатив: суффикс -DIR/-T/-IR/-ER

Каузатив — это способ сказать, что кто-то заставляет / побуждает / велит другого что-то сделать. По-русски: «я заставил его прочитать», «мы показали ей фильм» (показать = заставить увидеть). В турецком это делается добавлением суффикса к корню глагола — и тогда объект становится другим человеком.

Формула

[глагольный корень] + -DIR / -T / -IR / -ER + обычные времена

Кто заставляет: субъект в именительном (I, you…)
Кого заставляет: объект в дательном (-e/-a)
Что делает объект: закодировано в каузативе

Пример: Ben ona kitabı okuttum. = Я заставил его прочитать книгу.

Какой суффикс выбрать?

СуффиксКогда использоватьПримеры
-DIR
(-dır/-dir/-dur/-dür)		 Большинство односложных корней, оканчивающихся на согласный iç → içdir (пить → поить)
giy → giydir (надевать → одевать)
-T Многосложные глаголы и те, что оканчиваются на гласный oku → okut (читать → заставить читать)
uyu → uyut (спать → усыплять)
-IR
(-ır/-ir/-ur/-ür)		 Небольшая группа односложных (нужно запомнить) çık → çıkar (выходить → выводить)
göç → göçür (мигрировать → переселять)
-ER
(-ar/-er)		 Несколько односложных нерегулярных (список) git → gittir / geç → geçir (опаздывать → задерживать)
DİKKAT! Правило FSTKÇŞHP работает и здесь: -DIR после глухого согласного становится -TIR. Например: git + -dir → gittir (заставить идти). Удвоение t — это и FSTKÇŞHP, и ассимиляция одновременно!

✍️ Упражнения по каузативу

1. Какой каузативный суффикс нужен для глагола uyu- (спать)? Последний звук корня — гласный.
💡 Когда корень оканчивается на гласный — используем -t (самый лаконичный вариант).
2. Образуй форму прошедшего времени, 1sg: «Я уложил ребёнка спать.»
Çocuğu _____ (uyu + каузатив + прошедшее 1sg)
💡 uyu + -t = uyut → прошедшее: добавь -DI. После T (глухой!) по правилу FSTKÇŞHP суффикс -DI → -TI. Личное окончание 1sg = -m.
3. «Директор заставил нас работать до позднего вечера.» Какая форма глагола çalışmak нужна?
💡 çalış + -tır = çalıştır (тут -DIR становится -TIR по FSTKÇŞHP: ş глухой). Уже изучали как «запускать/включать»!
4. Переведи на турецкий: «Учитель показал нам картину.»
(göstermek = görmek + -ter → уже готовый каузатив)
💡 göstermek — уже готовый каузатив. Прошедшее 3sg = gösterdi. Кому = bize (дат.), что = tabloyu (вин.).
5. Что отличает «Ali okudu» от «Ali bana okuttu»?
6. Образуй каузатив от içmek (пить). Какое слово получится?
💡 iç (односложный, заканчивается на ç — глухой) → суффикс -IR (группа нерегулярных). iç + ir = içirmek = поить / дать выпить.
7. Переведи: «Не заставляй меня ждать!» (beklemek → beklet-)
💡 bekle + -t = beklet → повелительное отрицание: -me/-ma. Кого? beni (вин. от ben).
8. Что значит: «Müziği yüksek sesle çaldırarak herkesi rahatsız etti.»?
💡 çaldırmak = каузатив от çalmak (играть/воровать). -arak = «делая». rahatsız etmek = беспокоить.
9. Заполни пропуск: «Мой старший брат заставил меня помочь ему.»
«_____ bana yardım ettirdi.» (Используй: ağabey + притяжательный суффикс 1sg)
💡 ağabey + притяжательное 1sg: гласная гармония — последняя гласная e → суффикс -im.

🧭 Мини-ревью урока

1. Каузатив = «заставить / побудить кого-то что-то сделать». Добавляем суффикс к корню глагола.

2. Главный суффикс -DIR (4 варианта по гармонии: -dır/-dir/-dur/-dür) — для большинства корней на согласный.

3. Суффикс -T — для корней на гласный: uyu → uyut, oku → okut, söyle → söylet.

4. FSTKÇŞHP работает и тут: после глухого согласного -DIR → -TIR (git → gittirmek).

5. Тот, кого заставляют, стоит в дательном падеже (-e/-a); то, что делается — в винительном.

Типичная ошибка: «Ben onu okudum» ≠ заставил читать.
Правильно: Ben ona kitabı okuttum. (дательный для объекта-человека!)
DİKKAT! Многие каузативы уже лексикализовались как обычные слова: göstermek (показывать), bildirmek (сообщать), çalıştırmak (запускать), içirmek (поить). Ты уже их знаешь — теперь понимаешь их структуру!
