Темы из диагностики — проверяем, что осталось в памяти.

Тема: -arak/-erek
Выбери правильный вариант деепричастия от глагола koşmak («бежать»):
💡 Правило: корень koş- → последняя гласная o → задний ряд → суффикс -arak (не -erek).
Тема: будущее время -(y)EcEK
Как сказать «Она защитит» (korumak, 3-е лицо ед.ч.)?
💡 Корень koru- оканчивается на гласную → вставляется -y-. Последняя гласная корня u → задний ряд → -acak. 3-е лицо ед.ч. — без личного окончания.
Тема: инструментальный падеж -le/-la
Переведи фразу: «с другом» (arkadaş):
💡 Слово оканчивается на согласную ş. Последняя гласная a → задний ряд → суффикс -la. Конечная ş → твёрдая (в FSTKÇŞHP) → -la (не -da/de), но instrumental -le/-la не зависит от FSTKÇŞHP — смотрим только на гармонию гласных.
Тема: именное сказуемое değil
Как сказать «Это не моя сумка» (bu, benim çantam)?
💡 Отрицание именного сказуемого — «değil» после предиката. «Yok» — для физического отсутствия, «değil» — для «не является тем-то».

🎯 Глагол дня — kesmek

kesmek — резать / обрезать / прерывать / останавливать
Управление: neyi keser? → прямое дополнение в винительном падеже (-i/-ı/-u/-ü)

Спряжение в трёх временах

Лицо -iyor (наст.) -di (прош.) -(y)ecek (буд.)
Benkesiyorumkestimkeseceğim
Senkesiyorsunkestinkeseceksin
Okesiyorkestikesecek
Bizkesiyoruzkestikkeseceğiz
Sizkesiyorsunuzkestinizkeseceksiniz
Onlarkesiyorlarkestilerkesecekler
DİKKAT ET! Корень kes- заканчивается на s (из FSTKÇŞHP) → в прошедшем времени суффикс -DI становится -ti (не -di): kesti, kestik, kestiler. Гласная e → передний ряд → -ti (не -tı).

Живые примеры

Saçlarını kesti.
Она/он постриглась/ся. (букв. «срезала/срезал волосы»)
Ekmek kesiyorum.
Я режу хлеб. (ekmek — без вин. пад., т.к. неопределённый объект)
Elektriği kestiler.
Они отключили электричество. (elektriği = elektrik + -i, вин. пад.)
Telefonu kesme!
Не бросай трубку! (отрицательный императив)
Konuşmayı kestim.
Я прервал разговор. (konuşma + -yı → вин. пад.)
Pazartesi toplantı yarı yolda kesildi.
В понедельник совещание прервалось на полпути. (kesmek → пассив kesilmek — тема сегодняшнего урока!)

Однокоренные слова

  • kesim — порез / разрез / сектор
  • keskin — острый (нож, ум)
  • kesilmek — прерываться / быть разрезанным (пассив от kesmek)
  • kesiştirmek — пересекать (пути, линии)
  • kesintisiz — непрерывный / без остановок (-siz = «без»)

📖 Новая грамматика — Пассив -IL / -İL / -UL / -ÜL / -N

Пассивный залог (страдательный) говорит, что действие происходит с субъектом, а не производится им. В русском — «дверь открывается», «письмо написано». В турецком — специальный суффикс добавляется к основе глагола.

Формула

Глагол (основа) + -IL / -İL / -UL / -ÜL + (время) + (лицо)

Если основа оканчивается на гласную → суффикс -N (не -IL)
Если основа оканчивается на согласную → суффикс -IL / -İL / -UL / -ÜL

Таблица гармонии гласных

Последняя гласная основы Суффикс пассива Пример Значение
a, ı -ıl yazılmak быть написанным (yazmak)
e, i -il kesilmek быть разрезанным (kesmek)
o, u -ul bulunmak* находиться / иметься (bulmak)
ö, ü -ül görülmek быть увиденным (görmek)
* bulmak → bulunmak (основа bul-, оканчивается на согласную l → +ul → bulul → нерегулярное: bulunmak)
оканчивается на гласную -n okunmak читаться / быть прочитанным (okumak)
оканчивается на гласную -n açıklanmak объясняться / быть объяснённым (açıklamak)

Примеры в разных временах

Mektup yazıldı.
yaz + -ıl + -dı → Письмо было написано.
Письмо написали / Письмо было написано.
Bu kitap çok okunuyor.
oku + -n + -uyor → Эта книга читается (сейчас).
Эту книгу много читают.
Kapı açılacak.
aç + -ıl + -(y)acak → Дверь будет открыта.
Дверь откроют / Дверь будет открыта.
Söz tutuldu.
tut + -ul + -du → Обещание было сдержано.
Слово сдержали. (tutmak = держать/соблюдать)
Yeni yasa kabul edildi.
kabul et → kabul edil + -di → Новый закон был принят.
Новый закон приняли. (составной глагол: etmek → edilmek)
✅ ЗАПОМНИ: Составные глаголы типа «существительное + etmek» образуют пассив заменой etmek → edilmek:
kabul etmek → kabul edilmek
takdim etmek → takdim edilmek
Личные суффиксы добавляются уже к пассивной форме.
DİKKAT ET! Пассив ≠ рефлексив. Суффикс -in / -ın / -un / -ün — это рефлексив (возвратный: «делать самому с собой»).
-il / -ıl / -ul / -ül — пассив («что-то делают с кем-то/чем-то»).
Пример: yıkanmak = мыться (сам) ← рефлексив; yıkanmak = быть вымытым ← пассив.
Внешне совпадают, но контекст чётко указывает значение.

Деятель в пассивной конструкции — tarafından

Если нужно указать, кем выполнено действие — используется конструкция kişi + tarafından («со стороны / от»):

Bu roman ünlü bir yazar tarafından yazıldı.
yazar tarafından = «со стороны писателя / писателем»
Этот роман написан известным писателем.
Şarkı benim tarafımdan söylendi.
benim tarafımdan = «с моей стороны / мной»
Песня была спета мной.

✍️ Упражнения — Пассив

1. Какая форма правильно выражает пассив от bulmak (находить)?
💡 Основа bul- оканчивается на согласную l. Гласная u → -ul, но bul + ul → bulul → нерегулярно сокращается в bulun-. Это частое исключение.
2. Вставь форму пассива в настоящем времени от okunmak (читаться), 3-е лицо ед.ч.:
Bu makale her gün ___________. (Эту статью читают каждый день.)
💡 oku- оканчивается на гласную → пассив -n → okun-. Настоящее время + 3-е ед.ч.: -uyor (без личного окончания).
3. Что означает форма yazılacak?
💡 yaz + -ıl + -(y)acak = пассив + будущее время. Суффикс -(y)acak/-ecek → будущее.
4. Переведи: «Провода обрезали» → используй kesmek в пассиве прош. вр. (3-е лицо ед.ч.).
Kablolar ___________.
💡 kes- + -il (e-ряд) + -di (не -ti! -il- оканчивается на l — не из FSTKÇŞHP → звонкое -di). 3-е лицо ед.ч. — без личного окончания.
5. Выбери правильное продолжение:
Pencere kasıtlı olarak ___________. (Окно было намеренно разбито.)
💡 kır- + -ıl + -dı. Последняя гласная корня ı → -ıl. Суффикс -ıl оканчивается на l (не FSTKÇŞHP) → -dı (звонкое). Это прошедшее, не вопрос.
6. Поставь görmek в пассивную форму настоящего времени (3-е ед.ч.):
Bu film çok iyi ___________. (Этот фильм очень хорошо воспринимается / его много смотрят.)
💡 gör- + -ül (ö/ü-ряд — передние огублённые) + -üyor (настоящее). Итого: gör-ül-üyor.
7. Как выразить «написан известным писателем» (ünlü yazar)?
💡 Деятель в пассивной конструкции — «kişi + tarafından». «-ile» — инструментальный (с помощью); «-e göre» — по мнению; «-den» — из/от.
8. Как сказать «Заявка была принята» (başvuru, kabul etmek)?
Başvuru ___________.
💡 Составной глагол kabul et- → пассив: etmek → edilmek. Прошедшее: -di. Итого два слова: kabul edildi.
9. Определи: какая из форм является пассивом (не каузативом)?
💡 Каузатив: -tır/-dir/-t/-ir/-er — «заставить делать». Пассив: -il/-ıl/-ul/-ül/-n — «быть сделанным». Суффикс -ıl/-il явно указывает на пассив.
10. Поставь sallamak («качать/трясти») в пассив прошедшего времени, 3-е ед.ч.:
Ağaç rüzgarla ___________. (Дерево было раскачано ветром.)
💡 salla- оканчивается на гласную a → пассив -n → sallan-. Прошедшее: последняя гласная a → -dı. Но n не из FSTKÇŞHP → звонкое d: sallan-dı.

🎨 Свободная продукция

Составь 3–4 предложения о любом событии, которое недавно произошло — используй пассивный залог. Можно взять тему: рабочее собрание, поездка, новость в городе, событие из жизни.

🔑 Опорные слова и структуры:

  • Новые слова: kesmek (резать), kaynamak (кипеть), yakalamak (поймать), sallamak (качать)
  • Weak слова: korumak (защищать), hissetmek (чувствовать), gezmek (гулять)
  • Конструкции: ___ tarafından + пассив, ___ kesildi / bulundu / yakalandı
  • Шаблон: Bu [существительное] [кем] tarafından [пассивный глагол].

Примеры-подсказки (можно использовать как основу):

Hırsız polis tarafından yakalandı.
yakala- + -n (гласная) + -dı
Вор был пойман полицией.
Doğa yeni kanunlarla korunacak.
koru- + -n + -(y)acak
Природа будет защищена новыми законами.
Şehirde hissedilen sıkıntı herkes tarafından biliniyordu.
hisset- + -il + -en (причастие) → ощущаемая...
Тревога, ощущаемая в городе, была всем известна.
Структура пассивного предложения в турецком:
[Субъект (пациенс)] + [деятель + tarafından] + [глагол в пассиве]

Пример: Mektup (субъект) + müdür tarafından (деятель) + imzalandı (пассив прош. от imzalamak).
Если деятель неважен или неизвестен — просто: Mektup imzalandı.

🧭 Мини-ревью урока

  • Пассив в турецком — суффикс -IL/-İL/-UL/-ÜL (после согласной) или -N (после гласной).
  • Гармония гласных: последняя гласная основы определяет вариант суффикса: a/ı → -ıl, e/i → -il, o/u → -ul, ö/ü → -ül.
  • Главная формула: основа + пассивный суффикс + суффикс времени + личное окончание
    → yaz + ıl + dı + m = yazıldım («меня написали» / «я был написан»)
  • Деятель указывается через ___ tarafından («со стороны кого-то»).
  • Типичная ошибка: путаница пассива с каузативом. Запомни: -tır/-dir/-t = «заставить делать» (каузатив); -il/-ıl/-ul = «быть сделанным» (пассив).
