Корень для спряжения: hisset- → FSTKÇŞHP: конечный t → суффикс -di превращается в -ti

📖 Каузатив — суффикс -DIR/-T/-IR: «заставить сделать»

Каузатив (понудительный залог) отвечает на вопрос: «кто заставляет кого-то что-то делать?». В турецком он образуется суффиксом, который добавляется к глагольному корню перед остальными суффиксами времени.

Основная формула:
[глагол-корень] + [-DIR / -T / -IR / -ER / -IT / -ÜRT...] + [суффикс времени] + [личное окончание]

Смысл: субъект заставляет / велит кому-то выполнить действие.

Три основных варианта суффикса

Суффикс Когда используется Пример
-DIR/-TIR Самый универсальный. Добавляется к большинству глаголов (с учётом гармонии гласных) yap-tır-mak (заставить сделать)
-T К глаголам, оканчивающимся на гласную oku-t-mak (заставить читать)
-IR/-ER/-UR/-ÜR К ряду односложных корней (нерегулярно) geç-ir-mek (проводить время/переводить)

Гармония гласных в -DIR

Последняя гласная корня Вариант суффикса Пример
a, ı -TIR / -DIR yap → yaptır, çal → çaldır
e, i -TİR / -DİR içir → iç → içir, giy → giydір
o, u -TUR / -DUR oku → okut, koş → koştur
ö, ü -TÜR / -DÜR gör → göster (нерег.), düşün → düşündür
DİKKAT ET! FıSTıKÇı ŞaHaP
Если корень оканчивается на твёрдый согласный (F-S-T-K-Ç-Ş-H-P), суффикс начинается с глухого -t, а не звонкого -d:
• yap (P) → yaptırmak ✓ (не yapdırmak!)
• sat (T) → sattırmak ✓
• iç (Ç) → içirmek (особый вариант -ir)

Кто «заставляет», а кто «выполняет»?

В каузативной конструкции появляется второй участник — тот, кого заставляют. Он ставится в дативный падеж (-e/-a):

Anne çocuğa ellerini yıkattı.
çocuk + -a (дат., «ребёнку») | yıka (мыть) + -t (кауз.) + -tı (прош.)
Мама заставила ребёнка вымыть руки.
Müdür raporu sekretere yazdırdı.
rapor + -u (акк.) | sekreter + -e (дат.) | yaz + -dır + -dı
Директор велел секретарю написать отчёт.
Arabanı tamir ettirecek misin?
araba + -nı (акк.) | tamir ettir (кауз. от tamir etmek) + -ecek + mi + sin
Ты отдашь машину в ремонт? (букв.: заставишь починить?)
Annem bana saçımı kestirdi.
kes (резать/стричь) + -tir (кауз.) + -di | bana = мне
Мама отправила меня постричься. (букв.: мама заставила меня постричь волосы)
💡 Бытовое использование: В повседневной речи каузатив часто означает «отдать что-то делать»:
• elbiseyi yıkatmak — отдать платье в стирку
• saçını kestirmek — постричься (у парикмахера)
• evi boyatmak — покрасить дом (через маляра)
Т.е. субъект не обязательно прямо командует — он просто организует, чтобы действие было выполнено кем-то другим.

✍️ Упражнения по каузативу

1. Образуй каузатив от глагола «okumak» (читать → заставить читать). Выбери правильную форму инфинитива:
💡 oku- оканчивается на гласную → суффикс каузатива для глаголов на гласную: -T. oku + T + mak = ?
2. Образуй каузатив от «yazmak» (писать). Заполни пропуск: «Öğretmen öğrencilere şiir yaz___tı.»
💡 yaz: последняя гласная — a → суффикс -dır (звонкий, т.к. z — не из FıSTıKÇı ŞaHaP). Затем прошедшее время -dı. Итого: yaz + dır + dı.
3. Что означает «yaptırmak»?
💡 yap- (делать) + -tır (каузатив) + -mak (инфинитив). Суффикс -tır указывает, что действие выполняется кем-то другим по велению субъекта.
4. Переведи на турецкий: «Я велел другу принести книгу.»
getirmek (принести) → каузатив: getir + t = getirtmek? нет — getir оканчивается на согласный r → getirt... нет. Подсказка: getirt → getirttim? нет. Используй форму: getir + dir = getirdir... Нет! Смотри: getir → корень кончается на r (не из FıSTıKÇı). Суффикс: -t → getiртmek — нет. Правило: getir → добавляем -t → getirtmek.
💡 getir- (корень кончается на r, не из FıSTıKÇı) → суффикс -t → getirt-. Прошедшее: -ti + -m. «Другу» = arkadaşıma (дат.). «Книгу» = kitabı (акк.).
5. Выбери правильную форму: «Она отдала платье в химчистку.» (elbise = платье, temizlemek = чистить)
💡 Нужен каузатив, т.к. «она» не сама чистит, а отдаёт. temizle- (кончается на гласную) + -t = temizlet-. Прошедшее -ti: temizlett + i = temizletti.
6. «Annem bize sebze ___» — Мама заставила нас есть овощи. (yemek → yedir- это нерег. форма; подбери правильную каузативную форму в прошедшем, 3л.)
💡 yemek → нерегулярный каузатив: ye- + -dir = yedir-. Прошедшее 3л ед.ч.: yedir + di = yedirdi. (ye- — особая форма с гласным корнем + -dir)
7. Какое предложение содержит ошибку в использовании каузатива?
💡 Каузатив значит «заставить другого», но пассив (-il/-in) значит «быть сделанным самому». «Музыкой заниматься» — это ilgilenmek, и там добавление каузатива + пассива создаёт неестественную конструкцию. Найди предложение, где каузатив использован вместо простого глагола.
8. Переведи: «Папа заставил меня убраться в комнате.» (toplamak = убирать/собирать; oda = комната)
💡 «Меня» в роли того, кого заставляют = bana (дат.). topla- (гласный конец) + -t (кауз.) = toplat-. Прошедшее: toplattı. Комнату (определ. объект) = odayı.
9. Повторение пассива (тема прошлой сессии): Переведи на пассив: «Письмо написали» (mektup = письмо; yazmak → passive: yazılmak)
💡 Пассив от yaz-: yaz + -ıl (корень кончается на согласный → -ıl) + -dı (прош.) = yazıldı. Субъект исчезает, объект становится подлежащим.

Напиши 4–5 предложений о том, как ты или кто-то из твоего окружения «заставляет» или «велит» что-то сделать. Используй каузатив! Ниже — опорная лексика.

💡 Опорная лексика для этого задания:
• ağabeyim (мой старший брат) ⚠ — Ağabeyim bana...
• ilgilenmek (заниматься чем-то) ⚠ — ...ile ilgilenmemi istedi
• tanımak (знать кого-то) ⚠ — Onu tanıdırttı (познакомил)
• hissetmek (чувствовать) — Bana korkuyu hissettirdi
• durmak (останавливаться) → каузатив: durdurtmak / durdur-
• girmek (входить) → каузатив: girdirmek
• yaptırmak — заставить сделать
• -e karar verdirmek — заставить принять решение
Образец ответа:
1. Ağabeyim beni korkuyu hissettirdi. — Мой старший брат заставил меня почувствовать страх.
2. Müdür sekreterine raporu yazdırdı. — Директор велел секретарю написать отчёт.
3. Annem ilgilenmemi istedi — Türkçe ile ilgilenmemi. — Мама хотела, чтобы я занялся турецким.
4. Arkadaşımı tanıdırttım — Я познакомил их (заставил узнать друг друга).
5. Trafik dolayı arabayı durdurttum. — Из-за пробок я остановил машину.

🧭 Мини-ревью урока 43

  • Каузатив = суффикс -DIR / -T / -IR (+ варианты по гармонии) между корнем и суффиксом времени. Значение: «заставить/велеть кому-то что-то сделать».
  • Три основных варианта: -tır/-dir (большинство глаголов), -t (глаголы на гласную: oku→okut), -ir/-er (нерегулярные: ye→yedir).

  • Тот, кого заставляют — в дативе (-e/-a): Çocuğa ders yaptırdım — Я заставил ребёнка делать уроки.
  • Типичная ошибка: путать каузатив (-tır) и пассив (-ıl/-il). yaptırıldı = «было велено сделать» (каузатив + пассив!) — это уже двойной суффикс, реально встречается, но не смешивай их значения.
